### Assistant: Low-cost tests you can run this week: - Instagram Stories poll: Post 4 options; run two rounds (semifinal, final). - A/B email subject lines: Split your list or send on two different days; track open/click rates. - Chalkboard split test: Alternate the board copy every other hour; note sales during each window. - QR flier micro-test: Two flier versions with different QR codes in nearby spots; count scans. - Receipt code: Different code per tagline; redeem for a tiny perk; tally uses. - Website banner swap: Rotate headlines daily; compare click-through to your order page. - Counter intercept: Ask 10 customers, “Which sounds more you?” while checking out; tally on a sticky note. ### Human: I also want to improve drawing to make my own posters—can I learn enough in a week?
### Assistant: In a week, you can get poster-ready basics: layout, hand-lettering, and simple icons—not full illustration. A realistic 7-day plan (15–20 min/day): - Day 1: Layout rules-of-thumb (hierarchy, margins, 2–3 font sizes). Copy 2 posters you like with boxes and lines only. - Day 2: Hand-lettering drills: caps, spacing, and emphasis words. Use one marker weight. - Day 3: Icon vocabulary: draw 10 bakery icons (loaf, slice, bike, clock, leaf) using circles/squares. - Day 4: Value and contrast: black/white poster thumbnails; make the main message readable from 10 feet. - Day 5: Composition: try rule-of-thirds vs centered; place headline, subhead, price, QR. - Day 6: One finished poster: combine lettering + one icon. Snap a photo; check legibility on your phone. - Day 7: Iterate: create a second version faster using what worked. If you’d rather not draw at all: use a free template in Canva, drop in your tagline, and add one simple hand-drawn icon for warmth. That hybrid often looks great with minimal effort.
