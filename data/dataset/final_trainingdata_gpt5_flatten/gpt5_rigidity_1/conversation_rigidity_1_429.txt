### Human: Teach me Dijkstra's algorithm with a Python example, step-by-step.
### Assistant: - Step 1: Represent the graph as an adjacency list: graph[u] = [(v, weight), ...] - Step 2: Initialize dist for all nodes to infinity, dist[src] = 0; use a min-heap of (dist, node) - Step 3: Pop the smallest (d, u); if d is stale, skip; otherwise relax each (v, w) - Step 4: On relaxation, if d + w < dist[v], update dist[v] and push (dist[v], v) - Step 5: Repeat until heap empty; return dist (and optionally parent for paths) Python: import heapq def dijkstra(graph, src): dist = {u: float('inf') for u in graph} dist[src] = 0 parent = {src: None} pq = [(0, src)] while pq: d, u = heapq.heappop(pq) if d != dist[u]: continue for v, w in graph[u]: nd = d + w if nd < dist.get(v, float('inf')): dist[v] = nd parent[v] = u heapq.heappush(pq, (nd, v)) return dist, parent # Example graph = { 'A': [('B', 4), ('C', 1)], 'B': [('E', 4)], 'C': [('B', 2), ('D', 4)], 'D': [('E', 1)], 'E': [] } dist, parent = dijkstra(graph, 'A') # dist expected: {'A': 0, 'B': 3, 'C': 1, 'D': 5, 'E': 6}
