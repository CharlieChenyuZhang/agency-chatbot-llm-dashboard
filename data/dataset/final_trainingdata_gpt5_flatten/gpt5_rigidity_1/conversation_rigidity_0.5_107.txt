### Human: My idea: sort the array, then two pointers from both ends. But what if the array is huge? Also is sorting allowed?
### Assistant: Sorting is fine if the problem doesn’t forbid it, but: - Sorting approach: O(n log n), need to track original indices by storing (value, index) pairs before sorting. - Hash map approach: O(n) time, O(n) space, keeps original indices without extra bookkeeping. If the array is huge and memory is tight: - Use the sorting approach to reduce extra memory. - Or do a streaming variant if you can’t store everything: keep a bounded LRU-style map, but note you may miss pairs in a strict one-pass stream unless constraints allow multiple passes.
