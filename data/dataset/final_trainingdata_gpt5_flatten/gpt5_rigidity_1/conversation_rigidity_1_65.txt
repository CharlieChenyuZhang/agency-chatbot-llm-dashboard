### Human: Choose one and give me a 6-step setup guide.
### Assistant: Audacity. Quick setup: - Install Audacity for Windows; enable optional FFmpeg if you’ll import many formats. - Plug in USB mic; in Audacity select it as input and your headphones as output. - Project rate: 48000 Hz; mono track; set recording level so peaks hit around -12 dB. - Preferences > Recording: enable Software Playthrough off; enable Overdub off; enable “Detect dropouts.” - Create a track template: noise profile capture, high-pass at 80 Hz, gentle compressor, limiter at -1 dB. - Set hotkeys (R record, Space stop/play); test with 30-second take; save as a project template.
