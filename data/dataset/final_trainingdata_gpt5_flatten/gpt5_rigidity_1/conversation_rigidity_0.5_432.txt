Simple conversion path: - Tool: fre:ac (free, lightweight) or dBpoweramp (paid, very easy). fre:ac can convert FLAC → ALAC with tags preserved. - Steps (fre:ac example): 1) Install fre:ac. 2) Add your FLAC folders. 3) Encoder: “Core Audio AAC/ALAC Encoder” → choose ALAC (Apple Lossless). 4) Output to a new folder named “ALAC_Converted”. 5) Run a test on 2–3 tracks first. 6) When satisfied, convert the rest. ### Human: How do I remove duplicates inside iTunes and keep the best ones?
### Assistant: In iTunes on Windows: 1) Back up your iTunes Library.itl file and your music folder (just in case). 2) Library view: switch to “Songs.” 3) File > Library > Show Duplicate Items. - Tip: Hold Shift while clicking to reveal “Show Exact Duplicate Items” (matches name and artist) to reduce false positives. 4) Sort columns by: - Bit Rate (keep higher) - Kind (prefer Apple Lossless over MP3/AAC for a master copy) - Time (keep the one that matches album version; watch out for deluxe/clean versions) 5) For each group, delete the lower-quality duplicate: - Right-click > Delete from Library. - When prompted, choose “Move to Recycle Bin” if you want the file removed from disk; choose “Keep File” if you’re not ready to delete physically. Optional smart playlists to batch-find likely keepers: - “Lossless Keepers”: Kind contains “Apple Lossless” - “Low Bitrate Candidates”: Bit Rate is less than 192 kbps Use these to guide which versions you keep or remove. We’ll do this in passes so you stay in control.
