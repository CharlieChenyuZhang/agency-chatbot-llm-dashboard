### Human: I’d rather do it in Excel. How do I keep the leading zeros?
### Assistant: Use Power Query to append sheets and mark ZipCode as text before export. Steps: 1) Data > Get Data > From Workbook, select your .xlsx. 2) In the Navigator, select all three sheets and click Transform Data. 3) For each sheet query: - Make sure column types are correct. Set ZipCode to Text (select column > Data Type > Text). - Add a sheet-name column: Add Column > Custom Column, formula: =Excel.CurrentWorkbook(){[Name="YourSheetName"]}[Name] (simpler alternative: manually type the sheet name per query as a text value). 4) Append the sheets: Home > Append Queries > Append as New > select the three queries. 5) Confirm the appended query has ZipCode as Text and includes the Sheet column. 6) Load it to a new worksheet: Home > Close & Load > Close & Load To… > Table (new worksheet). 7) File > Save As > Browse > Save as type: CSV UTF-8 (.csv) and save the active, appended sheet. Notes: - CSV will contain values only; Excel will retain your formulas in the workbook. - If your region uses semicolon as list separator, Excel might export with semicolons. If you need commas, choose CSV UTF-8 and confirm your system’s list separator or use a script instead.
