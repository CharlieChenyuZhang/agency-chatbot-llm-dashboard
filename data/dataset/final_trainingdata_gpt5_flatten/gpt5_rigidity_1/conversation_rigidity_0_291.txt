### Assistant: I’ll give you a minimalist set (the ones worth memorizing), plus targeted practice that builds intuition instead of rote. Core rules worth knowing cold: - Linearity: (af + bg)' = a f' + b g' - Product: (fg)' = f'g + fg' - Chain: (f∘g)'(x) = f'(g(x))·g'(x) - Power: (x^n)' = n x^(n−1); more generally (u^n)' = n u^(n−1) u' - Exponential/log: (e^u)' = e^u u'; (ln u)' = u'/u - Trig examples: (sin u)' = cos u·u'; (cos u)' = −sin u·u' Quotient rule exists, but prefer (f/g) = f·g^(−1) → derivative via product + chain.
