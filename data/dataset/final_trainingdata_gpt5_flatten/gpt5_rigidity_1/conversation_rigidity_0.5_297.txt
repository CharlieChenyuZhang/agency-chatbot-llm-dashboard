### Human: Okay, let's try Mp3tag and dupeGuru. What exact steps?
### Assistant: Steps with minimal risk: 1) Back up: Copy your current music folders to an external drive or a “_backup” folder. 2) Gather into a staging folder: Create C:\Music_Staging and copy all music there (don’t move originals yet). 3) Mp3tag (portable): - Download the portable zip from Mp3tag’s site and extract. - In Mp3tag: File > Change directory… point to C:\Music_Staging. - Use Tag Sources (Alt+S) > MusicBrainz or Discogs to fill in missing/incorrect tags (Artist, Album, Track, Year, Album Artist, etc.). - Ensure “Album Artist” is set (for compilations use “Various Artists”). - Optionally embed cover art: Right-click selected tracks > Extended Tags > Add cover (or use Tag Sources that fetch art). 4) Define the folder/file naming scheme in Mp3tag: - Convert > Tag - Filename… - For folders by Album Artist/Year/Album and files as Track - Title (with VA handling), I recommend: Folder + filename pattern combined: C:\Music_Organized\$if2(%albumartist%,%artist%)\$if2(%year%,$left(%date%,4)) - %album%\$if($or(%discnumber%,%totaldiscs%),Disc $num(%discnumber%,1)\,)$num(%track%,2) - $if($eql(%albumartist%,Various Artists),%artist% - ,)%title% - Run this on a small subset first (e.g., 200 tracks) to verify. 5) Move (don’t overwrite): The Convert action will place files into C:\Music_Organized. Leave the staging copy until you’re satisfied. 6) Deduplicate with dupeGuru (portable): - Mode: Music. Point it at C:\Music_Organized. - Preferences: Scan type = Filename + Tags + Contents; adjust “Word weighting” around default. - Sort by “Dupe Count” or “Similarity”. - In the results, use the Mark menu to prefer keeping: higher bitrate, FLAC over MP3, longer duration. Then “Send Marked to Recycle Bin” (not permanent delete) so you can restore mistakes. 7) Spot check: Open a few albums; check multi-disc handling and artwork. 8) When happy, archive or delete the old scattered folders. This avoids heavy installs, keeps it reversible, and gets you clean Artist/Year/Album folders.
### Human: What naming pattern do you recommend including featured artists and multi-disc?
### Assistant: Good call. A practical, tidy pattern: - Folder path: C:\Music_Organized\$if2(%albumartist%,%artist%)\$if2(%year%,$left(%date%,4)) - %album%$if($or(%discnumber%,%totaldiscs%),\Disc $num(%discnumber%,1),) - Filename: $num(%track%,2) - $if($eql(%albumartist%,Various Artists),%artist% - ,)%title% - Featured artists in title: If you want “Title (feat. X)” when there’s a %featuring% tag, use: $num(%track%,2) - $if($eql(%albumartist%,Various Artists),%artist% - ,)%title%$if(%featuring%, (feat. %featuring%),) Notes: - For compilations, Album Artist = “Various Artists” groups them neatly. - The Disc folder appears only when discnumber exists. - Year falls back to the year parsed from date if year is missing.
### Human: What about organizing by genre? I kind of want genre folders.
### Assistant: You can, but a heads-up: genre tags are inconsistent, tracks can have multiple genres, and artists span genres—so physical genre folders often cause duplicates or fragmentation. A more practical approach is: - Keep files by Album Artist/Year/Album. - Use genre-based smart playlists or views in your player (MusicBee, Foobar, Plex, etc.) without moving files. If you still want genre folders, use the first genre only to avoid duplicates: C:\Music_Organized\$meta(genre,0)\$if2(%albumartist%,%artist%)\$if2(%year%,$left(%date%,4)) - %album%\$num(%track%,2) - $if($eql(%albumartist%,Various Artists),%artist% - ,)%title% But I’d encourage virtual organization by genre vs. physical folders for long-term sanity.
