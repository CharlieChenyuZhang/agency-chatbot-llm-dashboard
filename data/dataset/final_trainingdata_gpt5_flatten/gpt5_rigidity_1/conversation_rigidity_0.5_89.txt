### Human: I also play keyboard and want to record vocals occasionally. Is USB still OK?
### Assistant: USB is fine for solo voice. For keyboard plus vocals, an audio interface is more flexible, but you can phase this in. Two practical options: - Hybrid now, upgrade later: Get ATR2100x-USB (USB today). Later add a 2‑in interface (MOTU M2, SSL 2, or Focusrite 2i2) and use the mic’s XLR output. The interface will also let you record your keyboard properly. - All‑in‑one USB now: PodMic USB for your voice, and use your keyboard’s USB-MIDI to play virtual instruments. If you need the keyboard’s audio, you’ll still want an interface eventually for clean, stereo line‑in. So USB is okay to start; for keyboard audio, plan on an interface when you can.

### Human: Ok, let’s go with the ATR2100x-USB. Help me configure the audio chain in OBS.
### Assistant: Perfect. Quick setup steps: Physical setup - Distance: 2–4 inches from the grille, slightly off-axis (about 20–30°) to reduce plosives. - Use a foam windscreen or pop filter. - Mount on a boom arm to get it close and away from keyboard. Windows/mac settings - Sample rate: 48 kHz, 24-bit if available. - Set ATR2100x as default input and monitoring output (headphones into the mic for zero-latency monitoring). Gain staging - On the mic: Set gain so normal speech peaks around -12 to -9 dB in OBS, not hotter than -6 dB. - Keep the mic close; lower gain helps reduce room noise. OBS chain (Filters on your Mic source, in this order) 1) High Pass Filter - Frequency: 80–100 Hz (start 90 Hz), 12 dB/oct. 2) Noise Suppression - Method: RNNoise (good quality). Strength: Medium. If it warbles, back off and rely more on close-miking and gate. 3) Noise Gate - Close Threshold: around -50 dB - Open Threshold: around -45 dB - Attack: 5 ms, Hold: 50 ms, Release: 100 ms 4) Compressor - Ratio: 3:1 - Threshold: about -18 dB - Attack: 10 ms, Release: 100 ms - Output gain: +2 to +4 dB as needed 5) De-esser (if available via VST, e.g., TDR Nova or ReaPlugs) - Target 5–8 kHz, reduce 2–4 dB on sibilant peaks 6) Limiter - Ceiling: -1 dB, Release: 60–100 ms Optional EQ (via VST) - Low shelf: +1–2 dB at 120 Hz for warmth (use sparingly) - Presence: +2 dB at 3–4 kHz - Air: +1 dB at 10 kHz if it sounds dull Test - Record a 30–60 sec sample. Aim for loudness around -16 LUFS integrated for streaming. Adjust compressor makeup gain to get there without clipping.
### Human: My keyboard hums when I connect it. What do I do?
### Assistant: That’s likely a ground loop or unbalanced cable noise. Since the ATR2100x is USB and doesn’t have line inputs, you may be routing the keyboard into your PC’s line-in, which is noisy. Short-term fixes (no interface yet): - Use a ground loop isolator between keyboard and PC line-in. - Use the keyboard’s headphone out at low volume into line-in, but expect more noise; keep cable short. - If the keyboard supports USB-MIDI, use that and play a virtual instrument instead of its analog audio for streams. Better solution: - Add a 2‑in USB interface (MOTU M2, SSL 2, Focusrite 2i2 4th Gen). - Connect keyboard’s L/R outputs to the interface using two 1/4-inch TS to TS cables. If you hear hum, use a stereo DI box or TRS balanced outputs if your keyboard supports them. If you want a minimal-budget interim interface for stereo keys, I can suggest a couple options.
### Human: I can increase budget to $300 later. What should I upgrade first?
### Assistant: Biggest impact upgrades in order: 1) Audio interface (MOTU M2 or SSL 2). Cleaner preamps, meters, proper inputs for your keyboard, lower latency. 2) Light room treatment. Two 2×4 ft panels or thick blankets at first reflection points will reduce echo more than any plugin. 3) Mic upgrade (optional). Keep ATR2100x for portability; consider Rode PodMic (XLR) or a used Electro‑Voice RE320 if you find a good deal. 4) Accessories: Quality boom arm, shock mount, and a better pop filter. This path keeps the ATR2100x useful while expanding capability.
