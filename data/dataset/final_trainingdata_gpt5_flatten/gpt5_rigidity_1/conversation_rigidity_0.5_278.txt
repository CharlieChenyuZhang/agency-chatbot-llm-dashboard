### Human: Sure, send the PowerShell snippet.
### Assistant: Here’s a quick hash-based duplicate lister (SHA256). It scans a folder and outputs potential duplicates to a CSV. PowerShell script: $path = "C:\Photos_Staging\BySource" $hashTable = @{} $dupes = @() Get-ChildItem -Path $path -Recurse -File | ForEach-Object { try { $hash = Get-FileHash -Algorithm SHA256 -Path $_.FullName if ($hashTable.ContainsKey($hash.Hash)) { $dupes += [PSCustomObject]@{ Hash = $hash.Hash Original = $hashTable[$hash.Hash] Duplicate = $_.FullName } } else { $hashTable[$hash.Hash] = $_.FullName } } catch { Write-Warning "Failed to hash $($_.FullName): $($_.Exception.Message)" } } $dupes | Export-Csv -Path "$env:USERPROFILE\Desktop\photo_duplicates.csv" -NoTypeInformation Write-Host "Done. Check photo_duplicates.csv on your Desktop." Run in Windows PowerShell. Review the CSV before deleting anything.
