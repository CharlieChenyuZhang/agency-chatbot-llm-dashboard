### Human: Let's start with one—coin change min coins. Walk me through.
### Assistant: Goal: Given coins and an amount, find the minimum number of coins to make the amount (or -1 if impossible). Idea: - dp[a] = minimum coins to make amount a. - Initialize dp[0] = 0; dp[a] = inf for a > 0. - For each a from 1..amount, for each coin c: if a - c >= 0, dp[a] = min(dp[a], dp[a-c] + 1). - Answer is dp[amount] if finite, else -1. Pitfalls: - Use a sentinel (amount+1) or a large number for “inf.” - Unbounded coins: iterate amount outer loop, coins inner loop. Complexity: O(amount × number_of_coins) time, O(amount) space. Try coding it, then we can review and do follow-ups like counting combinations.
