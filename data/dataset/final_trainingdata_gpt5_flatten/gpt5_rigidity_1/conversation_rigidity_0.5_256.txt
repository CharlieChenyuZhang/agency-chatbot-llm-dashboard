### Human: What should the capture rules be? Like when do I write a task vs a note vs a reference?
### Assistant: Use this quick decision flow: - Can it be done in under 2 minutes? - Yes: do it now. No capture. - No: capture it. - Is there a clear, next physical action? - Yes: Type=Task. Title starts with a verb (“Draft,” “Call,” “Review”). Add Due if there’s a date. - No: continue. - Is this information you might reuse, not tied to a specific outcome? - Yes: Type=Reference. Add Source link if applicable. Status=Active (then later to Archived). - No: continue. - Is it related to an active outcome you care about? - Yes: Type=Note. Link it to a Project or create one. - Still unsure? - Type=Unclear, Status=Clarify. Revisit during weekly review. Triage cadence: - Daily (5 minutes): Empty Inbox. Every item becomes Task, Note, or Reference—or Clarify if truly uncertain. - Weekly (20–30 minutes): Process all Clarify items, review Projects, and archive stale Reference. Naming: - Title pattern at capture: “YYYY‑MM‑DD quick gist”. - Tasks: keep titles short and actionable (“Email vendor about invoice”).
### Human: How do I keep my Notion database from bogging down over time?
### Assistant: Keep it fast with a few habits and views: - Archive aggressively: - Reference: move to Status=Archived when it’s not active. Create an “Archived” view that’s excluded from all working views. - Tasks: when done, Status=Archived (don’t delete—keeps history). - Views that default to “only what matters”: - Tasks Due: Type=Task, Status=Active, Due within next 14 days. - Recent Notes: Type=Note, Created within last 30 days, Status not Archived. - Active Reference: Type=Reference, Status=Active. - Monthly cleanup: - Filter for Created > 90 days ago and Status not Active. Batch change to Archived. - Performance tip: - Keep one main Inbox database rather than many small ones. - Use relations (Projects) sparingly—only when the connection helps execution. - Optional: After 6–12 months, export Archived to markdown/CSV if the database gets huge, then keep only the last year online.
