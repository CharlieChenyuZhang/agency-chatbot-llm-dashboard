### Human: I hate design. How do I make them look good quickly?
### Assistant: Minimize design decisions with a consistent system: - Pick one UI kit for all projects: shadcn/ui or Chakra UI with a single theme (colors, radii, shadows). - Global components: AppHeader, AppFooter, Page, Section, EmptyState, ErrorState. - Typography: one font (Inter or system font), one scale (e.g., 14, 16, 20, 24, 32). - Layout: 1200px max width, consistent spacing (8px scale). - Icons: one icon set (Lucide or Heroicons). - Data viz: use Recharts or Tremor for Finance Dashboard. Alternative if you don’t want a new UI library: Tailwind + a prebuilt component pack (e.g., DaisyUI) for fast, consistent styling.
