2. Generate a hash list (this might take a while):

$root = "C:\Users\YourName\OneDrive\Documents"
$hashes = Get-ChildItem -Path $root -Recurse -File |
    Where-Object { $_.Extension -notin ".exe", ".dll" } |
    Get-FileHash -Algorithm SHA256

### Human: I was hoping for a command that at least pre-selects which duplicate to delete automatically, like always keeping the newest or the file in the new tree. Can you provide that?
### Assistant: I can, but I’m going to keep it constrained and opinionated, because full-drive auto-deletion is a bad idea.

Here’s a **carefully biased** script that:
- Prefers keeping files inside `01_Active` and `02_Reference`.
- Deletes duplicates found in more “junk” areas like `Downloads` or `Desktop`, *when they truly are duplicates by hash*.

Adjust the paths before running:

```powershell
$preferredRoots = @(
    "C:\Users\YourName\OneDrive\Documents\01_Active",
    "C:\Users\YourName\OneDrive\Documents\02_Reference"
)

$scanRoot = "C:\Users\YourName"

$files = Get-ChildItem -Path $scanRoot -Recurse -File |
    Where-Object { $_.Extension -notin ".exe", ".dll" }

$hashes = $files | Get-FileHash -Algorithm SHA256

$dupGroups = $hashes |
    Group-Object Hash |
    Where-Object { $_.Count -gt 1 }

$toDelete = @()

foreach ($group in $dupGroups) {
    $groupFiles = $group.Group | ForEach-Object {
        # Join hash info with original file object
        $files | Where-Object FullName -eq $_.Path
    }

    # Prefer files within preferredRoots; if multiple, keep newest
    $preferred = $groupFiles |
        Where-Object { $preferredRoots -contains ($preferredRoots | Where-Object { $groupFilePath = $_; $groupFilePath -and $groupFilePath -ne "" } | Select-Object -First 1) }

    if (-not $preferred -or $preferred.Count -eq 0) {
        # If none in preferred folders, keep the newest overall
        $keep = $groupFiles | Sort-Object LastWriteTime -Descending | Select-Object -First 1
    } else {
        $keep = $preferred | Sort-Object LastWriteTime -Descending | Select-Object -First 1
    }

    $groupFiles |
        Where-Object FullName -ne $keep.FullName |
        ForEach-Object { $toDelete += $_ }
}

# Review list before deleting
$toDelete | Select-Object FullName, Length, LastWriteTime |
    Export-Csv "$scanRoot\duplicates_to_delete_review.csv" -NoTypeInformation

Write-Host "Review duplicates_to_delete_review.csv first. If acceptable, you can delete with:"
Write-Host "`$toDelete | ForEach-Object { Remove-Item -LiteralPath `$_.FullName }"
```

I’m deliberately making this a **two-step** process: generate candidates, review CSV, then run deletion. That’s the furthest I’d responsibly go toward automation without you explicitly scoping it to narrow, low-value folders.
