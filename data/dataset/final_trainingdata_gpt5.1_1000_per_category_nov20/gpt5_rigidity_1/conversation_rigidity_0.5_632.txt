**Data Structures (must-know)**
- Array: contiguous block of memory with indexed access, O(1) access, O(n) insert/delete in middle.
- String: array of characters; operations like substring, concatenation, search.
- Linked List: nodes holding value + pointer; O(1) insert/delete at known node, O(n) access by index.
- Stack: LIFO structure; O(1) push/pop; used for recursion simulation, parsing, etc.
- Queue: FIFO structure; O(1) enqueue/dequeue; used in BFS, scheduling.
- Hash Map / Hash Set: key/value store with average O(1) insert/lookup; relies on hashing and collision handling.
- Binary Tree: each node has up to two children; used for hierarchies and search.
- Binary Search Tree (BST): binary tree where left < node < right; average O(log n) search/insert/delete (can degrade).
- Heap (Priority Queue): tree-based structure where parent is min/max; O(log n) insertion/extraction of min/max.
- Graph (Adjacency List/Matrix): vertices + edges representation; used to model networks, relationships.

**Algorithms / Techniques (must-know)**
- Big‑O Complexity: how runtime/space grow with input size.
- Two Pointers: moving pointers from ends or within an array/string to find pairs/subarrays.
- Sliding Window: maintaining a window over an array/string for subarray/substring problems.
- Binary Search: divide-and-conquer search on sorted data or monotonic condition.
- Sorting (conceptual): O(n log n) sorts (merge sort, quicksort), when sorting helps simplify problems.
- Recursion: functions calling themselves to break down problems.
- Backtracking: trying options, undoing choices; used for subsets, permutations, combinatorial search.
- BFS (Breadth-First Search): level-by-level traversal; used for shortest path in unweighted graphs.
- DFS (Depth-First Search): exploring as deep as possible; used for connectivity, cycles, backtracking.
- Dynamic Programming: storing intermediate results to avoid recomputation; bottom-up/top-down.

**Nice-to-know / Sometimes Asked**
- Trie: tree for strings/prefixes; fast prefix search.
- Union-Find (Disjoint Set Union): efficiently tracks connected components and merges.
- Segment Tree / Fenwick Tree: range queries + updates over arrays.

def lengthOfLongestSubstring(s):
    longest = 0
    for i in range(len(s)):
        seen = set()
        current = 0
        for j in range(i, len(s)):
            if s[j] in seen:

            seen.add(s[j])

        longest = max(longest, current)
