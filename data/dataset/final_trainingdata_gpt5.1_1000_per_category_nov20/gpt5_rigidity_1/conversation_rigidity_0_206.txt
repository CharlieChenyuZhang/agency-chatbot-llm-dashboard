### Human: I was planning to have separate databases: one for tasks, one for books, one for journal. Why do you think that’s a bad idea?

### Assistant: Separate databases feel neat at first, but they make your system brittle:

1. Fragmented search and review  
   - You can’t easily see “What did I read, think, and decide last week?” across tasks, books, and journaling.

2. Higher friction to capture  
   - You must mentally choose the “right” database *before* you even write the note.
   - That tiny pause accumulates and makes you capture less.

3. Harder to evolve  
   - When you inevitably want a new note type (e.g., “Courses” or “People”), you’re adding yet another database, filters, dashboards, etc.

My bias is toward:
- One capture point
- One review habit
- Many ways to *view* the same data (filters, views, dashboards)

If you still want separate databases, I can outline rules, but I’d treat them as views on a unified Inbox database instead:

- Tasks view: filter Type = Task
- Books view: filter Type = Book
- Journal view: filter Type = Journal

That gives you the feel of separate spaces with the advantages of a unified store. I strongly prefer this.

### Human: Fine, let’s do your single database with views approach. How should my daily workflow look with this system?

### Assistant: Good—that choice will make your life easier.

I’d design your daily workflow around two short rituals instead of trying to “be organized all day”:

1. All-day: Mindless capture
   - Rule: whenever something might be worth keeping, you:
     - Open Notion → Inbox
     - Hit “New”
     - Choose the quickest reasonable template (or no template)
     - Write *just enough* to remember what it is and why it matters

   Don’t organize. Don’t tag heavily. Just capture.

2. Daily: 10–15 minute Inbox Review (non-negotiable)
   I’d structure it like this:

   Step 1: Filter today’s captures (Date captured = today)
   For each item:
   - Ask: “Will I care about this in a week?”
     - If no → Status = Archived
     - If yes → continue

   Step 2: Clarify by Type
   - If it’s actionable → Type = Task, fill in “Outcome” + optional due date
   - If it’s insight/learning → Type = Idea or Book, bullet your own summary
   - If it’s emotional processing → Type = Journal, add 1–2 “What I learned” bullets

   Step 3: Slot *only 1–3 tasks* into tomorrow
   - From the Tasks view, pick 1–3 items that truly matter
   - Add a “Do on” date = tomorrow

3. Weekly: 30–45 minute cleanup (I prefer this over complex capture rules)
   - Open each view:
     - Tasks: close or archive anything stale or irrelevant
     - Books: pick one note to refine/condense
     - Journal: scan entries and add 2–3 tags for recurring themes

This is a simple but strong loop: capture → clarify → choose → act → learn.
