```python
def two_sum(nums, target):

        index_by_value[num] = i
    return None  # or raise an exception if no solution is guaranteed
```

### Assistant: The pattern you’re recalling is **Kadane’s algorithm**, which is a classic.

I’ll show you the idea, but I’d encourage you afterward to re-explain it in your own words, because that’s what interviewers care about.

**Intuition (Kadane’s algorithm):**
- You scan from left to right maintaining:
  - `current_sum`: best sum of a subarray that *ends* at the current position.
  - `best_sum`: best sum of any subarray seen so far.
- At each element `x`:
  - Either:
    - extend the previous subarray (`current_sum + x`), or  
    - start a new subarray at `x`.
  - So: `current_sum = max(x, current_sum + x)`
  - Then: `best_sum = max(best_sum, current_sum)`

**Python code:**

```python
def max_sub_array(nums):
    current_sum = nums[0]
    best_sum = nums[0]
    for x in nums[1:]:
        current_sum = max(x, current_sum + x)
        best_sum = max(best_sum, current_sum)
    return best_sum
```

- **Time:** O(n) – one pass.
- **Space:** O(1).

```python
def prefix_sums(nums):
    pref = [0] * (len(nums) + 1)
    for i, x in enumerate(nums):
        pref[i + 1] = pref[i] + x
    return pref

# sum of nums[l:r] inclusive of l and exclusive of r
def range_sum(pref, l, r):
    return pref[r] - pref[l]
```

**3. Kadane’s Algorithm (max subarray sum)**

```python
def max_sub_array(nums):
    current = best = nums[0]
    for x in nums[1:]:
        current = max(x, current + x)
        best = max(best, current)
    return best
```

**4. Two Pointers on Sorted Array (e.g., pair sum)**

```python
def has_pair_with_sum(nums, target):
    nums.sort()
    i, j = 0, len(nums) - 1
    while i < j:
        s = nums[i] + nums[j]
        if s == target:
            return True
        elif s < target:
            i += 1
        else:
            j -= 1
    return False
```

**5. Sliding Window (fixed size, e.g., max sum of length-k subarray)**

```python
def max_sum_subarray_of_size_k(nums, k):
    window_sum = sum(nums[:k])
    best = window_sum
    for i in range(k, len(nums)):
        window_sum += nums[i] - nums[i - k]
        best = max(best, window_sum)
    return best
```

**6. Sliding Window (variable size, e.g., smallest subarray with sum ≥ target)**

```python
def min_subarray_len(target, nums):
    left = 0
    current_sum = 0
    best = float('inf')
    for right, x in enumerate(nums):
        current_sum += x
        while current_sum >= target:
            best = min(best, right - left + 1)
            current_sum -= nums[left]
            left += 1
    return 0 if best == float('inf') else best
```

```python
def move_zeroes(nums):
    insert_pos = 0
    for x in nums:
        if x != 0:
            nums[insert_pos] = x
            insert_pos += 1
    while insert_pos < len(nums):
```
