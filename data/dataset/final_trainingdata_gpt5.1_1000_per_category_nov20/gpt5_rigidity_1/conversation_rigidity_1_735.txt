1. **Two Sum**  
   Given an int array `nums` and an int `target`, return indices of the two numbers such that they add up to `target`.

```java
public int[] twoSum(int[] nums, int target) {
    Map<Integer, Integer> map = new HashMap<>();
    for (int i = 0; i < nums.length; i++) {
        int need = target - nums[i];
        if (map.containsKey(need)) return new int[]{map.get(need), i};
        map.put(nums[i], i);
    }
    return new int[0];
}
```

2. **Best Time to Buy and Sell Stock (Single Transaction)**  
   Max profit from one buy and one sell.

```java
public int maxProfit(int[] prices) {
    int min = Integer.MAX_VALUE, ans = 0;
    for (int p : prices) {
        if (p < min) min = p;
        ans = Math.max(ans, p - min);
    }
    return ans;
}
```

3. **Contains Duplicate**

public boolean containsDuplicate(int[] nums) {

4. **Valid Anagram**  
   Given two strings, check if one is an anagram of the other (assume lowercase English).

```java
public boolean isAnagram(String s, String t) {
    if (s.length() != t.length()) return false;
    int[] cnt = new int[26];
    for (int i = 0; i < s.length(); i++) {
        cnt[s.charAt(i) - 'a']++;
        cnt[t.charAt(i) - 'a']--;
    }
    for (int c : cnt) if (c != 0) return false;
    return true;
}
```

5. **Two Sum II (Sorted Array)**  
   Given sorted array, return 1-based indices of two numbers that add to target.

```java
public int[] twoSumSorted(int[] numbers, int target) {
    int l = 0, r = numbers.length - 1;
    while (l < r) {
        int sum = numbers[l] + numbers[r];
        if (sum == target) return new int[]{l + 1, r + 1};
        if (sum < target) l++; else r--;
    }
    return new int[0];
}
```

6. **Remove Duplicates from Sorted Array**  
   Return new length after removing duplicates in-place.

```java
public int removeDuplicates(int[] nums) {
    if (nums.length == 0) return 0;
    int j = 1;
    for (int i = 1; i < nums.length; i++) {
        if (nums[i] != nums[i - 1]) nums[j++] = nums[i];
    }
    return j;
}
```

7. **Valid Parentheses**  
   Given a string with `()[]{}`, determine if it is valid.

```java
public boolean isValid(String s) {
    Deque<Character> st = new ArrayDeque<>();
    for (char c : s.toCharArray()) {
        if (c == '(' || c == '{' || c == '[') st.push(c);
        else {
            if (st.isEmpty()) return false;
            char o = st.pop();
            if ((c == ')' && o != '(') ||
                (c == ']' && o != '[') ||
                (c == '}' && o != '{')) return false;
        }
    }
    return st.isEmpty();
}
```

8. **Intersection of Two Arrays II**  
   Return the intersection of two arrays, including duplicates.

```java
public int[] intersect(int[] nums1, int[] nums2) {
    Map<Integer, Integer> map = new HashMap<>();
    for (int n : nums1) map.put(n, map.getOrDefault(n, 0) + 1);
    List<Integer> res = new ArrayList<>();
    for (int n : nums2) {
        int c = map.getOrDefault(n, 0);
        if (c > 0) {
            res.add(n);
            map.put(n, c - 1);
        }
    }
    int[] ans = new int[res.size()];
    for (int i = 0; i < res.size(); i++) ans[i] = res.get(i);
    return ans;
}
```

9. **Majority Element**  
   Find the element that appears more than n/2 times.

```java
public int majorityElement(int[] nums) {
    int cand = 0, count = 0;
    for (int n : nums) {
        if (count == 0) cand = n;
        count += (n == cand) ? 1 : -1;
    }
    return cand;
}
```

10. **Longest Common Prefix**  
   Find the longest common prefix string among an array of strings.

```java
public String longestCommonPrefix(String[] strs) {
    if (strs == null || strs.length == 0) return "";
    String prefix = strs[0];
    for (int i = 1; i < strs.length; i++) {
        while (!strs[i].startsWith(prefix)) {
            prefix = prefix.substring(0, prefix.length() - 1);
            if (prefix.isEmpty()) return "";
        }
    }
    return prefix;
}
```
