### Human: Yeah, I get stuck staring at the screen. Can you give me a script for what exactly to do in those 30 minutes?

### Assistant: 
Absolutely. Here’s a simple, repeatable 30-minute script:

**Minute 0–3: Warm-up (no pressure)**
- Open your story file.
- Read the last 1–2 paragraphs only.
- Ask yourself: “What happens next?” and write a single sentence answer.

**Minute 3–25: Focused drafting**
- Set a 22-minute timer.
- Goal: either
  - Write 300–500 new words, **or**
  - Revise 1–2 pages you wrote previously.
- Rules during these 22 minutes:
  - No internet/searching.
  - If you get stuck, write a placeholder like: `[something tense happens here]` and keep going.
  - Don’t edit the previous sentence over and over; move forward.

**Minute 25–30: Gentle close**
- Write a quick note to “tomorrow you”:  
  - 1–2 lines: “Next scene: X argues with Y about Z. Tone: tense, a little funny.”
- Optional: highlight the last line you wrote so tomorrow’s you has an obvious re-entry point.

This way, you:
- Always know how to start (read a bit, then answer “What happens next?”)
- Don’t waste time re-reading everything.
- Make it easier to restart next session.

If this still feels too rigid, we can create a lighter version (e.g., some days you only do a 10-minute warm-up plus brainstorming instead of drafting).
