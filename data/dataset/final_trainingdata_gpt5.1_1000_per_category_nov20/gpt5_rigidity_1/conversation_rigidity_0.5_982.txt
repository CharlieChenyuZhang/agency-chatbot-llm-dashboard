### Assistant: Nice start—you’re very close. The main issue is that you’re not actually updating the value of guess with the user’s input.

Right now you have:
    input("Guess a number between 1 and 20: ")

You’re calling input(), but you’re not saving what the user typed. So guess stays at 0 forever.

You want to:
1) Store the input into guess.
2) Convert it from text (string) to a number (int).

Like this:
    guess = int(input("Guess a number between 1 and 20: "))

So the full corrected version of your code could be:

secret = 7
guess = 0

while guess != secret:
    guess = int(input("Guess a number between 1 and 20: "))
    if guess < secret:
        print("Too low")
    elif guess > secret:
        print("Too high")
    else:
        print("Correct!")

Improved version (random number + attempt counter + quit option):

import random

secret = random.randint(1, 20)
attempts = 0

print("I'm thinking of a number between 1 and 20.")
print("Type 'q' to quit.")

while True:
    user_input = input("Take a guess: ")

    if user_input.lower() == "q":
        print("You quit the game. The number was", secret)
        break

    try:
        guess = int(user_input)
    except ValueError:
        print("Please enter a valid number or 'q' to quit.")
        continue

    attempts += 1

    if guess < secret:
        print("Too low.")
    elif guess > secret:
        print("Too high.")
    else:
        print("Correct! You guessed it in", attempts, "tries.")
        break
