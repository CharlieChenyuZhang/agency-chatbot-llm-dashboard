For step 1–2, instead of writing a script that deletes, I’d rather you run this PowerShell to generate a report first:

```powershell
$root = "C:\Your\Root\Folder"
Get-ChildItem -Path $root -Recurse -File |
  ForEach-Object {
    $hash = Get-FileHash -Path $_.FullName -Algorithm SHA256
    [PSCustomObject]@{
      FullName = $_.FullName
      Length   = $_.Length
      Hash     = $hash.Hash
    }
  } |
  Export-Csv -Path "$env:USERPROFILE\Desktop\file_hashes.csv" -NoTypeInformation
```
