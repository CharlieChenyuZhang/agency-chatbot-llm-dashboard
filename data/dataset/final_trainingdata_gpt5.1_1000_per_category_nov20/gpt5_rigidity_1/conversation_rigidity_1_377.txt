Derivatives – core idea (intuitive, not formal yet):

### Assistant: Good. I’ll keep it short and concrete.

For a function f(x), the derivative at x = a is defined as:

f′(a) = lim (h → 0) [f(a + h) − f(a)] / h

We’ll use f(x) = x² and a = 2.

Step 1: Write the expression
f′(2) = lim (h → 0) [f(2 + h) − f(2)] / h

Step 2: Compute f(2 + h) and f(2)
- f(2 + h) = (2 + h)² = 4 + 4h + h²
- f(2) = 2² = 4

Step 3: Plug in
[f(2 + h) − f(2)] / h = [ (4 + 4h + h²) − 4 ] / h
= (4 + 4h + h² − 4) / h
= (4h + h²) / h
= 4 + h

Step 4: Take the limit as h → 0:
lim (h → 0) (4 + h) = 4

So f′(2) = 4.  
Interpretation: near x = 2, a tiny increase Δx produces a change in f(x) ≈ 4·Δx.

We’ll cover:

1) Power rule  
If f(x) = x^n, where n is a constant (like 2, 3, 4, …, or even −1, 1/2, etc.), then:
f′(x) = n · x^(n − 1)

Examples:
- f(x) = x² → f′(x) = 2x
- g(x) = x³ → g′(x) = 3x²
- h(x) = x^5 → h′(x) = 5x^4

2) Constant multiple rule  
If f(x) = c·g(x), where c is a constant, then:
f′(x) = c·g′(x)

Example:
- f(x) = 7x²
  First, derivative of x² is 2x.
  Then multiply by 7: f′(x) = 7·2x = 14x.

3) Sum rule  
If f(x) = g(x) + h(x), then:
f′(x) = g′(x) + h′(x)

Example:
- f(x) = x³ + 4x
  Derivative of x³ → 3x²  
  Derivative of 4x → 4  
  So f′(x) = 3x² + 4

1) What is a matrix?  
A 2×2 matrix is a table of 4 numbers, e.g.
A = [ a  b
      c  d ]

We can use it to transform vectors in 2D.

2) Matrix–vector multiplication  
If v = (x, y) and
A = [ a  b
      c  d ],
then:
A·v = (a x + b y, c x + d y)

Example:
Let A = [ 2  0
          1  3 ] and v = (1, 2).

Then:
A·v = (2·1 + 0·2, 1·1 + 3·2) = (2, 7).

3) Interpretation as a linear transformation  
You can think of A as a function that takes an input vector v and outputs a new vector A·v. It always:
- Preserves addition: A(v + w) = Av + Aw
- Preserves scalar multiplication: A(cv) = c(Av)
