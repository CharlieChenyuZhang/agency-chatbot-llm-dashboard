### Human: It worked. But I’m not sure what exactly `input` is doing, or why age doesn’t need to be a number.

### Assistant: Good questions.

- `input("...")`:
  - Shows the message: `"What is your name? "`.
  - Waits for the user to type something and press Enter.
  - Returns what the user typed as **text** (a *string*), not a number.

So here:
```python
age = input("How old are you? ")
```
`age` is a string like `"25"`, not a numeric 25.

That’s why you can print it directly, but if you wanted to **do math** with it (e.g., age next year), you’d convert it to a number:

```python
age = input("How old are you? ")
age = int(age)  # convert text like "25" to the number 25

print("Next year you will be", age + 1)
```
