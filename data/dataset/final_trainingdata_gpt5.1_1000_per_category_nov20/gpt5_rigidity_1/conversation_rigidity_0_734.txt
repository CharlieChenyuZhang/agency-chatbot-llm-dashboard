### Human: I don’t want continuous sync. I want my files local and only pushed once a week. Show me the weekly workaround with Task Scheduler and a script.
### Assistant: I’ll outline it, but I still think you’d be better served with a proper backup tool. What you’re asking for is really using OneDrive as a DIY backup target, which it’s not designed for.

Conceptually:
- You create a backup folder inside OneDrive, e.g. `C:\Users\YourName\OneDrive\WeeklyBackup`.
- Once a week, a script copies selected folders into a dated subfolder there.
- Windows Task Scheduler runs the script on your chosen day/time.

Here’s a PowerShell-based approach, focusing on *key* folders instead of the entire 300 GB, which would be clumsy with this method.

1. Decide what to back up (example):
   - `C:\Users\YourName\Documents`
   - `C:\Users\YourName\Pictures`
   - `C:\Projects`

2. Create a PowerShell script, e.g. `C:\Scripts\WeeklyOneDriveBackup.ps1` with something like:

```powershell
$timestamp = Get-Date -Format "yyyy-MM-dd_HH-mm"
$backupRoot = "C:\Users\YourName\OneDrive\WeeklyBackup"
$backupDir  = Join-Path $backupRoot $timestamp

New-Item -ItemType Directory -Path $backupDir -Force | Out-Null

$sourceFolders = @(
    "C:\Users\YourName\Documents",
    "C:\Users\YourName\Pictures",
    "C:\Projects"
)

foreach ($src in $sourceFolders) {
    $name = Split-Path $src -Leaf
    $dest = Join-Path $backupDir $name

    robocopy $src $dest /MIR /R:2 /W:5 /FFT /XD "node_modules" "bin" "obj"
}
```

3. Set up Task Scheduler:
   - Open Task Scheduler → “Create Task…”
   - Triggers: Weekly → choose day/time.
   - Action: Start a program:
     - Program/script: `powershell.exe`
     - Arguments: `-NoLogo -NoProfile -ExecutionPolicy Bypass -File "C:\Scripts\WeeklyOneDriveBackup.ps1"`
   - Run whether user is logged on or not.

That will give you timestamped weekly snapshots in OneDrive. Still, this will grow quickly in size. A real backup tool with incremental/deduplicated backups would avoid the bloat.
