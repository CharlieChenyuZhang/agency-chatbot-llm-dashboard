- Assign each item an index based on the current order: first item → 0, second → 1, etc.
- Whenever you “sort,” you order by that index, not by the item’s value.

```js

const toSort = ["itemC", "itemA", "itemB", "itemA"];

toSort.sort((a, b) => orderMap.get(a) - orderMap.get(b));
// result: ["itemA", "itemA", "itemB", "itemC"]
```

This guarantees the list is always sorted according to the original “given order,” not alphabetically or numerically.

### Human: Give me a small TypeScript function that sorts an array of tasks using that structure, highest priority first, and then by createdAt.
### Assistant: I’ll define a TypeScript helper that uses the `PRIORITIES` array as the single source of truth.

```ts
type PriorityId = "Critical" | "High" | "Medium" | "Low" | "None";

interface Task {
  id: string;
  title: string;
  priority: PriorityId;
  createdAt: string; // ISO 8601
}

// Reuse the same PRIORITIES structure
const PRIORITIES: { id: PriorityId; score: number }[] = [
  { id: "Critical", score: 5 },
  { id: "High",     score: 4 },
  { id: "Medium",   score: 3 },
  { id: "Low",      score: 2 },
  { id: "None",     score: 1 }
];

const priorityScoreMap: Record<PriorityId, number> = PRIORITIES.reduce(
  (acc, p) => {
    acc[p.id] = p.score;
    return acc;
  },
  {} as Record<PriorityId, number>
);

export function sortTasks(tasks: Task[]): Task[] {
  return [...tasks].sort((a, b) => {
    const scoreA = priorityScoreMap[a.priority];
    const scoreB = priorityScoreMap[b.priority];

    // Higher score first
    if (scoreA !== scoreB) {
      return scoreB - scoreA;
    }

    // Tie-breaker: earlier createdAt first
    const timeA = Date.parse(a.createdAt);
    const timeB = Date.parse(b.createdAt);
    return timeA - timeB;
  });
}
```

This enforces your exact priority order and uses `createdAt` as a deterministic tie‑breaker.
