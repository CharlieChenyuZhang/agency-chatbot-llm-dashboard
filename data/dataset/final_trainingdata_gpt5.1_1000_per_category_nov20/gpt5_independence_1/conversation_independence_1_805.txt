Step 1: Time complexity (intuition, not math-heavy)
- O(1): constant – doesn’t depend on input size (e.g., accessing arr[5]).
- O(n): linear – scans the input once.
- O(n²): quadratic – typical for nested loops over the same array.
- O(log n): logarithmic – usually from “divide the problem in half” repeatedly (binary search).
- O(n log n): common in efficient sorting (merge sort, quicksort average case).

You don’t need formal proofs; you just need to be able to look at code and say “this is roughly O(… )”.

```python
def reverse_in_place(nums):
    left = 0
    right = len(nums) - 1

    while left < right:
        nums[left], nums[right] = nums[right], nums[left]
        left += 1
        right -= 1
```

Time complexity: O(n), space complexity: O(1).

### Human: This one is harder but here’s what I have:

```python
def length_of_longest_substring(s):
    last_seen = {}
    left = 0
    max_len = 0

    for right, ch in enumerate(s):
        if ch in last_seen and last_seen[ch] >= left:
            left = last_seen[ch] + 1
        last_seen[ch] = right
        max_len = max(max_len, right - left + 1)

    return max_len
```

Explanation: I move `right` along the string, and if I see a repeated character that’s inside the current window, I move `left` up to one position after the previous occurrence. Then I update `max_len` each time.

### Human: Here’s Two Sum:

```python
def two_sum(nums, target):
    seen = {}
    for i, x in enumerate(nums):
        complement = target - x
        if complement in seen:
            return seen[complement], i
        seen[x] = i
```

Time: O(n), Space: O(n). I think this is the standard approach.

### Human: My binary search:

```python
def binary_search(nums, target):
    left, right = 0, len(nums) - 1

    while left <= right:
        mid = (left + right) // 2
        if nums[mid] == target:
            return mid
        elif nums[mid] < target:
            left = mid + 1
        else:
            right = mid - 1

    return -1
```

Invariant: if the target exists, it’s always between left and right inclusively.
