**Projects**

2) Build the Home dashboard

Create a page called:  
**Home**

Inside Home, add the following:

A. “Today” tasks view
- Add a linked view of the **Tasks** database.
- Name the view: **Today**
- Filter:
  - Status is not Done
  - Due Date is on or before today
- Sort:
  - By Due Date (ascending)
  - Then by Priority (High → Low)

B. “Next Actions” view
- Add another linked view of **Tasks**.
- Name it: **Next Actions**
- Filter:
  - Status is To Do or Doing
  - Due Date is empty OR due in the next 7 days
- Sort:
  - Priority (High → Low)
  - Then Due Date (ascending)

C. “Active Projects” view
- Add a linked view of **Projects**.
- Name it: **Active Projects**
- Filter:
  - Status is Active
- Show as a Board or Table.

D. “Recent Notes” view
- Add a linked view of **Notes**.
- Name it: **Recent Notes**
- Sort by:
  - Last edited time (descending)
- Limit the view to, say, last 14 days with a filter on “Last edited time”.

3) Quick capture setup

A. Task quick capture
In **Tasks**:
- Create a template called: **Quick Task**
  - Default properties:
    - Status: To Do
    - Area: Personal (you can change per task)
    - Priority: Medium

You’ll use this template to quickly add tasks from anywhere.

B. Note quick capture
In **Notes**:
- Create a template called: **Quick Note**
  - Type: Idea

4) Project workflow

When you start a new project:
1) Go to **Projects** and create a new item.
2) Fill:
   - Title = project name
   - Status = Active
   - Area = Work or Personal
   - Goal / Outcome = clear description
3) In that project page:
   - Use the **Related Tasks** relation to add/browse its tasks.
   - Use the **Related Notes** relation to add/browse its notes.

This creates a hub for each project: tasks + notes together.

---

5) Daily use pattern

Morning:
- Open **Home → Today** to see what’s due.
- Pick 3–5 tasks and set Status to Doing.
- If new tasks come to mind, add them directly to **Tasks** using the **Quick Task** template.

During the day:
- Work from **Today** and **Next Actions** views.
- Take meeting notes directly into **Notes**, link them to a **Project**.

Evening:
- In **Tasks**, quickly set:
  - Done for finished tasks
  - Adjust Due Date for anything overdue
- In **Projects**, set any finished project’s Status to Completed.

This structure will handle both tasks and notes cleanly and stay maintainable.
