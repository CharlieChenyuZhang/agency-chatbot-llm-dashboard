### How to clean up your current Desktop using this

1. **Create the folders above** exactly as named.
2. **Sweep everything into `_INBOX` first.**
   - Select all loose files and folders on your desktop.
   - Move into `_INBOX`. Now your desktop is visually clear.
3. **Process `_INBOX` once.**
   - Documents for work → appropriate `Work` subfolder.
   - Personal stuff (IDs, bills, letters) → `Personal` subfolders.
   - PDFs/manuals you only reference → `Reference`.
   - Old/zipped projects you rarely use → `Archive`.
   - App installers (.dmg, .exe) → keep only what’s needed in `System_Utilities/Tools`, otherwise delete.
4. **Adopt a naming pattern**:
   - `YYYY-MM-DD_Keyword_MoreWords.ext` for anything time-specific.
   - For versions: `ProjectName_v01.ext`, `v02`, etc.
5. **New rule going forward**:
   - All new stuff lands in `_INBOX`.
   - You clear `_INBOX` once per day (or at least once per week), moving items into their permanent homes.

This layout keeps the desktop visually clean but still practical: one “messy” spot (`_INBOX`) plus well-defined permanent homes for everything else.

#### 2. Backup strategy
- If you use a cloud service (e.g., OneDrive, iCloud Drive, Dropbox, Google Drive sync):
  - Put `Workspace` inside the sync folder:
    - `CloudService/Workspace/...`
- If you use an external drive:
  - Create `Backup/Workspace/` on the drive.
  - Back up the entire `Workspace` directory regularly (manual or automated).

With this:
- The taxonomy you’re using is identical locally and in backup.
- Restoring or moving to a new machine becomes simply copying the `Workspace` folder and re-creating a few Desktop shortcuts.
