**Step 1 – Create the main page**

---

**Step 2 – Create the key databases**

You’ll make 4 main databases inside this page:

1. **Clients**
2. **Projects**
3. **Finances**
4. **Content Ideas**

Do this:

1. Type “/table full” and select **“Table – Full page”**.
2. Name it **Clients**.
3. In the sidebar, drag the “Clients” database so it sits under your main Command Center page.

Now add these columns:

- Title (already there): rename to **Client Name**
- Add property:
  - Type: Email – name it **Email**
- Add property:
  - Type: Phone – name it **Phone**
- Add property:
  - Type: Select – name it **Status**  
    Options: Lead, Active, Past, Cold
- Add property:
  - Type: Date – name it **Last Contact**
- Add property:
  - Type: Text – name it **Next Step**
- Add property:
  - Type: Number – name it **Estimated Value ($)**

Repeat the process to create **Projects** (another “Table – Full page”):

Columns:

- Title: rename to **Project Name**
- Relation:
  - Type: Relation  
  - Link it to the **Clients** database  
  - Name it **Client**
- Date: **Start Date**
- Date: **Due Date**
- Select: **Status**  
  Options: Planned, In Progress, Waiting, Done, Canceled
- Number: **Project Fee ($)**
- Text: **Deliverables**
- Checkbox: **Invoice Sent**

Create **Finances**:

Columns:

- Title: rename to **Entry**
- Select: **Type** (Income, Expense)
- Number: **Amount**
- Date: **Date**
- Relation to **Clients** (optional)
- Text: **Category**
- Text: **Notes**

Create **Content Ideas**:

Columns:

- Title: **Idea**
- Select: **Platform** (Twitter, LinkedIn, Blog, Newsletter, Other)
- Select: **Status** (Idea, Draft, Scheduled, Posted)
- Date: **Target Date**
- Text: **Notes**

---

**Step 3 – Build the Command Center dashboard**

Go back to the **Freelancer Command Center** main page.

You’ll now *link* those databases into this page:

1. Type “/linked” and choose **“Create linked view of database”**.
2. Choose **Projects**.
3. You’ll now see a table of your Projects inside the main page.

Create these sections:

**Section A – Today & This Week**

1. Add a heading: “Today”
2. Under it, insert a linked **Projects** view:
   - Click on the three dots (…) of the table > **Filter**
   - Add filter:
     - Where **Due Date** is **on or before** today  
     - And **Status** is not **Done**
   - Sort by **Due Date ascending**
3. Duplicate this view, rename it “This Week”, change filter:
   - Due Date is **within the next week**

**Section B – Clients**

1. Heading: “Active Clients”
2. Add linked **Clients** view.
3. Filter:
   - Status is **Active** OR **Lead**
4. Sort:
   - By **Last Contact** (oldest first) so you see who you’re neglecting.

**Section C – Money**

1. Heading: “Finances Overview”
2. Add linked **Finances** view.
3. Change view type to **Board** if you like, grouped by **Type**, or keep as table.
4. Add a **“Sum”** at the bottom of **Amount** so you can see monthly totals (Group by month via a “Month” formula later if you want; for now, keep it simple).

**Section D – Content**

1. Heading: “Content Pipeline”
2. Add linked **Content Ideas** view.
3. Change to **Board view**, grouped by **Status** (Idea, Draft, Scheduled, Posted).
