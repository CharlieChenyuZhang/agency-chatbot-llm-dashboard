**Title**
Build fails on CI due to Node.js version mismatch

**Body**
Our Node.js project build is failing on GitHub Actions due to a Node.js version mismatch between local development and CI.

---

### Steps to Reproduce
1. Push a commit to any active branch or open a pull request.
2. Let the GitHub Actions workflow run automatically.
3. Observe that the build job fails during the `npm run build` or `npm test` step.

---

### Expected Behavior
- The GitHub Actions workflow should use the same Node.js version as required by the project (Node 16) and complete successfully.

### Actual Behavior
- Local environment uses Node 16 and builds/tests pass.
- GitHub Actions runner is configured (or defaulting) to Node 18.
- The build fails on CI with a version-related error.

---

### Logs (CI)
Relevant excerpt:
```text
Run npm run build
> app@1.0.0 build
> react-scripts build

Error: This project requires Node.js 16.x. Current version: v18.x.x
Please switch to Node.js 16 and try again.
npm ERR! code ELIFECYCLE
npm ERR! errno 1
npm ERR! app@1.0.0 build: `react-scripts build`
npm ERR! Exit status 1
```

---

### Environment
- CI: GitHub Actions (Ubuntu runner, e.g., `ubuntu-latest`)
- Node on CI: 18.x (current)
- Node required by project: 16.x
- Local: Node 16.x, build/test succeed

---

### Root Cause
- GitHub Actions is running the workflow with Node 18, while the project and/or tooling explicitly require Node 16.
- This mismatch causes the build to fail on CI, even though it passes locally.

---

### Proposed Fix
1. **Pin Node.js to 16 in GitHub Actions workflow**  
   In `.github/workflows/<workflow>.yml`, ensure the `setup-node` step specifies Node 16:
   ```yaml
   - name: Use Node.js 16
     uses: actions/setup-node@v4
     with:
       node-version: '16.x'
   ```
2. **Align documentation and config**  
   - Update `engines` in `package.json` if needed:
     ```json
     "engines": {
       "node": "16.x"
     }
     ```
   - Document Node 16 as the required version in the README / contributor docs.

3. **Optional: plan Node 18 upgrade**  
   - If Node 18 support is desired, create a follow-up task to:
     - Audit dependencies for Node 18 compatibility.
     - Test locally and on a separate CI job.
     - Update `engines`, workflows, and runtime environments together.

---

### Requested Action
- Update the GitHub Actions workflow to use Node 16.x.
- Verify that builds and tests pass on CI after the change.
- Align documentation and configs so local and CI environments are consistent.
