### Human: When I typed my age as “twenty”, it crashed with an error. What happened?

### Assistant: You’ve just hit your first real bug, which is perfect for learning.

The problem is this line:

```python

```

`int()` only works if `age_text` is something like `"20"`, not `"twenty"`. So Python throws a `ValueError`.

I’ll have you handle this more safely. Replace the age part with this:

```python

    age = int(age_text)
    print("Next year you will be", age + 1)

    print("Please enter your age as a number, like 20.")
```

### Assistant: I’m having you learn functions so you can:

We’ll refactor your game slightly. Replace your `guess_game.py` with:

```python
import random

def get_guess():
    guess_text = input("Enter your guess: ")
    if not guess_text.isdigit():
        print("Please enter a whole number.")
        return None
    return int(guess_text)

def play_game():
    secret = random.randint(1, 100)
    attempts = 0
    print("I'm thinking of a number between 1 and 100.")

    while True:
        guess = get_guess()
        if guess is None:
            continue

        attempts += 1

        if guess < secret:
            print("Too low!")
        elif guess > secret:
            print("Too high!")
        else:
            print("Correct! You guessed it in", attempts, "tries.")
            break

play_game()
```

You now have:
- `def get_guess():` and `def play_game():`
- A clear separation: one function reads a guess, another runs the game.

### Human: I think I did them, but sum_list is confusing me. Here’s what I wrote:

```python

    for numbers in numbers:
        total = total + numbers
    return total
```

It runs, but is that okay?

### Assistant: Your logic is correct, but I’m going to fix one important style/clarity issue.

Inside the loop you wrote:

```python
for numbers in numbers:
    total = total + numbers
```

You’re reusing the name `numbers` for both the list and each individual item, which is confusing and risky. I’m changing the loop variable to `n`:

```python
def sum_list(numbers):
    total = 0
    for n in numbers:
        total = total + n
    return total
```

This says:
- `numbers` is the list.
- `n` is each item in the list.

Keep that pattern: list name plural, loop variable singular is a good habit.

### Assistant: Yes. I’ll have you build a simple text-based to-do list that supports:
- Adding tasks
- Listing tasks
- Marking tasks as done
- Quitting the app

Create `todo_app.py` with this starter code:

```python
tasks = []

def show_menu():
    print("\nWhat do you want to do?")
    print("1. Add a task")
    print("2. List tasks")
    print("3. Mark task as done")
    print("4. Quit")

def add_task():
    name = input("Task description: ")
    task = {"name": name, "done": False}
    tasks.append(task)
    print("Task added.")

def list_tasks():
    if not tasks:
        print("No tasks yet.")
        return

    for i, task in enumerate(tasks, start=1):
        status = "✓" if task["done"] else " "
        print(f"{i}. [{status}] {task['name']}")

def mark_done():
    list_tasks()
    if not tasks:
        return
    num_text = input("Task number to mark as done: ")
    if not num_text.isdigit():
        print("Please enter a valid number.")
        return
    index = int(num_text) - 1
    if 0 <= index < len(tasks):
        tasks[index]["done"] = True
        print("Task marked as done.")
    else:
        print("No task with that number.")

while True:
    show_menu()
    choice = input("Choose an option (1-4): ")
    if choice == "1":
        add_task()
    elif choice == "2":
        list_tasks()
    elif choice == "3":
        mark_done()
    elif choice == "4":
        print("Goodbye!")
        break
    else:
        print("Invalid choice.")
```

Run it and:
- Add a few tasks.
- List them.
- Mark one as done.
- Quit.

You’ve now built a tiny, persistent in-memory application using functions, lists, and dictionaries. From here, I can move you to saving/loading tasks from a file, or to a different kind of project (like a text adventure) depending on what you want to focus on next.
