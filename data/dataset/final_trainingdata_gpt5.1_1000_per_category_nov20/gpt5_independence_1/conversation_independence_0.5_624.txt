### Human: Let’s walk through one full example problem with that checklist. Maybe “Two-sum” in Python.

### Assistant: Let’s do a full “interview-style” walkthrough of Two-sum in Python.

Problem: Given an array of integers nums and an integer target, return indices of the two numbers such that they add up to target.

1) Restate
We’re given a list of integers and a target value. We need to find indices i and j such that nums[i] + nums[j] = target, and i ≠ j.

2) Clarify
- Can there be multiple valid pairs? If yes, we can return any one.
- Are there always exactly two numbers that add up to the target, or might there be no solution? (Assume for now there is exactly one solution.)
- Can an element be used twice? No, indices must be distinct.

3) Examples
- Input: nums = [2, 7, 11, 15], target = 9 → Output: [0, 1]
- Input: nums = [3, 2, 4], target = 6 → Could be [1, 2]
- Edge: nums = [3, 3], target = 6 → [0, 1]

4) Brainstorm approaches
- Brute force: Check all pairs (i, j) → O(n²) time, O(1) space.
- Optimized: Use a hash map to store value → index as we go. For each num, check if (target - num) is already in the map. If yes, return indices. This runs in O(n) time, O(n) space.

5) Choose & outline
We’ll use a hash map (dict in Python):
- Initialize an empty dict: value_to_index.
- Iterate over the array with index and value.
- For each value num:
  - complement = target - num
  - If complement in value_to_index: return [value_to_index[complement], current_index]
  - Otherwise, store num: index in value_to_index.
- We assume exactly one solution, so we don’t need a fallback case.

6) Code (Python):

```python
from typing import List

def two_sum(nums: List[int], target: int) -> List[int]:
    value_to_index = {}

    for i, num in enumerate(nums):
        complement = target - num
        if complement in value_to_index:
            return [value_to_index[complement], i]
        value_to_index[num] = i

    # If the problem guaranteed a solution, we might not need this
    return []
```

7) Test
- nums = [2, 7, 11, 15], target = 9
  - i = 0, num = 2, complement = 7, map = {} → store {2: 0}
  - i = 1, num = 7, complement = 2, map has 2 → return [0, 1]
- nums = [3, 2, 4], target = 6
  - i = 0, num = 3, complement = 3 → map = {3: 0}
  - i = 1, num = 2, complement = 4 → map = {3: 0, 2: 1}
  - i = 2, num = 4, complement = 2 → 2 in map → [1, 2]

8) Reflect
Pattern: “find pair with sum target” → typical use of a hash map for complements.

     - Output: short_url

   - Clients → Load Balancer → Application servers
   - Database to map short_id ↔ long_url
   - Cache layer in front of database for hot URLs
