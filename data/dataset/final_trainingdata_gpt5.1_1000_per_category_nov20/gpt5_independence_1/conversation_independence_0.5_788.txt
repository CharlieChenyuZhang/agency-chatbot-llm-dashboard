Let me start with a compact **Big-O refresher**, tuned for interviews:

**1. Time Complexity Intuition**
- O(1): Constant time – does the same amount of work regardless of input size.
  - Example: Accessing `arr[i]`, checking `len(arr)`, dictionary lookup on average.
- O(log n): Work grows slowly as input grows, often from **divide-and-conquer**.
  - Example: Binary search.
- O(n): Work grows proportionally with input size.
  - Example: Single loop through an array once.
- O(n log n): Typical for efficient sorting algorithms (merge sort, quicksort average).
- O(n²): Nested loops over the same input.
  - Example: Checking all pairs in an array.

**2. Space Complexity**
- Measures how much extra memory your algorithm uses (ignoring input storage).
- Typical patterns: O(1) extra (in-place), O(n) extra (using aux arrays/hash maps).

class Stack:
    def __init__(self):
        self._data = []

    def push(self, x):
        self._data.append(x)

    def pop(self):
        if self.is_empty():
            # For interviews, you'd usually specify behavior;
            # I'll return None here for emptiness.
            return None
        return self._data.pop()

    def peek(self):
        if self.is_empty():
            return None
        return self._data[-1]

    def is_empty(self):
        return len(self._data) == 0

**Problem (simplified):**  
Given a string `s` containing only `'('`, `')'`, `'{'`, `'}'`, `'['`, `']'`, determine if the input string is valid.  
A string is valid if:
- Open brackets are closed by the same type of brackets.
- Open brackets are closed in the correct order.

**Core idea (why stack?):**
- Validity depends on **last unclosed opening bracket** → LIFO → stack.
- When we see an opening bracket, we **push** it.
- When we see a closing bracket, it must match the **top** of the stack; if it doesn’t, invalid.

**Algorithm:**
1. Create an empty stack.
2. For each char `c` in the string:
   - If `c` is an opening bracket: push it onto the stack.
   - If `c` is a closing bracket:
     - If stack is empty → invalid (nothing to match with).
     - Pop the top; check if the type matches (`(` with `)`, `[` with `]`, `{` with `}`).
     - If it doesn’t match → invalid.
3. After processing all chars:
   - If the stack is empty → valid.
   - Otherwise → invalid (some opening brackets weren’t closed).

```python
def isValid(s: str) -> bool:
    stack = []
    pairs = {')': '(', ']': '[', '}': '{'}

    for c in s:
        if c in pairs.values():
            stack.append(c)
        else:
            if not stack:
                return False
            top = stack.pop()
            if pairs.get(c) != top:
                return False

    return len(stack) == 0
```
