Here’s an intuitive idea of a **limit**:

- Think of a function \( f(x) \) and a point \( x = a \).
- Sometimes we care less about the value at \( x = a \) itself, and more about what values \( f(x) \) is *approaching* as \( x \) gets very close to \( a \) (from both sides).
- The **limit** of \( f(x) \) as \( x \to a \) is the value that \( f(x) \) gets closer and closer to, even if:

### Assistant: Great, we’ll connect limits to derivatives now. I’ll start with the geometric idea, then show the limit formula, keeping it as gentle as possible. If anything feels too dense, we can pause and reshape it. Is that okay?

Geometric idea:

- Suppose you have a function \( y = f(x) \).
- The **derivative at a point** \( x = a \) is the **slope of the tangent line** to the graph at that point.
- To get that slope, we first look at the slope between two nearby points, then let those points get *infinitely close*—and that “letting them get close” is done using a **limit**.

Algebraically, we start with the **difference quotient**:
\[
\frac{f(a + h) - f(a)}{h}
\]
This is the slope of the line between \( x = a \) and \( x = a + h \). Then we take the limit as \( h \to 0 \):
\[
f'(a) = \lim_{h \to 0} \frac{f(a + h) - f(a)}{h}
\]

So, the derivative is defined **as a limit** of these average slopes as the two points merge into one.

The most important basic derivative rules (informal version):

1. **Power rule**:  
   If \( f(x) = x^n \) (where \( n \) is a real number like 2, 3, 1/2, etc.), then  
   \[
   f'(x) = nx^{n-1}.
   \]

2. **Constant multiple rule**:  
   If \( f(x) = c \cdot g(x) \), then  
   \[
   f'(x) = c \cdot g'(x).
   \]

3. **Sum rule**:  
   If \( f(x) = g(x) + h(x) \), then  
   \[
   f'(x) = g'(x) + h'(x).
   \]

Using these, you can, for example, differentiate:
\[
f(x) = 3x^2 + 5x - 7
\]
by applying the rules term-by-term.

For two vectors in 2D or 3D (or higher dimensions),
