Next, you need solid intuition about arrays vs linked lists, because this underpins many later choices.

I’ll define them and then give you a comparison table to memorize.

Arrays (Python list behaves like a dynamic array conceptually):
- Contiguous block of memory.
- Fast random access: a[i] is O(1).
- Insert/delete in the middle: O(n) because elements need shifting.

Singly linked list:
- Each node holds data + pointer to next node.
- Not stored contiguously.
- Accessing the k-th element requires walking from the head: O(k).
- Insert/delete at head: O(1); in the middle: O(1) if you already have the node, but O(n) to find it.

You will store this mental table:

- Access by index:
  - Array: O(1)
  - Linked list: O(n)
- Insert/delete at end:
  - Array (amortized dynamic array): O(1) average
  - Linked list (with tail pointer): O(1)
- Insert/delete at beginning:
  - Array: O(n)
  - Linked list: O(1)

### Human: Can you show me a clean implementation of that singly linked list in Python so I can compare?

### Assistant: Here is a straightforward, clear implementation you can use as a reference and then modify or retype yourself:

```python
class Node:
    def __init__(self, value, next=None):
        self.value = value
        self.next = next


class SinglyLinkedList:
    def __init__(self):
        self.head = None

    def prepend(self, value):
        new_node = Node(value, self.head)
        self.head = new_node

    def append(self, value):
        new_node = Node(value)
        if self.head is None:
            self.head = new_node
            return
        curr = self.head
        while curr.next is not None:
            curr = curr.next
        curr.next = new_node

    def find(self, value):
        curr = self.head
        while curr is not None:
            if curr.value == value:
                return curr
            curr = curr.next
        return None

    def delete(self, value):
        if self.head is None:
            return

        # If the head needs to be removed
        if self.head.value == value:
            self.head = self.head.next
            return

        prev = self.head
        curr = self.head.next
        while curr is not None:
            if curr.value == value:
                prev.next = curr.next
                return
            prev, curr = curr, curr.next

    def __iter__(self):
        curr = self.head
        while curr is not None:
            yield curr.value
            curr = curr.next

    def __repr__(self):
        return "->".join(str(v) for v in self)
```

Use it as a reference, but re-implement it yourself to internalize the logic.

Next, I’m advancing you to binary search, because it’s the canonical example of:
- Using sorted arrays efficiently
- Practicing divide & conquer and thinking in O(log n)

Concept summary: Binary search on a sorted array
- Keep low and high indices.
- Compute mid.
- Compare target to arr[mid].
  - If equal: return mid.
  - If target < arr[mid]: search left half.
  - Else: search right half.
- Stop when low > high (not found).
