### Human: Here's my attempt.

Idea:
- Use a sliding window with two pointers, `left` and `right`.
- Maintain a set of characters currently in the window.
- Move `right` forward; if `s[right]` is not in the set, add it and update max length.
- If `s[right]` is already in the set, move `left` forward, removing chars from the set until `s[right]` is no longer in the set.
- Complexity: O(n) time, O(min(n, alphabet)) space.

Code:

```python
def lengthOfLongestSubstring(s: str) -> int:
    char_set = set()
    left = 0
    max_len = 0

    for right in range(len(s)):
        while s[right] in char_set:
            char_set.remove(s[left])
            left += 1
        char_set.add(s[right])
        max_len = max(max_len, right - left + 1)
    return max_len
```
