3. Change **Next Follow-up** to a **Formula** property (instead of Date):
   - Click on “Next Follow-up” → **Property type: Formula**.

4. Use this formula:

```notion
if(
  empty(prop("Last Contacted")) or prop("Contact Frequency") = "Ad hoc",
  "",
  if(
    prop("Contact Frequency") = "Every week",
    dateAdd(prop("Last Contacted"), 1, "weeks"),
    if(
      prop("Contact Frequency") = "Every 2 weeks",
      dateAdd(prop("Last Contacted"), 2, "weeks"),
      if(
        prop("Contact Frequency") = "Every 1 month",
        dateAdd(prop("Last Contacted"), 1, "months"),
        if(
          prop("Contact Frequency") = "Every 3 months",
          dateAdd(prop("Last Contacted"), 3, "months"),
          if(
            prop("Contact Frequency") = "Every 6 months",
            dateAdd(prop("Last Contacted"), 6, "months"),
            if(
              prop("Contact Frequency") = "Yearly",
              dateAdd(prop("Last Contacted"), 1, "years"),
              ""
            )
          )
        )
      )
    )
  )
)
```

This will:
- Leave **Next Follow-up** blank if there’s no Last Contacted or frequency is Ad hoc.
- Otherwise, automatically set a follow-up date.
