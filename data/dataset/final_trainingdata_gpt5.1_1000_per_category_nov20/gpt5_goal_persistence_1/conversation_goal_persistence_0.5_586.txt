### Human: It prints “x is 3” and “y is 5”. I guess Python sees that x is 3 so it does 3 + 2 and stores it in y. But I still don’t really get what a variable *is*.
### Assistant: That’s a good description already; let’s sharpen the mental model.

Think of a variable as:
- A **labeled box in memory**.
- The label is the variable name (`x`, `y`).
- The thing inside the box is the value (3, 5, etc.).

When you write:
```python
x = 3
```
you’re saying “create a box labeled `x` and put the number 3 inside.”

When you write:
```python
y = x + 2
```
Python:
1) Looks inside the `x` box (sees 3).
2) Adds 2 → gets 5.
3) Creates a box labeled `y` and puts 5 inside.

To check this idea, change your code to:


### Human: I thought x would be 99 and y would be 101, but it printed x is 99 and y is 12. That’s weird.
### Assistant: This is actually a great moment for learning.

What happened:
1) `x = 10` → box `x` holds 10.
2) `y = x + 2` → looks at `x` (10), adds 2, puts 12 in box `y`.
3) `x = 99` → changes the value in the `x` box, but `y` still has 12; Python doesn’t “link” them automatically.

So:
- A variable stores a *value at a moment in time*.
- Later changes to other variables don’t retroactively change old calculations.
