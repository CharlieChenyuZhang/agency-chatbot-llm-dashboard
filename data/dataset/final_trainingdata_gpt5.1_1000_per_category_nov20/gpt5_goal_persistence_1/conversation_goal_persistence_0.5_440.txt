        mid = (left + right) // 2

            return True
        elif nums[mid] < target:

        else:

### Assistant: Sure, recursion is a big one, and factorial is a classic starting point.

Core idea of recursion:
1. A function calls **itself**.
2. You need:
   - A **base case**: when to stop.
   - A **recursive case**: how to make the problem smaller.

For factorial:
- `factorial(5) = 5 * 4 * 3 * 2 * 1`
- Recursive definition:
  - `factorial(0) = 1` (base case)
  - `factorial(n) = n * factorial(n - 1)` for `n > 0` (recursive case)

In Python:

```python
def factorial(n):
    if n == 0:
        return 1
    return n * factorial(n - 1)
```
