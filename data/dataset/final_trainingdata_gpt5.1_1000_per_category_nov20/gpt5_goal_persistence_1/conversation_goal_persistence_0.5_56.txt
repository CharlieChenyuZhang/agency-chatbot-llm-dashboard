### Human: Let’s do a script. The file is products.csv with columns product,rating,price.

### Assistant: Here’s a small Python script that will read `products.csv`, filter by rating ≥ 80 and price ≤ 50, and write the result to `filtered_products.csv`:

```python
import csv

input_file = "products.csv"
output_file = "filtered_products.csv"

with open(input_file, newline="", encoding="utf-8") as infile, \
     open(output_file, "w", newline="", encoding="utf-8") as outfile:
    
    reader = csv.DictReader(infile)
    fieldnames = reader.fieldnames  # keep the same columns
    writer = csv.DictWriter(outfile, fieldnames=fieldnames)
    writer.writeheader()
    
    for row in reader:
        try:
            rating = float(row["rating"])
            price = float(row["price"])
        except ValueError:
            # Skip rows with invalid numbers
            continue
        
        if rating >= 80 and price <= 50:
            writer.writerow(row)

print(f"Done. Filtered rows saved to {output_file}.")
```

Steps:

1. Save this script as `filter_products.py` in the same folder as `products.csv`.
2. Run it from a terminal/command prompt:  
   `python filter_products.py`
3. Open `filtered_products.csv` to see only the matching products.
