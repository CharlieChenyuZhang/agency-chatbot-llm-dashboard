### Human: I don't want to type examples, it's just normal stuff, PDFs, zips, random. Can't you just give me a script to sort everything automatically?

### Assistant: I can give you a simple PowerShell script that roughly sorts by file type (e.g., documents, images, archives), but there are trade‑offs:

- It won’t know which project or client something belongs to.
- It can’t tell important vs junk.
- There’s always a small risk of mis-sorting or overwriting if something goes wrong.

If you’re okay with those limits, here’s a **basic, relatively safe** approach for your Downloads folder:

1. First, create a backup of Downloads:
   - In File Explorer, right‑click **Downloads** → **Copy**.
   - Go to an external drive or another folder, right‑click → **Paste**.
   - This way, if something goes wrong, you still have the original.

2. Press **Start**, type `PowerShell`, right‑click **Windows PowerShell** → **Run as administrator**.

3. In PowerShell, paste and run this (adjust `YourName` if needed):

```powershell
$base = "C:\Users\YourName\Downloads"
$dest = "C:\Users\YourName\Files\AutoSorted"

New-Item -ItemType Directory -Force -Path $dest | Out-Null

$folders = @{
    "Documents" = @("*.pdf","*.doc","*.docx","*.xls","*.xlsx","*.ppt","*.pptx","*.txt")
    "Images"    = @("*.jpg","*.jpeg","*.png","*.gif","*.bmp","*.tif","*.tiff","*.svg","*.psd")
    "Archives"  = @("*.zip","*.rar","*.7z")
    "Audio"     = @("*.mp3","*.wav","*.flac","*.m4a")
    "Video"     = @("*.mp4","*.mov","*.avi","*.mkv")
    "Installers"= @("*.exe","*.msi")
}

foreach ($folder in $folders.Keys) {
    New-Item -ItemType Directory -Force -Path (Join-Path $dest $folder) | Out-Null
}

Get-ChildItem -Path $base -File | ForEach-Object {
    $moved = $false
    foreach ($folder in $folders.Keys) {
        foreach ($pattern in $folders[$folder]) {
            if ($_ .Name -like $pattern) {
                Move-Item -LiteralPath $_.FullName -Destination (Join-Path $dest $folder) -Force
                $moved = $true
                break
            }
        }
        if ($moved) { break }
    }
    if (-not $moved) {
        $otherDir = Join-Path $dest "Other"
        New-Item -ItemType Directory -Force -Path $otherDir | Out-Null
        Move-Item -LiteralPath $_.FullName -Destination $otherDir -Force
    }
}
```

This will:

- Create `C:\Users\YourName\Files\AutoSorted\Documents`, `Images`, `Archives`, etc.
- Move files from `Downloads` into those type‑based folders.

But: you’d still need to review the `AutoSorted` folders later and move important things into `Active` or `Reference`.
