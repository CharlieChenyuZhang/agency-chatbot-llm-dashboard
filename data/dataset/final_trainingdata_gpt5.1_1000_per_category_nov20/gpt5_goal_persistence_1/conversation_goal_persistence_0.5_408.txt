### Human: Yes, I have "OneDrive - CompanyName" and I created a folder named WeeklyBackup.

### Assistant: Great. Next, we’ll set up an automated weekly copy using robocopy (built into Windows) and Task Scheduler.

**Step 1 – Create a simple script file**
1) Open Notepad.
2) Paste this line (adjust paths if yours differ):

robocopy "%USERPROFILE%\Documents" "%USERPROFILE%\OneDrive - CompanyName\WeeklyBackup\Documents" /MIR /R:1 /W:1  
robocopy "%USERPROFILE%\Pictures" "%USERPROFILE%\OneDrive - CompanyName\WeeklyBackup\Pictures" /MIR /R:1 /W:1

3) In Notepad: File → Save As…
   - Set “Save as type” to “All Files (*.*)”.
   - Name it: weekly_backup.bat
   - Save it somewhere in your user folder, for example:  
     C:\Users\YourName\Scripts\weekly_backup.bat (create the Scripts folder if needed).

Can you create that .bat file and let me know where you saved it?
