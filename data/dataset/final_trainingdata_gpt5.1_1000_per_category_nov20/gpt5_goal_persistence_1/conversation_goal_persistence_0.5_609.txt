Given all the constraints (no sudo, no extra tools), I’m going to suggest a practical compromise:

1. **Use the GitLab web UI** to see your assigned MRs.
2. **Maintain a small, manual checklist** of active branches.
3. Use a tiny bash helper to fetch/checkout a branch by MR IID, assuming you type the IID yourself:

```bash
#!/usr/bin/env bash
# checkout_mr <project_id> <mr_iid>
PROJECT_ID="$1"
MR_IID="$2"

API="https://gitlab.mycompany.com/api/v4"
BRANCH=$(curl -s --header "PRIVATE-TOKEN: $GITLAB_TOKEN" \
  "$API/projects/$PROJECT_ID/merge_requests/$MR_IID" \
  | sed -n 's/.*"source_branch":"\([^"]*\)".*/\1/p')

if [ -z "$BRANCH" ]; then
  echo "Could not determine branch for MR !${MR_IID}"
  exit 1
fi

git fetch origin "$BRANCH":"$BRANCH" && git checkout "$BRANCH"
```

You’d save that as `checkout_mr`, `chmod +x checkout_mr`, then run:
```bash

```

It’s not fully automatic “checkout all assigned MRs”, but it avoids complicated tooling and still speeds things up.
