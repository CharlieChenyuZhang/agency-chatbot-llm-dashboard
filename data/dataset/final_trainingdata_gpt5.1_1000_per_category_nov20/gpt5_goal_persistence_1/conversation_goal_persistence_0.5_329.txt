### Assistant: Absolutely; we’ll take it step by step.

We want:
- Keep asking for a guess
- Stop when the user gets it right
- Optionally allow them to quit

Here’s a very literal version:

```python
secret = 7
while True:
    raw = input("Guess a number between 1 and 10 (or 'q' to quit): ")

    if raw == "q":
        print("Goodbye!")
        break

    if not raw.isdigit():
        print("Please enter digits only.")
        continue

    guess = int(raw)

    if guess == secret:
        print("You got it!")
        break
    else:
        print("Not quite, try again.")
```

Key ideas:
- `while True:` means “loop forever until we `break`”.
- `break` exits the loop.
- `continue` jumps to the next loop iteration.
