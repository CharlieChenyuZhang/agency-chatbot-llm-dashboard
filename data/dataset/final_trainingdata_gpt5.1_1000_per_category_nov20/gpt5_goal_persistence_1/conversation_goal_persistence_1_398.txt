### Human: Build a Notion workspace for tasks and notes

1. A “Home” page  
2. A **Tasks** database  
3. A **Notes** database  
4. A way to link tasks ↔ notes so everything stays connected

I’ll describe structure first, then walk you through exact steps.

**Structure:**

- **Home (page)**
  - Quick links / views:
    - “Today” tasks
    - “This week” tasks
    - “Recent notes”
- **Tasks (database – table view)**
  - Key properties:
    - Name (task title)
    - Status (To Do / Doing / Done)
    - Due date
    - Priority (Low / Med / High)
    - Related note (relation to Notes)
- **Notes (database – table or list)**
  - Key properties:
    - Title
    - Type (Meeting, Idea, Reference, etc.)
    - Related tasks (relation to Tasks)

**Step-by-step in Notion:**

1. **Create Home page**
   - In the left sidebar, click **+ New page**.
   - Name it **Home**.
   - Optionally add an icon (e.g., 🏠) and a little intro line like “Central hub for tasks & notes”.

2. **Create Tasks database**
   - On the **Home** page, type `/table` and choose **Table – Full page**.
   - Name it **Tasks**.
   - Add / adjust properties:
     - Keep **Name** as is (this is your task title).
     - Add a **Select** property: name it *Status* (values: To Do, Doing, Done).
     - Add a **Date** property: name it *Due*.
     - Add a **Select** property: name it *Priority* (Low, Medium, High).
   - We’ll add the link to notes in a moment.

3. **Create Notes database**
   - Go back to **Home** (breadcrumbs at top or sidebar).
   - Type `/table` again, choose **Table – Full page**.
   - Name it **Notes**.
   - Properties:
     - Keep **Name** as your note title.
     - Add a **Select** property named *Type* (Meeting, Idea, Research, Journal, etc.).
     - Optionally a **Date** property for when you created/took the note.

4. **Link tasks and notes**
   - Open the **Tasks** database.
   - Add a new property:
     - Click **+** at the right of the table → choose **Relation**.
     - Link it to the **Notes** database.
     - Name it **Related note**.
   - Open the **Notes** database.
     - Notion will auto-create a **Related tasks** relation back to Tasks (you can rename it if needed).

Now you can:
- Attach any note to a task (e.g., meeting notes for “Prepare presentation”).
- From a note, see all tasks associated with it.
