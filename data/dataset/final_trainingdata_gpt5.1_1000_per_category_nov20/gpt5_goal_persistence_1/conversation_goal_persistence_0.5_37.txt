### Assistant: Good plan. Let’s keep it straightforward so it’s easy to stick with.

#### 1. Set up a clear folder structure in OneDrive

1. Open **File Explorer**.
2. In the left pane, click on **OneDrive – [Your Company or Name]**.
3. In OneDrive, create a main folder:
   - Right‑click → **New → Folder** → name it:  
     `Backups`
4. Inside `Backups`, create two folders:
   - `Documents`
   - `Desktop`

Your OneDrive path will look like:
- `OneDrive\Backups\Documents`
- `OneDrive\Backups\Desktop`

#### 2. Weekly backup routine (what you’ll do each week)

Once a week:

1. **Copy Documents:**
   - Go to `This PC → Documents`.
   - Press `Ctrl+A` to select everything (or only what you care about).
   - Copy (`Ctrl+C`), then go to `OneDrive\Backups\Documents`.
   - Paste (`Ctrl+V`).
   - If prompted, choose **Replace the files in the destination** (so the backup stays current).

2. **Copy Desktop:**
   - Go to `This PC → Desktop`.
   - Select what you want to back up.
   - Copy and paste into `OneDrive\Backups\Desktop`, again replacing as needed.

3. Wait for the OneDrive icon to finish syncing (it should show a checkmark when done).

You can also create subfolders by date if you prefer, like `Backups\Documents\2025-11-21`, but overwriting the same location weekly is simpler.

#### 3. Create a weekly reminder (Outlook example)

If you use Outlook with Office 365:

1. Open **Outlook**.
2. Go to the **Calendar**.
3. Create a new **Appointment** (not a meeting).
4. Title: `Weekly OneDrive Backup`.
5. Set **Start time** to a day/time you’re usually at the laptop (e.g., Friday 4:30 PM).
6. Click **Make Recurring**:
   - Pattern: **Weekly**
   - Recur every: **1** week
   - On: your chosen day.
7. Set a reminder (e.g., 10 minutes before).
8. Save & Close.

You’ll get a weekly nudge to do the 5‑minute copy.
