- ε: how close you want f(x) to be to L (vertical closeness).

About 0 < |x − a|: let me try a more concrete, less symbolic explanation.

We use 0 < |x − a| < δ because:

- |x − a| < δ means “x is within δ of a” (possibly equal to a).
- The extra “0 <” part says “but x is not exactly equal to a”.

Why exclude x = a?

Because the limit is about what f(x) does *near* a, not necessarily at a. The function might:
- be undefined at a, or
- have a weird value at a that doesn’t match the limiting behavior.

Example: f(x) = (x² − 1)/(x − 1).  
For x ≠ 1, this simplifies to x + 1, but f(1) is undefined.  
Still, limₓ→1 f(x) = 2, because as x gets close to 1 (but not equal), f(x) gets close to 2.

So 0 < |x − a| is our way of saying “ignore the actual point a; only look at points arbitrarily close to it.”

### Assistant: Induction is a method to prove statements that are meant to hold for all natural numbers (1, 2, 3, …).

Basic structure (for a statement P(n)):

1. Base case: Show P(1) is true (or P(0), depending on where you start).
2. Inductive step: Assume P(k) is true for some arbitrary k (this is the *induction hypothesis*). Then prove P(k + 1) is true using that assumption.

If both hold, you conclude P(n) is true for all n.

Simple example:

Claim: For all n ≥ 1,
1 + 2 + 3 + … + n = n(n + 1)/2.

Sketch of proof:
- Base case (n = 1):  
  Left side: 1. Right side: 1(1 + 1)/2 = 1. So it holds.

- Inductive step: Assume it’s true for n = k:
  1 + 2 + … + k = k(k + 1)/2.   (induction hypothesis)

  Now consider n = k + 1:
  1 + 2 + … + k + (k + 1)
  = [1 + 2 + … + k] + (k + 1)
  = k(k + 1)/2 + (k + 1)      (by the hypothesis)
  = (k + 1)(k/2 + 1)
  = (k + 1)(k + 2)/2
  = (k + 1)((k + 1) + 1)/2.

So the formula holds for k + 1, assuming it holds for k.  
Thus, by induction, it holds for all n ≥ 1.

You don’t need to internalize all the algebra right now—just the *pattern*:

- Check the first domino (base case),
- Show “if one domino falls, the next one falls” (inductive step),
- Conclude all dominos fall (the statement holds for all n).
