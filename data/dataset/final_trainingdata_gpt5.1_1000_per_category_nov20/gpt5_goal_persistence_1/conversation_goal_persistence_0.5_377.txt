### Assistant: Here’s a compact ILP formulation you can use.

**Sets**
- P = set of people = {A, B, C, D, E, F, G}
- D = days = {Mon, Tue, Wed, Thu, Fri, Sat, Sun}
- S = shifts = {M, E, N}

**Parameters**
- req[d, s] = required number of staff on day d, shift s  
  - req[d, M] = 3  
  - req[d, E] = 3  
  - req[d, N] = 2
- senior[p] = 1 if p is senior (A,B,F), 0 otherwise.
- canWorkNight[p] = 1 if p can work Night (A,B,D,E,G), 0 otherwise (C,F).
- available[p, d, s] = 1 if p is allowed/available that day and shift, 0 otherwise  
  (e.g., G on Mon/Tue = 0; A on Sat = 0; B on Sun = 0; Night shifts for C,F = 0).
- fullTime[p] = 1 if full-time, 0 if part-time.
- maxHoursFT = 40, maxHoursPT = 24.
- shiftHours = 8.

**Decision variables**
- x[p, d, s] ∈ {0,1} : 1 if person p works shift s on day d, else 0.

Optionally:
- Nshifts[p] = total shifts per person (derived variable).
- Nnights[p] = total nights per person.

**Constraints**

1. **Coverage constraints**
   For every day d and shift s:
   ∑ₚ x[p, d, s] ≥ req[d, s]

2. **Senior presence per shift**
   For every d,s:
   ∑ₚ senior[p] * x[p, d, s] ≥ 1

3. **Availability and skill constraints**
   For every p,d,s:
   x[p, d, s] ≤ available[p, d, s]
   And for Nights:
   x[p, d, N] ≤ canWorkNight[p]

4. **Per-day shift limits and Night exclusivity**
   For every p,d:
   ∑ₛ x[p, d, s] ≤ 2                (max 2 shifts/day)
   And Night exclusivity:
   x[p, d, N] + x[p, d, M] ≤ 1
   x[p, d, N] + x[p, d, E] ≤ 1

5. **No Evening/Night → Morning next day**
   For every p and every day d where nextDay(d) exists:
   x[p, d, E] + x[p, nextDay(d), M] ≤ 1
   x[p, d, N] + x[p, nextDay(d), M] ≤ 1

6. **Weekly hour limits (full- vs part-time)**
   For every p:
   TotalHours[p] = shiftHours * ∑_{d,s} x[p, d, s]

   If fullTime[p] = 1:
   TotalHours[p] ≤ maxHoursFT
   If fullTime[p] = 0:
   TotalHours[p] ≤ maxHoursPT

7. **Days off (at least 2 per week)**
   For every p:
   ∑_{d} [ ∑ₛ x[p, d, s] ≥ 1 ] ≤ 5

   - Then:
     ∑_{d} y[p, d] ≤ 5

8. **Define total shifts and night shifts for fairness**
   Nshifts[p] = ∑_{d,s} x[p, d, s]
   Nnights[p] = ∑_{d} x[p, d, N]

**Objective (fairness)**

You can choose, for example:

- Minimize imbalance in Night shifts and total hours:

   Let:
   - AvgNights = (1 / |P|) * ∑ₚ Nnights[p]
   - AvgHours = (1 / |P|) * ∑ₚ TotalHours[p]

   To linearize, introduce deviation variables:

   For each p:
   devNightPlus[p] ≥ Nnights[p] – AvgNights  
   devNightMinus[p] ≥ AvgNights – Nnights[p]

   devHourPlus[p] ≥ TotalHours[p] – AvgHours  
   devHourMinus[p] ≥ AvgHours – TotalHours[p]

   All dev variables ≥ 0.

Then:
