Two common options:

1) Browser automation (no backend access needed)
   - Use a tool like Python + Selenium or Playwright.
   - Script logs into your app, navigates to Customers, iterates pages, collects the table HTML, and writes it to CSV.

Example (high-level Python + Selenium snippet, to be customized):

```python
from selenium import webdriver
from selenium.webdriver.common.by import By
import csv
import time

driver = webdriver.Chrome()
driver.get("https://your-internal-app/login")

# TODO: log in (find username/password fields and submit)
# driver.find_element(...).send_keys("your-username")
# ...

all_rows = []

while True:
    table = driver.find_element(By.CSS_SELECTOR, "table")  # adjust selector
    rows = table.find_elements(By.CSS_SELECTOR, "tbody tr")

    for row in rows:
        cells = [c.text for c in row.find_elements(By.TAG_NAME, "td")]
        all_rows.append(cells)

    # Try to go to next page; adjust selector to match your app
    next_buttons = driver.find_elements(By.XPATH, "//button[contains(., 'Next')]")
    if not next_buttons or "disabled" in next_buttons[0].get_attribute("class"):
        break
    next_buttons[0].click()
    time.sleep(1)

driver.quit()

with open("customers.csv", "w", newline="", encoding="utf-8") as f:
    writer = csv.writer(f)
    writer.writerows(all_rows)
```
