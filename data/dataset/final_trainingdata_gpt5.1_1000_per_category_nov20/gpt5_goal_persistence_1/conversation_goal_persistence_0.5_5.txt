Idea:
- The **derivative** of a function at a point tells you its **instantaneous rate of change** there.

- If f(x) = x², then f′(x) = 2x.
- If f(x) = x³, then f′(x) = 3x².

How limits fit in (conceptually, not too formal yet):

- The derivative at a point is defined using a **limit**.
- We look at the average rate of change over smaller and smaller intervals and see what value it approaches.

Picture:
For f(x) = x², the **average rate of change** between x and x + h is:
[f(x + h) − f(x)] / h

We then take:
f′(x) = lim (h → 0) [f(x + h) − f(x)] / h

So limits answer: “As h gets closer and closer to 0, what value does this expression approach?”

Why do we need limits?

For “nice” functions (like 3x + 1), plugging in works. Limits become essential when:
1) The function is not defined at the point (like a hole in the graph).
2) The behavior near the point matters more than the value *at* the point.

Example:
f(x) = (x² − 1) / (x − 1)

- If you plug x = 1 directly, you get 0/0, which is undefined.
- But for x ≠ 1, you can simplify:
  x² − 1 = (x − 1)(x + 1), so
  f(x) = (x − 1)(x + 1) / (x − 1) = x + 1, for x ≠ 1.
- So as x → 1, f(x) behaves like x + 1, which goes to 2.

Thus:
lim (x → 1) (x² − 1) / (x − 1) = 2
even though f(1) is not defined.

To get better at computing derivatives, it helps to know a small set of **rules** really well:

1) Power rule:
   d/dx (x^n) = n x^(n−1)

2) Constant multiple:
   d/dx (c·f(x)) = c·f′(x)

3) Sum rule:
   d/dx (f(x) + g(x)) = f′(x) + g′(x)

4) Product rule:
   d/dx (f(x)g(x)) = f′(x)g(x) + f(x)g′(x)

5) Quotient rule:
   d/dx (f/g) = (f′g − fg′)/g²

6) Chain rule:
   d/dx f(g(x)) = f′(g(x))·g′(x)

Instead of dumping all of these with complex examples, let’s practice with one new rule at a time.

You’re already okay with the power rule. Let’s add the **product rule**.

Example:
If f(x) = x² and g(x) = 3x, then
d/dx [f(x)g(x)] = f′(x)g(x) + f(x)g′(x)
= (2x)(3x) + (x²)(3)
= 6x² + 3x² = 9x²
