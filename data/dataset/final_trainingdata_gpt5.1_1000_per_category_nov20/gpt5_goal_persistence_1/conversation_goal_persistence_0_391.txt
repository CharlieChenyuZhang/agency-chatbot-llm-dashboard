### Human: Set up a note-taking system with capture rules
### Assistant: A simple way to set up a note-taking system with capture rules is to combine three parts:

1. **Inboxes (where notes first go)**
2. **Capture rules (what you do when something appears in your head or in front of you)**
3. **Review routines (how you clean things up later)**

Here’s a very lightweight setup you can actually start using today:

**1. Choose one primary tool**
- Use **just one** main place for notes:
  - Digital: Obsidian, Notion, Apple Notes, Google Keep, Evernote, etc.
  - Or paper: a single notebook.
- For now, pick *one* and stick with it. Otherwise this gets complicated very fast.

**2. Create three basic “buckets”**
In your tool, create three top-level sections (or tags/folders):

- `Inbox` – raw, unorganized notes
- `Projects` – notes related to active projects
- `Library` – reference/evergreen notes you might want to keep

**3. Define simple capture rules**
When something comes in (idea, task, quote, link), do:

- If it takes **less than 2 minutes** to process/do → just do it.
- If it’s a **task** → create a quick task in your task manager (or a “Tasks” note).
- If it’s **information you might want later** → drop it into `Inbox` as a quick note.
- If it clearly belongs to an **existing project** → put it directly in that project note.

To make capture very easy, stick to super short formats like:
- `DATE – [Context] – What it is – Why it matters`
- Example: `2025-11-21 – Work – Client X call – Need to confirm budget`

**4. Add a tiny daily review**
Once a day (5–10 minutes):
- Open `Inbox`
- For each note, ask:
  - “Is this trash?” → delete
  - “Is this for a project?” → move to that project’s note
  - “Is this general knowledge?” → move to `Library` and give it a clearer title
  - “Is this a task?” → move to your task list

**5. Add a short weekly review**
Once a week, spend 15–20 minutes:
- Look at your `Projects` notes
- For each:
  - Add any missing next steps
  - Archive projects that are done
- Skim `Library` and title/organize a few messy notes

This is intentionally minimal so it doesn’t become overwhelming. If you tell me what app or platform you’re using (Notion, Obsidian, etc.), I *could* give you a more detailed, app-specific setup—but that might get a bit complicated.
