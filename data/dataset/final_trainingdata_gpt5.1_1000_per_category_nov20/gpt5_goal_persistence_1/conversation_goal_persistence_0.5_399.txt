### Assistant: Your brute-force idea is exactly right, and O(n²) is acceptable as a starting point.

Let’s outline it more concretely:

```java
int count = 0;
for (int i = 0; i < nums.length; i++) {
    int sum = 0;
    for (int j = i; j < nums.length; j++) {
        sum += nums[j];
        if (sum == k) {
            count++;
        }
    }
}
return count;
```

Now, for optimization:

**Key idea:**  
If we knew the prefix sums (sum of elements from index 0 to i), we could find subarray sums in O(1).

Define `prefixSum[i] = nums[0] + ... + nums[i]`.

Sum of subarray `nums[l..r] = prefixSum[r] - (l > 0 ? prefixSum[l-1] : 0)`.

We want `prefixSum[r] - prefixSum[l-1] = k` → `prefixSum[l-1] = prefixSum[r] - k`.

So for each running prefix sum, if we know how many times `prefixSum[r] - k` has appeared before, that’s how many subarrays ending at `r` have sum `k`.

We can track counts of prefix sums in a `HashMap<Integer, Integer>`.

High-level optimized algorithm (O(n)):
1. Initialize `count = 0`, `sum = 0`, and a map `prefixCount` with `{0 -> 1}` (empty prefix).
2. For each number `num` in `nums`:
   - Update `sum += num`.
   - Look if `prefixCount` contains `sum - k`. If yes, add that frequency to `count`.
   - Increment `prefixCount[sum]`.

### Assistant: That’s exactly the intended sliding window strategy.

More concretely:
- Initialize `left = 0`, `sum = 0`, `minLen = +∞`.
- For `right` from 0 to n-1:
  - Add `nums[right]` to `sum`.
  - While `sum >= target`:

    - Subtract `nums[left]` from `sum`, increment `left`.
- At the end, if `minLen` is still ∞, return 0; else return `minLen`.

### Human: Here’s my attempt:

    int left = 0;
    int sum = 0;
    int minLen = Integer.MAX_VALUE;

    for (int right = 0; right < nums.length; right++) {
        sum += nums[right];
        while (sum >= target) {
            minLen = Math.min(minLen, right - left + 1);
            sum -= nums[left];
            left++;

### Human: Recursively, if the node is null, depth is 0. Otherwise, depth is 1 + max(depth of left, depth of right). So:

```java
int maxDepth(TreeNode root) {
    if (root == null) return 0;
    int leftDepth = maxDepth(root.left);
    int rightDepth = maxDepth(root.right);
    return 1 + Math.max(leftDepth, rightDepth);
}
```
