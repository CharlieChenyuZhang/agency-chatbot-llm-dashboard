### Human: I still need an example of the PowerShell script. Can you at least give me that?

Something like:

```powershell
$date = Get-Date -Format "yyyy-MM-dd"
$backupRoot = "C:\Users\YourName\OneDrive\WeeklyBackups"
$dest = Join-Path $backupRoot $date

New-Item -ItemType Directory -Path $dest -Force | Out-Null

$foldersToBackup = @(
    "C:\Users\YourName\Documents",
    "C:\Users\YourName\Pictures"
)

foreach ($folder in $foldersToBackup) {
    $folderName = Split-Path $folder -Leaf
    $targetPath = Join-Path $dest $folderName
    Copy-Item $folder $targetPath -Recurse -Force
}
```
