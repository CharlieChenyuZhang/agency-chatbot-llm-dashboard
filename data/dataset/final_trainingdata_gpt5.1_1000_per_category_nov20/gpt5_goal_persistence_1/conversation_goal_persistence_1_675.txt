#### GitHub Actions example

Create `.github/workflows/list-bug-issues.yml` in your repo:

```yaml
name: List bug issues

on:
  workflow_dispatch:

jobs:
  list-bugs:
    runs-on: ubuntu-latest
    permissions:
      issues: read
    steps:
      - name: List bug-labeled issues
        run: |
          REPO="${{ github.repository }}"
          curl -s -H "Authorization: Bearer ${{ secrets.GITHUB_TOKEN }}" \
               "https://api.github.com/repos/$REPO/issues?labels=bug&state=open&per_page=100" \
          | jq -r '.[] | "#\(.number) \(.title) [\(.state)]"'
```

Notes:
- `secrets.GITHUB_TOKEN` is auto-provided by GitHub Actions; no PAT needed.
- `jq` is used to format output nicely; it’s available on the Actions runner by default.

2. In the browser, go to **Actions → List bug issues → Run workflow**.
3. Open the run and look at the logs for `List bug-labeled issues` — you’ll see a clean list like:

```bash

BASE_DIR="${1:-$HOME/code}"

cd "$BASE_DIR" || exit 1

best_dir=""
best_time=0

for d in */ .*/ ; do
  [ -d "$d/.git" ] || continue

  cd - >/dev/null || exit 1

    best_dir="$d"
```

```bash

```
