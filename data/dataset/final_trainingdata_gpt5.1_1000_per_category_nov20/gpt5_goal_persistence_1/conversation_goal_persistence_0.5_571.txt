Method: Meta-Learned Layer-wise Learning Rate Modulation

1. Problem Setup  
   We consider supervised image classification with deep convolutional networks parameterized by θ and trained on dataset D = {(xi, yi)}. Standard training updates θ using a base optimizer O (e.g., SGD with momentum) with a global learning rate η. Our goal is to learn a function f_φ that outputs layer-wise learning-rate multipliers mℓ,t for each layer ℓ at training step t, such that the resulting parameter trajectory yields faster convergence and better generalization.

2. Base Optimizer  
   We adopt stochastic gradient descent with Nesterov momentum as the base optimizer:
   vt+1 = μ vt + ∇θ L(θt; Bt)  
   θt+1 = θt − η vt+1  
   where Bt is a minibatch, μ is the momentum coefficient, and L is the empirical loss. In the absence of modulation, η is constant across layers.

3. Layer-wise Modulation  
   We partition θ into L disjoint parameter blocks {θ1, …, θL}, corresponding to layers. At each step t, we compute a scalar multiplier mℓ,t for each layer and apply it to the base update:
   θℓ,t+1 = θℓ,t − mℓ,t η vℓ,t+1.  
   The multipliers mℓ,t are constrained to a positive interval [mmin, mmax] to ensure stability.

4. Input Features  
   To keep the approach simple and efficient, f_φ operates on low-dimensional per-layer statistics:
   - gℓ,t = ||∇θℓ L(θt; Bt)||2: current gradient norm,
   - rℓ,t: exponential moving average of gradient norms,
   - dℓ: normalized layer index in [0, 1].  
   We form a feature vector xℓ,t = [log gℓ,t, log rℓ,t, dℓ].

5. Meta-learner Architecture  
   The meta-learner f_φ is a small multilayer perceptron shared across layers:
   hℓ,t = ReLU(W1 xℓ,t + b1)  
   zℓ,t = ReLU(W2 hℓ,t + b2)  
   uℓ,t = W3 zℓ,t + b3  
   mℓ,t = σ(uℓ,t) (mmax − mmin) + mmin  
   where σ is the logistic sigmoid. Sharing φ = {W1, W2, W3, b1, b2, b3} across layers encourages the model to learn generic rules that transfer between architectures.

6. Meta-training Objective  
   We meta-train φ on a distribution of tasks T, where each task corresponds to training a specific architecture on a specific dataset split. For a given task τ ∈ T, we unroll the base training procedure for Tinner steps using f_φ, starting from a random initialization θ0:
   for t = 0, …, Tinner − 1:  
   - Sample Bt, compute gradients, features xℓ,t, and multipliers mℓ,t,  
   - Update parameters using the modulated optimizer.  
   We define the outer objective as the validation loss after Tinner steps:
   J(φ; τ) = Lval(θTinner; Dval,τ).  
   The meta-parameters φ are updated via gradient-based optimization over batches of tasks:
   φ ← φ − α ∇φ Eτ∼T [J(φ; τ)].  
   In practice, we approximate the meta-gradient by truncated backpropagation through time over the unrolled optimization.

7. Regularization and Stability  
   To prevent pathological meta-learned schedules, we add regularization terms encouraging multipliers close to 1 and discouraging rapid changes over time:
   R(φ) = λ1 Eℓ,t [(mℓ,t − 1)2] + λ2 Eℓ,t [(mℓ,t − mℓ,t−1)2].  
   The full meta-objective is J(φ) + R(φ). We also clip gradients during unrolled optimization to maintain numerical stability.

8. Inference-time Usage  
   After meta-training, we fix φ and apply f_φ during standard training on target tasks. We do not update φ during this phase; it introduces negligible computational overhead because feature computation and the MLP are inexpensive compared to forward and backward passes.
