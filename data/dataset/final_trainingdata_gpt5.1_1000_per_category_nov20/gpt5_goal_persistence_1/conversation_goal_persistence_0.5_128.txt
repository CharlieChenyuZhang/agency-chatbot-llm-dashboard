### Assistant: Great. Here’s a simple Python script that waits 25 minutes and then shows a desktop notification.

First, install a small helper package in a terminal (Command Prompt or PowerShell):

```bash

```

Then create a file called `pomodoro_25min.py` with this content:

```python
import time
from win10toast import ToastNotifier

def pomodoro(minutes=25):
    print(f"Timer started for {minutes} minutes.")
    time.sleep(minutes * 60)
    toaster = ToastNotifier()
    toaster.show_toast(
        "Time's up!",
        f"{minutes} minutes have passed.",
        duration=10,
        threaded=False
    )
    print("Time's up!")

if __name__ == "__main__":
    pomodoro(25)
```

Run it with:

```bash

```
