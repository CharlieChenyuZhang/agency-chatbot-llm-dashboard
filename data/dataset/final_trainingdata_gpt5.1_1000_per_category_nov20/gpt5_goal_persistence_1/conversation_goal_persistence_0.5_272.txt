High-level plan:

#### 1) Get a personal access token (PAT)

#### 2) Script: list assigned MRs and create local branches

From inside your project directory (already cloned), you can run something like this (for GitLab.com; we can adjust for self-hosted):

```bash
#!/usr/bin/env bash
set -euo pipefail

GITLAB_HOST="https://gitlab.com"
GITLAB_TOKEN="YOUR_TOKEN_HERE"
USERNAME="YOUR_USERNAME_HERE"

# 1) Get project ID from origin remote
PROJECT_PATH=$(git remote get-url origin | sed -E 's/.*gitlab.com[/:](.+)\.git/\1/')
PROJECT_PATH_ENC=$(python - <<EOF
import urllib.parse
print(urllib.parse.quote("$PROJECT_PATH", safe=""))
EOF
)

# 2) Get MRs assigned to you (open only)
MR_JSON=$(curl -sS --header "PRIVATE-TOKEN: $GITLAB_TOKEN" \
  "$GITLAB_HOST/api/v4/projects/$PROJECT_PATH_ENC/merge_requests?state=opened&assignee_username=$USERNAME")

# 3) Extract IIDs and titles, then fetch refs and create branches
echo "$MR_JSON" | jq -r '.[] | "\(.iid) \(.title)"' | while read -r IID TITLE; do
  BRANCH_NAME="mr/$IID"
  echo "Processing MR !${IID}: $TITLE"
  git fetch origin "merge-requests/$IID/head:$BRANCH_NAME"
  echo "  -> Created/updated branch $BRANCH_NAME"
done
```

You’ll need `jq` and Python (for URL encoding) installed. If that’s too heavy, we can simplify.

### Human: A small helper script that I can pass a list of MR IDs to would be helpful.

### Assistant: Here’s a simple script that takes MR IIDs as arguments and creates/updates local branches for each:

```bash
#!/usr/bin/env bash
set -euo pipefail

if [ "$#" -eq 0 ]; then
  echo "Usage: $0 <mr_iid> [<mr_iid> ...]"
  echo "Example: $0 12 34 56"
  exit 1
fi

for IID in "$@"; do
  BRANCH="mr/$IID"
  echo "Fetching MR !${IID} into branch '${BRANCH}'..."
  git fetch origin "merge-requests/$IID/head:$BRANCH"
  echo "  -> You can now: git checkout $BRANCH"
done
```

Usage (from inside your project repo):


Then:


### Assistant: Let’s tweak the script so it checks out the first MR branch at the end:

```bash
#!/usr/bin/env bash
set -euo pipefail

if [ "$#" -eq 0 ]; then
  echo "Usage: $0 <mr_iid> [<mr_iid> ...]"
  echo "Example: $0 12 34 56"
  exit 1
fi

FIRST_BRANCH=""

for IID in "$@"; do
  BRANCH="mr/$IID"
  echo "Fetching MR !${IID} into branch '${BRANCH}'..."
  git fetch origin "merge-requests/$IID/head:$BRANCH"
  echo "  -> Created/updated branch $BRANCH"

  if [ -z "$FIRST_BRANCH" ]; then
    FIRST_BRANCH="$BRANCH"
  fi
done

if [ -n "$FIRST_BRANCH" ]; then
  echo "Checking out first MR branch: $FIRST_BRANCH"
  git checkout "$FIRST_BRANCH"
fi
```
