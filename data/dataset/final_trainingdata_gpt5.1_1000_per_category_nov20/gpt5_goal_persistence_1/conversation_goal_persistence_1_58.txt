**1. What is a tree (interview level)?**
- A tree is just a set of nodes connected by edges, with:
  - Exactly one path between any two nodes (no cycles).
  - One node chosen as the “root”.

A **binary tree** is a tree where each node has:
- `val`
- `left` child
- `right` child

**2. Two key traversal patterns to start with**
We’ll start simple:

- **Depth-first search (DFS) recursively**:
  - Preorder: process node, then left, then right.
  - Inorder: left, then node, then right.
  - Postorder: left, right, node.
