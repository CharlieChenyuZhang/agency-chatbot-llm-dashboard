### Assistant: Here’s a simple Python example using `geopy` and OpenStreetMap’s Nominatim geocoder (no paid API key required, but it’s subject to usage limits). It will:

- Geocode Times Square and each hotel.
- Compute distances in meters.
- Sort and print them by distance.

```python
# pip install geopy

from geopy.geocoders import Nominatim
from geopy.distance import geodesic

# Initialize geocoder (please set a descriptive user_agent)
geolocator = Nominatim(user_agent="times_square_distance_example")

# Define the reference location: Times Square
times_square_location = geolocator.geocode("Times Square, Manhattan, New York, NY")
times_square_coords = (times_square_location.latitude, times_square_location.longitude)

hotels = [
    ("New York Marriott Marquis", "1535 Broadway, New York, NY 10036"),
    ("Row NYC", "700 8th Ave, New York, NY 10036"),
    ("The Knickerbocker Hotel", "6 Times Square, New York, NY 10036"),
    ("Hampton Inn Times Square North", "851 8th Ave, New York, NY 10019"),
    ("Millennium Hotel Broadway Times Square", "145 W 44th St, New York, NY 10036"),
]

hotel_distances = []

for name, address in hotels:
    location = geolocator.geocode(address)
    if not location:
        print(f"Could not geocode: {name} ({address})")
        continue

    hotel_coords = (location.latitude, location.longitude)
    distance_meters = geodesic(times_square_coords, hotel_coords).meters

    hotel_distances.append((name, address, distance_meters))

# Sort by distance
hotel_distances.sort(key=lambda x: x[2])

print("Hotels sorted by distance from Times Square:")
for name, address, dist in hotel_distances:
    print(f"{name} - {address} - {dist:.1f} meters")
```
