#### 1. Database vs Page (in Notion terms)

- A **Page** is like a blank document or folder. It can hold text, images, and also databases.
- A **Database** is a special kind of page that stores many items in a structured way:
  - Each **row** = one item (e.g., one task)
  - Each **column** = a property (e.g., Due date, Status)

So:
- `✅ Tasks` is both a **page** and a **database** page.
- `📝 Notes` is also a database page.
- `🧭 Home` is a normal page **with views of those databases** embedded in it.

When we used `/linked database`, we didn’t create a new database; we just created a **view** of an existing one.

---

#### 2. Recurring tasks (simple version)

Notion doesn’t have true recurring tasks built-in, but we can do a workable version.

In the `✅ Tasks` database:

1. Add property: `Recurring`  
   - Type: **Select**  
   - Options: `None`, `Daily`, `Weekly`, `Monthly`
2. Add property: `Last Done`  
   - Type: **Date**
3. Add property: `Next Due`  
   - Type: **Formula**

Use this formula for `Next Due`:

```notion
if(prop("Recurring") == "Daily",
    dateAdd(prop("Last Done"), 1, "days"),
if(prop("Recurring") == "Weekly",
    dateAdd(prop("Last Done"), 1, "weeks"),
if(prop("Recurring") == "Monthly",
    dateAdd(prop("Last Done"), 1, "months"),
prop("Due"))))
```

Workflow:
- When you complete a recurring task:
  1. Set `Status` to `Done`
  2. Update `Last Done` to today
  3. `Next Due` will auto-calculate the new date
- You can then either:
  - Filter your view to use `Next Due` instead of `Due`, or
  - Manually copy `Next Due` into `Due`

If that’s too much, we can simplify to “duplicate this task and set a new due date.”

### Human: Let’s keep the formula for now. Can you also add a priority score formula that combines Priority and Due date urgency?

### Assistant: Yes, we can add a simple priority score.

In `✅ Tasks`, add a new property:
- Name: `Score`
- Type: **Formula**

We’ll:
- Give each `Priority` a base score
  - High = 3, Medium = 2, Low = 1
- Add urgency points based on how close the `Due`/`Next Due` date is

Use this formula (assuming you want to use `Next Due`):

```notion
// Base priority score
let base :=
  if(prop("Priority") == "High", 3,
  if(prop("Priority") == "Medium", 2,
  if(prop("Priority") == "Low", 1, 0)));

let days :=
  if(
    empty(prop("Next Due")),
    999,
    dateBetween(prop("Next Due"), now(), "days")
  );

// Urgency score: closer due dates = higher score
let urgency :=
  if(days <= 0, 5,           // overdue or today
  if(days == 1, 4,           // tomorrow
  if(days <= 3, 3,
  if(days <= 7, 2,
  if(days <= 14, 1, 0)))));  // further out

base + urgency
```

Notes:
- Tasks with no `Next Due` get a very high `days` (999) and thus 0 urgency.
- Sort your main `Tasks` view by `Score` descending to see the most important/urgent tasks at the top.

If this formula editor complains about the `let` syntax (older Notion accounts sometimes do), I can give you a simpler version without `let`.
