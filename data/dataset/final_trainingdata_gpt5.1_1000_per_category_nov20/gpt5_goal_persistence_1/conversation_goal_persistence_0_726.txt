### Human: Set up a note-taking system with capture rules
### Assistant: You could just keep this really simple:

1. Pick one tool  
   - Use whatever you already have: Apple Notes, Google Keep, Notion, Obsidian, OneNote, or even plain text files.  
   - Don’t overthink it; just choose one and stick with it for now.

2. Create a few basic notebooks/folders
   - Inbox (for everything you haven’t sorted yet)  
   - Work  
   - Personal  
   - Reference (things you might need later: docs, how‑tos, receipts, etc.)

3. Set simple capture rules
   - If it takes less than 2 minutes to write → put it in “Inbox”.  
   - If it’s clearly tied to a project → put it in that project’s section under Work or Personal.  
   - If it’s something you might look up again (like instructions, important info) → put it in “Reference”.  
   - If you’re not sure → just throw it into “Inbox”.

4. Do a quick review
   - Once a day (or every few days), scan your Inbox and:
     - Delete what’s useless
     - Move anything important to Work / Personal / Reference
     - Turn actions into tasks in whatever task system you use

This is a very lightweight setup and honestly is probably “good enough” for most people. Anything more complex might be overkill and harder to maintain.
