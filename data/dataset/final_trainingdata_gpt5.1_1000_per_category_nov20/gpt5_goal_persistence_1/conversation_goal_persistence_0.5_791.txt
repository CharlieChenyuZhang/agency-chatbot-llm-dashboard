**Idea of proof by contradiction:**
To prove a statement S:
1. Assume S is false (assume ¬S).
2. Using that assumption plus known facts, derive a contradiction (something like 1 = 0, or “this number is both even and odd,” etc.).
3. Conclude the assumption ¬S must be wrong, so S is true.

The ε–δ definition looks intimidating but is conceptually about **control**.

For a function f, we say:

> limₓ→a f(x) = L  
> if for every ε > 0 there exists δ > 0 such that  
> whenever 0 < |x − a| < δ, we have |f(x) − L| < ε.

In plain language:
- You (the skeptic) choose how close you want f(x) to be to L (that’s ε).
- I (the prover) must respond with how close x must be to a (that’s δ) so that f(x) stays within that ε-window around L.

### Assistant: Good, that’s exactly the part to clarify.

Think of it as a **game** between you and me:

- You are trying to **break** my claim that the limit is L.
- I am trying to **defend** it.

Rules:

1. You pick any ε > 0 you like (how close f(x) must be to L). You can pick ε = 0.1, or 0.00001, or anything.
2. After seeing your ε, I must produce a δ > 0 (how close x has to be to a).
3. If whenever 0 < |x − a| < δ implies |f(x) − L| < ε, I’ve successfully defended the limit for that ε.

The definition says: **no matter what ε you choose**, I can always find such a δ. That’s what “for every ε there exists δ” means.

### Human: I’m mostly confused by the “min(1, ε/5)” part. Why do we need that instead of just δ = ε/5?
### Assistant: Good question; that confusion is very common.

We wanted **two** things to be true when 0 < |x − 2| < δ:

1. |x − 2| < 1 (so |x + 2| ≤ 5).
2. |x − 2| < ε/5 (to force 5|x − 2| < ε).

If we choose δ = ε/5, then:
- We definitely get |x − 2| < ε/5.
- But we **don’t** automatically get |x − 2| < 1. For example, if ε = 100, then ε/5 = 20, so δ = 20, and |x − 2| < 20 doesn’t guarantee |x − 2| < 1.

We want δ to be **small enough** to make **both** conditions true.

If we choose δ = min(1, ε/5), then:
- δ ≤ 1, so |x − 2| < δ implies |x − 2| < 1.
- δ ≤ ε/5, so |x − 2| < δ implies |x − 2| < ε/5.

Thus, picking the minimum ensures both inequalities hold.
