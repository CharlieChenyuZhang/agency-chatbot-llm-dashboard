If I see a character c at index r:
- If c is not in the map, I just add it with value r.
- If c is in the map at index prev, and prev >= left, that means it’s inside the current window, so I need to move left to prev + 1 to avoid having two of the same character.
- If prev < left, it’s outside the window already, so I can just update map[c] = r without moving left.

I’ll write Python:

def lengthOfLongestSubstring(s):
    last = {}
    left = 0
    best = 0
    for r, c in enumerate(s):
        if c in last and last[c] >= left:
            left = last[c] + 1
        last[c] = r
        best = max(best, r - left + 1)
    return best
