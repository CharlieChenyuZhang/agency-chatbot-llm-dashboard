### Human: I’ll try Google Sheets. Anything I should watch out for when I download as CSV from there?

### Assistant: A few practical points:

1. **Encoding:**  
   Google Sheets exports CSV as UTF‑8, which is usually good. If another system expects a different encoding (like ANSI), just be aware that special characters might look odd there.

2. **Formulas vs. values:**  
   CSV only stores values, not formulas. What you see in each cell in Sheets is what will go into the CSV.

3. **Multiple sheets:**  
   CSV can only represent one sheet. Google Sheets will export just the active sheet. If your Excel file has multiple tabs that you need as CSV, you’ll need to download each one separately.

4. **Commas in data:**  
   If cells contain commas, Sheets will wrap those fields in quotes in the CSV, which is standard and usually fine for import into other systems.
