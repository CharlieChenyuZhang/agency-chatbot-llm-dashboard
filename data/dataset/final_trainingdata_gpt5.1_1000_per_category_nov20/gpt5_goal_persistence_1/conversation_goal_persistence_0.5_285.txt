### Assistant: Great, thanks for the details.

We can do this in PowerShell. Here’s a script you can run in the folder containing your videos:

1. Open the folder in File Explorer.
2. Click into the address bar, type `powershell` and press Enter.
3. In the PowerShell window, paste this and press Enter:

```powershell
$courseName = "CourseName"

Get-ChildItem -File -Filter "Lesson * - *.mp4" |
ForEach-Object {
    if ($_ .BaseName -match '^Lesson\s+(\d+)\s*-\s*(.+)$') {
        $num   = [int]$matches[1]
        $title = $matches[2]
        $newNum = '{0:000}' -f $num
        $newName = "{0} - {1} {2}{3}" -f $courseName, $newNum, $title, $_.Extension
        Rename-Item -LiteralPath $_.FullName -NewName $newName
    }
}
```

This:
- Extracts the lesson number and title from names like `Lesson 1 - Introduction.mp4`
- Pads the number to 3 digits (`001`, `002`, …)
- Renames to `CourseName - 001 Introduction.mp4`, keeping the `.mp4` extension.

You can test it first on a copy of a few files if you’re nervous. If you see any errors, paste them here and we’ll adjust.
