### Human: I do want the Completed date to update automatically when I mark a task Done. Can we do that with a formula?

### Assistant: We can approximate it, but there’s a limitation:

- Notion formulas can’t “remember” the exact moment you changed Status.
- They calculate dynamically based on current data.

Two options:

1) Simple formula (always uses “today” for Done)
   - Add a `Formula` property: name it `Completed (Auto)`.
   - Formula:

   ```notion
   if(prop("Status") == "Done", now(), empty())
   ```

   Caveats:
   - `now()` updates; it won’t freeze the actual completion date.
   - Good only if you don’t need historical accuracy.

2) Manual but easy workflow (recommended)
   - Keep `Completed` as a Date property.
   - Create a Notion button (if you have the new Buttons feature):
     - On Tasks database → “+ Add button” → “Mark Done”.
     - Actions:
       - Set `Status` to `Done`
       - Set `Completed` to `Current time`

This way, your completion date is accurate and doesn’t change.
