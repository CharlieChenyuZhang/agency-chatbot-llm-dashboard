SELECT

### Assistant: For top 3 per country, we can use a window function:

```sql
WITH customer_ltv AS (
    SELECT
        c.customer_id,
        c.full_name,
        c.country_code,
        SUM(o.order_total) AS lifetime_value
    FROM public.crm_customers c
    JOIN public.sales_orders o ON o.customer_id = c.customer_id
    GROUP BY c.customer_id, c.full_name, c.country_code
),
ranked AS (
    SELECT
        customer_id,
        full_name,
        country_code,
        lifetime_value,
        RANK() OVER (
            PARTITION BY country_code
            ORDER BY lifetime_value DESC
        ) AS country_rank
    FROM customer_ltv
)
SELECT
    customer_id,
    full_name,
    country_code,
    lifetime_value
FROM ranked
WHERE country_rank <= 3
ORDER BY country_code, lifetime_value DESC;
```

Run that to get the top 3 customers (by lifetime value) in each country.
