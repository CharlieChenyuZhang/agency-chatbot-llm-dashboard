I’ll outline the structure first, then we can tweak it.

1) Sheet layout

Create three sheets:
- `Settings`
- `Budget`
- `Transactions`

**Settings sheet (one-time setup)**

Columns:
- A: Category
- B: Type (Fixed / Variable / Flex / Savings)
- C: Monthly Target

Example rows:
- Rent | Fixed   | 1500
- Groceries | Variable | 400
- Gas | Variable | 150
- Eating out | Variable | 200
- Subscriptions | Fixed | 80
- Flex | Flex | 200
- Savings | Savings | 0   (this will grow from leftovers)

**Transactions sheet**

Columns:
- A: Date
- B: Description
- C: Category (data-validated from `Settings!A:A`)
- D: Amount (negative for expense, positive for income if you log income here)

**Budget sheet**

We’ll summarize by month here:
- A: Category
- B: Monthly Target
- C: Actual Spent
- D: Leftover (or Overspent)
- E: Covered by Flex
- F: To/From Savings

2) Basic formulas (for one month to start)

On `Budget!A2:A`, list categories from `Settings!A:A`.

In `Budget!B2` (Monthly Target), use:
```gs
=IFERROR(VLOOKUP(A2, Settings!A:C, 3, FALSE), 0)
```
Copy down.

In `Budget!C2` (Actual Spent for a given month, say March 2025):
```gs
=SUMIFS(Transactions!$D:$D, Transactions!$C:$C, $A2,
        Transactions!$A:$A, ">=" & DATE(2025,3,1),
        Transactions!$A:$A, "<=" & DATE(2025,3,31))
```
Copy down. (We can make the dates dynamic later.)

In `Budget!D2` (Leftover / Overspent):
```gs
= B2 - C2
```
Positive result = leftover, negative = overspent.

3) Automatic rules concept

- For **non-Flex, non-Savings categories**:
  - If `D` > 0 → that amount goes to Savings.
  - If `D` < 0 → that amount (absolute value) is requested from Flex, up to remaining Flex funds.

- For **Flex**:
  - Starts with its target (e.g., 200).
  - Is reduced by all category overspends it covers.
  - If it runs out, overspends just stay as overspends (no magic money).

- H1: Overspend

In `Budget!H2`:
```gs
=IF(D2 < 0, -D2, 0)
```
Copy down. Now H shows overspend as positive numbers.

4) Simple Flex coverage assumption

To keep things manageable, we’ll use this rule:
- Total Flex available = Flex’s target (B at Flex row).
- Flex covers overspend proportionally or in full, as long as total overspends ≤ Flex.

First, total overspend (all non-Flex, non-Savings categories):

In `Budget!M1`:
```gs
=SUMIFS(H:H, G:G, "<>Flex", G:G, "<>Savings")
```

Flex target:

In `Budget!M2`:
```gs
=INDEX(B:B, $L$1)
```

Now in each category row, how much Flex actually covers:

Add column:
- E1: Covered by Flex

In `Budget!E2`:
```gs
=IF(AND(G2<>"Flex", G2<>"Savings", H2>0),
   IF($M$1 <= $M$2,
      H2,                              
      H2 * ($M$2 / $M$1)               
   ),
   0
)
```
Copy down.

This does:
- If total overspend ≤ Flex target → Flex covers 100% of each overspend.
- If total overspend > Flex target → Flex partially covers overspends proportionally.

5) Leftover or shortfall after Flex

Adjust `D` to show net leftover after Flex:

Change `Budget!D2` to:
```gs
= B2 - C2 + E2
```
Because E2 is money “added back” from Flex to offset overspend.

Flex’s own net leftover:

On the Flex row (automatically, same formula as above):
- Its overspend column H is likely 0.
- But we need to reduce Flex by the total coverage it provided.

In a new column:
- N1: Flex Used

In `Budget!N1`:
```gs
=SUM(E:E)
```

Then on the Flex row, leftover is basically:
`B(Flex) - N(Flex)`, but since D already calculates `B - C + E`, we can interpret:

- Flex actual spending is whatever you tag as Flex in `Transactions`.
- E from other rows is money Flex “gave away”.

To avoid overcomplicating, you can just interpret:
- `D` on the Flex row as `Remaining Flex` at month end, knowing E for other rows is what came out of Flex.

6) Savings allocation

In a new column:
- F1: To/From Savings

In `Budget!F2`:
```gs
=IF(G2="Savings", 0, MAX(D2, 0))
```
Copy down.

Then on the Savings row (where `G` = "Savings"), in `F`:
```gs
=SUMIFS(F:F, G:G, "<>Savings")
```

So Savings gets the sum of all positive leftovers from non-Savings categories.
