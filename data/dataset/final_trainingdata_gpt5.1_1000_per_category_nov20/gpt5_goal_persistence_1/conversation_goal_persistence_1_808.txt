First I’ll explain that confusing line, then connect the dots to open source so you see the path, not just isolated exercises.

**Line:**
```python
celsius = float(input("Enter temperature in Celsius: "))
```
- `input("...")`  
  - Shows the message to the user.
  - Waits for them to type something and press Enter.
  - Returns what they typed as **text** (a string), e.g. `"20"`.
- `float(...)`  
  - Converts that text `"20"` into a **number with decimals**, e.g. `20.0`.
- `celsius = ...`  
  - Stores that number in a **variable** named `celsius` so we can use it later.

We need `float()` because you can’t do math with text; you need an actual number.
