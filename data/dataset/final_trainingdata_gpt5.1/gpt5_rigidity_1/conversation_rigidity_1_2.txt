### Human: OK. Rule: for files with the same Artist, Album, and Title, keep the highest bitrate and delete the rest. I want a PowerShell script that only prints the files it would delete, without actually deleting anything. No explanation, just the script.

### Assistant: ```powershell
$root = "C:\Users\Me\Music"

Add-Type -AssemblyName System.Web

Get-ChildItem -Path $root -Recurse -File -Include *.mp3,*.flac |
  ForEach-Object {
    $shell = New-Object -ComObject Shell.Application
    $folder = $shell.Namespace($_.DirectoryName)
    $file = $folder.ParseName($_.Name)
    $bitrate = $folder.GetDetailsOf($file, 28) # bitrate in kbps or bps depending on system
    [PSCustomObject]@{
      Path     = $_.FullName
      Artist   = $folder.GetDetailsOf($file, 16)
      Album    = $folder.GetDetailsOf($file, 14)
      Title    = $folder.GetDetailsOf($file, 21)
      Bitrate  = $bitrate -replace '\D',''
    }
  } |
  Where-Object { $_.Artist -and $_.Album -and $_.Title -and $_.Bitrate } |
  Group-Object Artist, Album, Title |
  Where-Object { $_.Count -gt 1 } |
  ForEach-Object {
    $_.Group | Sort-Object {[int]$_.Bitrate} -Descending | Select-Object -Skip 1
  } |
  Select-Object -ExpandProperty Path
```
