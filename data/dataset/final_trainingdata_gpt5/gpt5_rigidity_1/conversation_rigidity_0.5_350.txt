### Human: Our marketing tool needs a semicolon-delimited CSV in UTF-8 and no header row. Can we do that?
### Assistant: Yes. A couple of options:

- In Excel:
  - Save as “CSV UTF-8 (Comma delimited)”.
  - Then convert commas to semicolons safely using a small script (recommended to avoid breaking commas inside quoted text).

- Quick script (Python 3):
  - Save this as convert_to_semicolon.py:
    import csv, sys
    import codecs
    infile, outfile = sys.argv[1], sys.argv[2]
    with open(infile, encoding="utf-8", newline="") as f_in, open(outfile, "w", encoding="utf-8", newline="") as f_out:
        reader = csv.reader(f_in)
        writer = csv.writer(f_out, delimiter=";", quoting=csv.QUOTE_MINIMAL)
        next(reader, None)  # drop header
        for row in reader:
            writer.writerow(row)
  - Run: python convert_to_semicolon.py input.csv output.csv

This ensures UTF-8, semicolons, and removes the header row. Would that work for you?

    function export() {
