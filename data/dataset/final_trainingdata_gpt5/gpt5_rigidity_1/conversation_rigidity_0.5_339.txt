### Human: I’m using Next.js and Tailwind. Can you outline setup to move fast?
### Assistant: Quick setup
- Create app: npx create-next-app@latest portfolio
- Add Tailwind: npm i -D tailwindcss postcss autoprefixer && npx tailwindcss init -p
- Configure globals: set Tailwind content paths, add base styles, define color themes
- Routes: /, /projects, /projects/[slug] for five projects
- Components: Layout, Header, Footer, Card, Badge, ChartWrapper, ChatUI, ProductCard, Stepper
- Utilities: hooks for useLocalStorage, useToggle, fetcher; lib/api for mock data
- Data: JSON seed files for products, FAQs, datasets; .env for keys
- Deploy: connect GitHub to Vercel; set environment variables; enable Preview deployments
- Analytics: Vercel Analytics or Umami
- QA: ESLint/Prettier, GitHub Actions for lint/build on PRs

Structure
- app/ or pages/
- components/
- lib/
- public/ (og images, demo assets)
- data/ (seed JSON)

This gets you shipping reliably by the first weekend.
