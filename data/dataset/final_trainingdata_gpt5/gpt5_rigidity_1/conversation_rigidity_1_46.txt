### Human: Give me the exact steps to install Python and VS Code on Windows and set up Git.
### Assistant: - Install Python: download from python.org > Windows; run installer and check “Add Python to PATH.”

- Install Git from git-scm.com; accept defaults (use VS Code as Git editor if you like).
- Configure Git: git config --global user.name "Your Name" and git config --global user.email "you@example.com".
- Create SSH key: ssh-keygen -t ed25519 -C "you@example.com"; add the public key to GitHub; test with ssh -T git@github.com.

### Human: Explain how to make a pull request with step-by-step instructions; keep it under 2 sentences per step, 8 steps max.
### Assistant: - Fork the repo on GitHub and clone your fork: git clone <your-fork-url>.
- Create a branch: git checkout -b fix/short-descriptor.
- Make your changes and run tests/lint locally.
- Stage and commit: git add .; git commit -m "DOC: fix typo in DataFrame.dropna".
- Push your branch: git push -u origin fix/short-descriptor.
- Open a Pull Request on GitHub from your branch to the upstream repo.
- Fill out the PR template and link any related issues.
- Respond to review comments, push updates, and wait for merge.
