### Human: Yes, give me a Zapier setup. Keep it minimal.
### Assistant: Minimal Zapier setup (create events from tasks)
- Trigger: Notion — New Database Item (choose Tasks)
- Filter: Only continue if Due Date exists and Status is not Done
- Action: Google Calendar — Create Detailed Event
  - Summary: Task Name
  - Start/End: Due Date (same date/time if you use times; otherwise all-day)
  - Description: link to the Notion page
  - Calendar: your target calendar

Optional second Zap for updates
- Trigger: Notion — Updated Database Item (Tasks)
- Filter: Due Date exists
- Action: Google Calendar — Update Event (store the Event ID on the task the first time via a property)

Tell me if you want me to add the Event ID property to Tasks.
