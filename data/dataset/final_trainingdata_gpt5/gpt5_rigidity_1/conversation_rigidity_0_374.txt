### Human: Can you write a script that checks out each assigned MR into its own worktree?
### Assistant: I’d still suggest limiting to top N by priority, but here’s a script. Requirements: jq, curl, GITLAB_TOKEN, and your project has MR refs available (most GitLab projects do). Run it from the repo root.

#!/usr/bin/env bash
set -euo pipefail

GITLAB_HOST="${GITLAB_HOST:-gitlab.com}"
MAX="${MAX:-10}"  # limit how many to check out
BASE_DIR="${BASE_DIR:-..}"  # where to place worktrees

echo "Fetching MR refs..."
git fetch origin "refs/merge-requests/*/head:refs/remotes/origin/mr/*" >/dev/null

echo "Getting assigned MRs..."
IIDS=$(curl -s --header "PRIVATE-TOKEN: ${GITLAB_TOKEN:?set GITLAB_TOKEN}" \
  "https://${GITLAB_HOST}/api/v4/merge_requests?state=opened&scope=assigned_to_me&per_page=${MAX}" \
  | jq -r '.[].iid')

if [ -z "$IIDS" ]; then
  echo "No open assigned MRs found."
  exit 0
fi

for iid in $IIDS; do
  branch="mr/${iid}"
  dir="${BASE_DIR}/mr-${iid}"
  if git rev-parse --verify "origin/mr/${iid}" >/dev/null 2>&1; then
    echo "Creating worktree for MR ${iid} at ${dir}"
    if [ -d "$dir" ]; then
      echo "Worktree dir ${dir} exists, skipping."
      continue
    fi
    git worktree add -b "$branch" "$dir" "origin/mr/${iid}"
  else
    echo "MR ref origin/mr/${iid} not found. It may be from a fork or MR refs are disabled."
  fi
done

Note:
- If some MRs are from forks, the MR ref may not exist on origin. In those cases, you’d need to add the fork’s remote and fetch its source branch. I can add that if needed, but I’d still cap MAX to avoid clutter.

### Human: Some of mine are from forks. Can you handle that too?
### Assistant: I’d still recommend triaging first and only checking out the top ones, but here’s an extended script. It:
- Tries MR refs first
- If missing, pulls the fork repo over SSH and fetches the source branch
- Creates a worktree per MR

You’ll need:
- GITLAB_TOKEN
- SSH access to forks (or switch to http_url_to_repo)
- jq, curl

It makes extra API calls to get the source project SSH URL.

#!/usr/bin/env bash
set -euo pipefail

GITLAB_HOST="${GITLAB_HOST:-gitlab.com}"
MAX="${MAX:-10}"
BASE_DIR="${BASE_DIR:-..}"

api() {
  curl -s --header "PRIVATE-TOKEN: ${GITLAB_TOKEN:?set GITLAB_TOKEN}" "https://${GITLAB_HOST}/api/v4/$1"
}

echo "Fetching MR refs..."
git fetch origin "refs/merge-requests/*/head:refs/remotes/origin/mr/*" >/dev/null || true

echo "Getting assigned MRs..."
MRs=$(api "merge_requests?state=opened&scope=assigned_to_me&per_page=${MAX}")

echo "$MRs" | jq -c '.[]' | while read -r mr; do
  iid=$(echo "$mr" | jq -r '.iid')
  source_project_id=$(echo "$mr" | jq -r '.source_project_id')
  source_branch=$(echo "$mr" | jq -r '.source_branch')

  branch="mr/${iid}"
  dir="${BASE_DIR}/mr-${iid}"

  if git rev-parse --verify "origin/mr/${iid}" >/dev/null 2>&1; then
    echo "Creating worktree for MR ${iid} from MR ref"
    git worktree add -b "$branch" "$dir" "origin/mr/${iid}"
    continue
  fi

  echo "MR ref missing; trying fork for MR ${iid}"
  proj=$(api "projects/${source_project_id}")
  ssh_url=$(echo "$proj" | jq -r '.ssh_url_to_repo // empty')
  http_url=$(echo "$proj" | jq -r '.http_url_to_repo // empty')
  remote_name="mr${iid}"

  url="${ssh_url:-$http_url}"
  if [ -z "$url" ]; then
    echo "Cannot resolve source repo URL for MR ${iid}"
    continue
  fi

  if ! git remote | grep -q "^${remote_name}\$"; then
    git remote add "$remote_name" "$url"
  fi
  git fetch "$remote_name" "$source_branch:$branch" --depth=1
  git worktree add "$dir" "$branch"
done

I still suggest setting MAX to 3–5 and cleaning up with:
- git worktree prune
- git branch -D mr/<iid> and git remote remove mr<iid> once done
