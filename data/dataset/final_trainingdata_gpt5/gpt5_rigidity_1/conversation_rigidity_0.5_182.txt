### Human: Yes, I use Todoist for tasks. How should I handle tasks vs notes?
### Assistant: Keep tasks in Todoist; keep context in notes. Practical workflow:
- In notes, write actions as lines starting with [ ] and a short verb phrase.
- During inbox or meeting processing, send tasks to Todoist and add a backlink to the note:
  - Example task title: Draft outreach email @ Note:[[Project – Client A]] due:2025-01-15
- In the note, replace [ ] with [x] and add “moved to Todoist: <task link>” (optional).
- For capture speed on iPhone, use a Shortcut that:
  1) Prompts you for a task
  2) Adds it to Todoist with a link to today’s Daily Note (or a chosen note)
  3) Appends a short log line to your Daily Note for traceability

If full linking feels heavy, a lightweight alternative is to include the note title or a unique shorthand (#ClientA) in the Todoist task, and later search by that tag or title.

### Human: I get overwhelmed by tags. What taxonomy do you recommend?
### Assistant: Keep it extremely simple:
- Type tags: #idea, #meeting, #lit, #project, #ref
- Topic tags: choose up to 7 top-level topics you actually use (e.g., #work, #writing, #health, #learning, #finance, #family, #tools). Avoid nesting at first.
- Status tags (optional): #seed (new), #growing (in progress), #evergreen (stable)
Rules:
- Max 2 tags per note: one Type, one Topic. Status only if it helps you.
- Prefer folders for lifecycle (Inbox/Fleeting/Projects/Reference) and use tags sparingly for filtering.

If you later want more nuance, add controlled sub-tags only after 30 days of consistent use.

### Human: Can we add a weekly and monthly review checklist?
### Assistant: Weekly review (15–30 min):
- Empty 00 Inbox: file, delete, or convert to tasks
- Process Fleeting notes: promote 0–3 into Projects/Reference; archive the rest
- Review Projects: update next actions; close or pause anything stale
- Sweep Daily notes: convert lingering [ ] items to Todoist or mark [x]
- Check calendar next 2 weeks; prep meeting templates
- Tag hygiene: remove duplicate or unused tags

Monthly review (45–60 min):
- Project health: for each active project, write one-sentence status and next milestone
- Reference pruning: delete or archive dead notes
- Literature: summarize top 3 learnings and link them to relevant projects
- System tweak: change 1 thing only (e.g., a tag, a template) to avoid churn
- Wins log: list 3–5 wins; link supporting notes

### Human: What about syncing and using this while traveling offline?
### Assistant: Since you’re offline-first, you’re set. For sync:
- Use Obsidian Sync or OneDrive/Dropbox. Obsidian Sync handles conflicts better and supports mobile; cloud drives are fine but can cause merge conflicts if you edit the same file on two devices before sync.
- Practical rule: when traveling, pick one primary device for editing a given day’s Daily note; let it sync before switching devices.
- If a conflict happens, Obsidian creates a conflict copy; during weekly review, merge the lines and delete the extra file.

If you prefer zero-cost and minimal risk, OneDrive works well if you avoid simultaneous edits on the same file across devices.
