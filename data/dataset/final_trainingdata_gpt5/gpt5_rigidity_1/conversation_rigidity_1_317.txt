### Human: Fine. Give me a Drive cleanup checklist I can do in 30 minutes, tailored for tag-style organization.
### Assistant: 30-minute Google Drive cleanup (tag-style, no folder reshuffles)

- Minute 0–3: Set up “tag” signals
  - Open drive.google.com.
  - Click Priority (left sidebar). Create a Workspace named Weekly.
  - Decide: Star = priority; Workspace = active set; filename suffix [tags] for topics.

- Minute 3–10: Triage Recent
  - Open Recent view.
  - For each file you still care about:
    - Rename for clarity: keep a clear noun + date; add tags at the end, e.g., Budget 2025-01 [finance q1].
    - Star it if it’s important.
    - Add shortcut to the Weekly workspace (click Add to Workspace or Add shortcut to Drive > Priority > Weekly).

- Minute 10–18: Surface owned docs quickly
  - In search bar, click filter icon.
  - Set Owner: Owned by me; Type: Documents (run once), then Spreadsheets (run again).
  - Sort by Last modified.
  - For the top 20 items you still use: rename with tags, Star, and add shortcuts to Weekly.

- Minute 18–24: Clear clutter
  - Open Shared with me; sort by Last opened by me; remove from view anything you won’t use (this doesn’t delete for others).
  - Open Trash; permanently delete items you’re sure you don’t need.

- Minute 24–30: Orphans and wrap-up
  - In search filters, set Location: Not in a folder (if available) or use Advanced search > Location to find loose/orphaned files.
  - For any you keep: rename with tags, Star, and add shortcuts to Weekly.
  - Review Weekly workspace; remove any shortcut you won’t work on this week.

Maintain weekly: 10-minute pass to rename/tag new files, Star priorities, and adjust Weekly workspace.

### Human: One more thing: suggest 5 filename conventions for tag-style organization.
### Assistant: Here are 5 simple, tag-friendly patterns with examples:

1) Name - Short description - YYYY-MM-DD [tag1 tag2]
   Example: Proposal - ACME Q1 - 2025-01-15 [sales draft]

2) YYYY-MM Project - Artifact [tag1 tag2]
   Example: 2025-02 Website - Sitemap [ux client-acme]

3) Client - Topic - Version - YYYYMMDD [tag]
   Example: ACME - Onboarding Guide - v3 - 20250210 [ops]

4) Area - Name - Period [tags]
   Example: Finance - Budget - 2025-Q1 [review]

5) Name_vMajorMinor - Context [tags]
   Example: BrandStyle_v1.4 - Web [design]

Use square brackets at the end for all tags to keep searches simple.
