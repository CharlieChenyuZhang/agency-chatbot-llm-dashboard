### Human: I want to keep my fork private. Is that possible?
### Assistant: For public repositories on GitHub.com, private forks aren’t allowed (unless you’re on certain Enterprise settings). Practical alternatives:
- Create a private mirror (duplicate repo) in your account, then track upstream manually or via automation.
- If you only need to stage changes privately before a PR, you can work locally and push a branch to a new private repo, then later open a PR from a temporary public fork when ready.

Private mirror steps:
1) Create a new empty private repo on your account, e.g., alexk/metaseq-private (no README/license/ignore).
2) Mirror-push:
   - git clone --bare https://github.com/facebookresearch/metaseq.git
   - cd metaseq.git
   - git push --mirror https://github.com/alexk/metaseq-private.git
   - cd ..
   - rm -rf metaseq.git
3) Use it normally:
   - git clone https://github.com/alexk/metaseq-private.git
   - cd metaseq-private
   - git remote add upstream https://github.com/facebookresearch/metaseq.git

Note: Check the project’s license to confirm private mirroring aligns with your use.

### Human: It’s main. Can you write the YAML?
### Assistant: Add this file to your private repo at .github/workflows/upstream-sync.yml

name: Upstream sync
on:
  schedule:
    - cron: "0 3 * * 1"  # Mondays at 03:00 UTC
  workflow_dispatch:

jobs:
  sync:
    runs-on: ubuntu-latest
    steps:
      - name: Checkout
        uses: actions/checkout@v4
        with:
          fetch-depth: 0

      - name: Set up Git
        run: |
          git config user.name "github-actions[bot]"
          git config user.email "github-actions[bot]@users.noreply.github.com"

      - name: Add upstream and fetch
        run: |
          git remote add upstream https://github.com/facebookresearch/metaseq.git || true
          git fetch upstream

      - name: Merge upstream/main into main
        run: |
          git checkout main
          git merge --ff-only upstream/main || git merge --no-edit upstream/main

      - name: Push changes
        env:
          GIT_AUTH_TOKEN: ${{ secrets.UPSTREAM_SYNC_TOKEN }}
        run: |
          repo_url="https://${GIT_AUTH_TOKEN}@github.com/${{ github.repository }}.git"
          git push "$repo_url" main

Notes:
- Create a PAT in your GitHub account with repo scope.
- Add it as a secret named UPSTREAM_SYNC_TOKEN in your private repo’s Settings > Secrets and variables > Actions.
- If you have branch protection, allow the workflow to push or use a service branch and a PR-based sync instead.
