### Human: Okay, give me the quick Git crash course.
### Assistant: Minimal Git you need:
- Fork the repo on GitHub.
- Clone your fork: git clone URL-of-your-fork
- Create a branch: git checkout -b fix-issue-123
- Make changes locally.
- Stage and commit: git add . then git commit -m "Short summary: what/why"
- Push: git push -u origin fix-issue-123
- Open a Pull Request from your fork/branch on GitHub.

If installing Git is a blocker, GitHub Desktop lets you do this with buttons. Also, if you prefer the web editor for tiny changes, GitHub will create a fork and branch for you when you click “Edit this file.”

### Human: I tried pushing and got “permission denied.” What now?
### Assistant: Likely you cloned the upstream repo instead of your fork, or you’re using HTTPS vs SSH with mismatched auth. Quick fix:
- Verify remotes: git remote -v
- If you see the upstream repo as origin, point origin to your fork:
  - git remote set-url origin https://github.com/your-username/geopandas.git
- Or add upstream separately:
  - git remote add upstream https://github.com/geopandas/geopandas.git
- Then push your branch to your fork:
  - git push -u origin fix-issue-123

If it still fails, try GitHub Desktop or the web editor for now, and we can fix CLI auth later.
