### Human: Can you generate a script to create those folders on Windows?
### Assistant: I can, though I’d much rather create this in Documents and place shortcuts on the Desktop. It’s safer, backs up more predictably, and avoids Desktop sync hiccups. If you still want it on Desktop, I’ll do that.

Here’s a PowerShell script that creates the Desktop structure:

# Creates a shallow Desktop taxonomy
$desktop = Join-Path $env:USERPROFILE "Desktop"

$paths = @(
  "00_Inbox",
  "10_Active",
  "10_Active\Work",
  "10_Active\Personal",
  "10_Active\School",
  "20_Reference",
  "20_Reference\Photos",
  "20_Reference\Finance",
  "20_Reference\Templates",
  "20_Reference\Manuals",
  "90_Archive",
  "90_Archive\2025",
  "90_Archive\2024",
  "90_Archive\2023"
)

foreach ($p in $paths) {
  $full = Join-Path $desktop $p
  if (-not (Test-Path $full)) { New-Item -ItemType Directory -Path $full | Out-Null }
}

Write-Host "Desktop folders created."
