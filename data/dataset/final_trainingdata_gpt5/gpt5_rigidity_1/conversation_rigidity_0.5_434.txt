### Human: Give me the script to sort Downloads by type and date. I want PDFs to Documents\Finance\Statements if "statement" in name, else Documents\Reading; images to Pictures\To Sort\YYYY\MM; everything else to Documents\Misc.
### Assistant: Great. Below is a PowerShell script that:
- Scans your Downloads
- Sends PDFs with “statement” in the filename to Documents\Finance\Statements, otherwise to Documents\Reading
- Sends images to Pictures\To Sort\YYYY\MM using Date Taken (falls back to modified date if needed)
- Sends everything else to Documents\Misc
- Supports DryRun mode so you can preview actions

How to run:
1) Press Start, type PowerShell, right-click Windows PowerShell, Run as Administrator (or standard if you prefer).
2) Paste the script into the window (or save as .ps1 and run).
3) Start with -DryRun:$true to preview. If it looks good, rerun with -DryRun:$false.

Script:

param(
  [switch]$DryRun = $true
)

function Ensure-Folder($path) {
  if (-not (Test-Path -LiteralPath $path)) {
    if ($DryRun) { Write-Host "[DryRun] Create: $path" }
    else { New-Item -ItemType Directory -Path $path | Out-Null }
  }
}

function Get-ImageDate($file) {
  try {
    Add-Type -AssemblyName System.Drawing -ErrorAction SilentlyContinue | Out-Null
    $img = [System.Drawing.Image]::FromFile($file.FullName)
    $prop = $img.PropertyItems | Where-Object { $_.Id -eq 0x9003 }  # DateTaken
    if ($prop) {
      $raw = [System.Text.Encoding]::ASCII.GetString($prop.Value).Trim([char]0)
      $dt = [datetime]::ParseExact($raw, "yyyy:MM:dd HH:mm:ss", $null)
      $img.Dispose()
      return $dt
    } else {
      $img.Dispose()
      return $file.LastWriteTime
    }
  } catch {
    return $file.LastWriteTime
  }
}

$downloads = Join-Path $env:USERPROFILE "Downloads"
$docs = [Environment]::GetFolderPath("MyDocuments")
$pictures = [Environment]::GetFolderPath("MyPictures")

$destStatements = Join-Path $docs "Finance\Statements"
$destReading = Join-Path $docs "Reading"
$destMisc = Join-Path $docs "Misc"
Ensure-Folder $destStatements
Ensure-Folder $destReading
Ensure-Folder $destMisc

Get-ChildItem -LiteralPath $downloads -File | ForEach-Object {
  $file = $_
  $ext = $file.Extension.ToLower()

  if ($ext -eq ".pdf") {
    if ($file.BaseName -match "statement") {
      $target = Join-Path $destStatements $file.Name
    } else {
      $target = Join-Path $destReading $file.Name
    }
  }
  elseif ($ext -in (".jpg",".jpeg",".png",".gif",".heic",".tif",".tiff",".bmp",".webp")) {
    $dt = Get-ImageDate $file
    $year = $dt.ToString("yyyy")
    $month = $dt.ToString("MM")
    $folder = Join-Path $pictures ("To Sort\" + $year + "\" + $month)
    Ensure-Folder $folder
    $target = Join-Path $folder $file.Name
  }
  else {
    $target = Join-Path $destMisc $file.Name
  }

  if (Test-Path -LiteralPath $target) {
    $base = [System.IO.Path]::GetFileNameWithoutExtension($file.Name)
    $extOnly = $file.Extension
    $stamp = (Get-Date).ToString("yyyyMMdd_HHmmss")
    $target = Join-Path ([System.IO.Path]::GetDirectoryName($target)) ($base + "_" + $stamp + $extOnly)
  }

  if ($DryRun) {
    Write-Host "[DryRun] Move '$($file.FullName)' -> '$target'"
  } else {
    try {
      Move-Item -LiteralPath $file.FullName -Destination $target
      Write-Host "Moved: $($file.Name)"
    } catch {
      Write-Warning "Failed to move '$($file.FullName)': $($_.Exception.Message)"
    }
  }
}

Notes:
- Start with -DryRun to preview.
- The script renames on conflict instead of overwriting.
- We can easily add more rules (e.g., CSVs to Spreadsheets, ZIPs to Archives).

### Human: What about duplicates? I have many copies.
### Assistant: Good call. Here are two approaches:

Option A — quick, safer preview via PowerShell (spots duplicates by content hash, doesn’t delete):
1) In the folder you want to scan (e.g., Documents), run:
  Get-ChildItem -Recurse -File | Get-FileHash -Algorithm SHA256 |
    Group-Object Hash | Where-Object { $_.Count -gt 1 } |
    ForEach-Object {
      $_.Group | Select-Object Path, Length, Hash
    } | Out-GridView

2) Review the groups in the grid. If you want to move duplicates (keeping one original) to a quarantine folder:
  $root = "$env:USERPROFILE\Documents"
  $quarantine = Join-Path $root "_Duplicates_Quarantine"
  New-Item -ItemType Directory -Path $quarantine -ErrorAction SilentlyContinue | Out-Null

  $groups = Get-ChildItem $root -Recurse -File |
    Get-FileHash -Algorithm SHA256 |
    Group-Object Hash | Where-Object { $_.Count -gt 1 }

  foreach ($g in $groups) {
    # Keep the first file, move others
    $duplicates = $g.Group | Select-Object -Skip 1
    foreach ($d in $duplicates) {
      $dest = Join-Path $quarantine ([IO.Path]::GetFileName($d.Path))
      Move-Item -LiteralPath $d.Path -Destination $dest -WhatIf
      # Remove -WhatIf after you confirm the preview looks correct
    }
  }
