### Human: If I miss a day, should I double the next day to catch up?
### Assistant: I wouldn’t. Doubling tends to cause avoidance and burnout. Since you want a hard streak, use the emergency rule to avoid misses:

### Human: Can you track my word counts automatically?
### Assistant: I can’t access your files or run things automatically for you. But you can auto-log your Google Doc word count to a Google Sheet with an Apps Script and a daily trigger. Then you’ll see a dated log and streak status.

Want the script and setup steps?

### Human: Yes, give me the script.
### Assistant: Steps:
1) Put each day’s writing in a single Google Doc, or use one master Doc. Note the Doc ID (in the URL).
2) In Google Drive, create a Google Sheet called “Writing Log” with columns: Date, WordCount, Streak.
3) In the Sheet, Extensions > Apps Script. Paste this:

const DOC_ID = 'PASTE_YOUR_DOC_ID';
const SHEET_NAME = 'Sheet1'; // or your sheet name
const TARGET = 500;

function logWordCount() {
  const doc = DocumentApp.openById(DOC_ID);
  const text = doc.getBody().getText();
  const words = countWords(text);
  const ss = SpreadsheetApp.getActiveSpreadsheet();
  const sheet = ss.getSheetByName(SHEET_NAME);
  const today = new Date();
  const lastRow = sheet.getLastRow();
  let prevStreak = 0;
  if (lastRow >= 2) {
    prevStreak = sheet.getRange(lastRow, 3).getValue(); // Streak column
  }
  const newStreak = words >= TARGET ? prevStreak + 1 : 0;
  sheet.appendRow([formatDate(today), words, newStreak]);
}

function countWords(s) {
  if (!s) return 0;
  // Normalize whitespace and punctuation
  const cleaned = s.replace(/\s+/g, ' ').trim();
  if (!cleaned) return 0;
  return cleaned.split(' ').length;
}

function formatDate(d) {
  return Utilities.formatDate(d, Session.getScriptTimeZone(), 'yyyy-MM-dd');
}

function createDailyTrigger() {
  // Runs at 23:55 daily
  ScriptApp.newTrigger('logWordCount')
    .timeBased()
    .atHour(23)
    .nearMinute(55)
    .everyDays(1)
    .create();
}

4) Save, then run createDailyTrigger() once and authorize.
5) It will append each day’s word count and streak. If you prefer one doc per day, we can adapt the script to check the most recent doc in a folder.
