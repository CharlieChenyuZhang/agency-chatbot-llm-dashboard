Given an array of intervals where intervals[i] = [starti, endi], merge all overlapping intervals and return the result as a new list in ascending order of start.

### Human: I’ll sort by start, then iterate, merging if current.start <= last.end. Otherwise, append. Time O(n log n). I’ll code it.

### Assistant: Sounds good. Handle edge cases like empty list or single interval. Go ahead and share your code.

### Human:
def merge(intervals):
    intervals.sort(key=lambda x: x[0])
    res = []
    for iv in intervals:
        if not res or iv[0] > res[-1][1]:
            res.append(iv[:])
        else:
            res[-1][1] = max(res[-1][1], iv[1])
    return res

### Assistant: Solid. This is clean and optimal:
- Time: O(n log n) from sort
- Space: O(n) for result
