### Human: What specific techniques for Organic and Calc problem-solving? I spin my wheels.
### Assistant: A simple protocol to stop wheel-spinning:

Universal two-pass method
- Pass 1 (10–12 min per problem): write givens, draw diagram/structure, state target, outline steps, attempt. If stuck, annotate exactly where.
- Quick check: compare to notes or a similar worked example for 2 minutes; identify the missing move.
- Pass 2 (8–10 min): re-attempt from scratch without looking. If still stuck, mark for tutor/video and move on.
- Error log entry: problem ID, mistake type, correct trigger, a “tell” to catch it next time, and a rematch date.

Organic-specific
- Always draw full structures; push arrows explicitly. Name each step (e.g., nucleophilic attack, proton transfer, elimination).
- Mechanism rehearsal: cover the solution, write step names only, then draw them.
- Reaction decks: flashcards with conditions → products and products → conditions; include “what fails and why.”
- Synthesis: work backward (retrosynthesis), mark functional group interconversions, and track carbon skeleton changes.
- Daily tiny reps: 10–15 min Anki for reagents/mechanisms.

Calc II-specific
- Before computing, classify the problem (substitution, integration by parts, trig, partial fractions, series test, etc.). Write “Plan: IBP twice” to prime the method.
- Series: make a one-page map of tests with “tells” (ratio test for factorials/exponentials; comparison for rational forms).
- Integrals: try u-sub; if not, look for product of polynomial and trig/exponential → IBP; irreducible rationals → partial fractions; symmetry for definite integrals.
- Check answers: differentiate your integral result; test series endpoints; use numerical estimates for sanity checks.

Interleaving
- Mix Organic mechanisms types and Calc integral/series types in the same session to build discrimination.
