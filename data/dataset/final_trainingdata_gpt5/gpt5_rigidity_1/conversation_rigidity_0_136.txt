### Human: Networking trips me up. Explain NAT gateway vs Internet gateway quickly.
### Assistant: My go-to mental model:
- Internet Gateway (IGW): Lets resources in public subnets have bidirectional Internet access when their route table points 0.0.0.0/0 to an IGW and the instance has a public IP. Think “public doorway.”
- NAT Gateway: Lets instances in private subnets initiate outbound Internet connections without being reachable from the Internet. Route table in private subnet points 0.0.0.0/0 to the NAT in a public subnet. Think “one-way outbound hatch.”

Key differences
- Placement: IGW attaches to the VPC; NAT lives in a public subnet.
- Direction: IGW allows inbound and outbound for public IP resources; NAT is outbound-only for private subnets.
- IPs: IGW uses the instance’s public IP; NAT uses an Elastic IP and performs translation.
- Cost/fault tolerance: NAT has hourly + data charges; use per-AZ NATs for HA.
