### Human: Can you help me add a contact form and basic SEO?
### Assistant: Absolutely.
Contact form (Netlify Forms):
- Create a page (e.g., content/contact/_index.md).
- In its layout, add a form with attributes: form name, method="POST", data-netlify="true".
- Minimal HTML:
  <form name="contact" method="POST" data-netlify="true">
    <input type="text" name="name" placeholder="Name" required>
    <input type="email" name="email" placeholder="Email" required>
    <textarea name="message" placeholder="Message" required></textarea>
    <button type="submit">Send</button>
  </form>
- Netlify will capture submissions automatically; you can add a hidden input called form-name matching the form’s name for robustness.

Basic SEO:
- In config, set title and description.
- PaperMod includes Open Graph and Twitter cards if you set params like images and social handles.
- Example fields to add in config:
  - title: Your Blog Title
  - params.description: Short site description
  - params.images: ["/images/cover.jpg"]
  - params.social:
      twitter: yourhandle
- For posts, include front matter:
  - title, description, date, categories, tags, draft (false), and optionally images.

Sitemaps and robots:
- Hugo auto-generates sitemap.xml.
- enableRobotsTXT = true handles robots.txt.
