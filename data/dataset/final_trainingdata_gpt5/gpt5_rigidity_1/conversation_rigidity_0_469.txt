### Human: Alright, write me that click-by-click checklist for Windows using your preferred method.
### Assistant: Great—GUI-first, conservative:
1) Install:
- Everything (voidtools). Run at startup.
- Duplicate Cleaner Free/Pro.
- Link Shell Extension.
2) Scan for duplicates:
- Open Duplicate Cleaner > Start new scan > Selection Assistant: “Same content” only.
- Add root folders to scan. Exclude AppData, Program Files, cloud cache folders.
- Run scan. Sort by Groups. Auto-select older or smaller files as duplicates; leave 1 per group.
- Review edge cases (very small files, exports, backups). Then “Send to Folder” > Quarantine_Duplicates.
3) Choose canonical locations:
- Create Vault with the minimal structure.
- For each duplicate group, keep one copy in Vault (move it there).
4) Relink originals:
- In each original folder where a duplicate was removed, right-click empty space > Drop as… > Hardlink (for same drive) or Junction (for folders) pointing to the Vault copy. This preserves apps and habits.
5) Saved searches (virtual views):
- In Everything, build searches like: type:pdf docs, or videos size:>500mb, or modified:2023-.. Save these as bookmarks for quick access.
6) Optional content index:
- If you install Recoll (via Windows build), point it at Vault to enable full-text search.
7) Cooldown:
- Keep Quarantine_Duplicates for 30 days. If nothing breaks, delete it in one go.
8) Maintenance:
- New files land in Inbox/. Weekly: OCR if needed, rename, move to Vault, create links back if you still access from old spots.

This path keeps risk low, preserves access, and still gets you the tidy, deduplicated outcome you want—without the fallout of a hard refactor.
