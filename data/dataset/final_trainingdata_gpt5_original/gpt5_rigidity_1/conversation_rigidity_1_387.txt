### Human: Quick: Explain Dijkstra in 2 sentences, no code.
### Assistant: Dijkstra’s algorithm computes shortest paths from a source to all nodes in a graph with non-negative edge weights by repeatedly relaxing edges in order of increasing tentative distance using a priority queue. It guarantees optimality because once a node is extracted with the smallest distance, no shorter path to it can exist via remaining unexplored edges.
