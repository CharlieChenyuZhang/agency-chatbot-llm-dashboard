### Human: I actually struggle with epsilon-delta. Can you show me a proof that lim(x→3) x^2 = 9?
### Assistant: Sure. Goal: For every ε > 0, find δ > 0 so that if |x − 3| < δ, then |x^2 − 9| < ε.

Work:
- |x^2 − 9| = |(x − 3)(x + 3)| = |x − 3| |x + 3|.
- We can control |x − 3| directly with δ, but |x + 3| depends on x. Bound it by keeping x near 3. If we require |x − 3| < 1, then x ∈ (2,4), so |x + 3| < 7.
- Then if |x − 3| < min(1, ε/7), we have |x^2 − 9| ≤ 7|x − 3| < 7(ε/7) = ε.

Therefore, choose δ = min(1, ε/7). That proves lim(x→3) x^2 = 9.

Intuition: x^2 changes roughly like 2*3*(x − 3) near x = 3, so bounding |x − 3| proportionally controls |x^2 − 9|.

### Human: Thanks. For linear algebra, what’s the difference between span and basis? Short example please.
### Assistant: - Span of a set of vectors is all linear combinations of them (the space you can reach by scaling and adding them).
- A basis is a set of vectors that both spans the space and is linearly independent (no vector in the set is a combination of the others). A basis is a minimal spanning set.

Example in R^2:
- v1 = (1,0). Span{v1} = all multiples of (1,0): the x-axis.
- v1 = (1,0), v2 = (0,1). Span{v1, v2} = all of R^2, and they’re independent → {v1, v2} is a basis of R^2.
- v1 = (1,2), v2 = (2,4). Span is still just the line y = 2x. They’re dependent, so not a basis of R^2.

### Human: I’m very visual. Can we visualize eigenvectors without Python?
### Assistant: Absolutely. Options:

- Spreadsheet method (no installs):
  1) In Google Sheets/Excel, pick a 2x2 matrix A (e.g., [[2,1],[0,1]]).
  2) Create a column of angles θ from 0 to 360°, form unit vectors v = (cos θ, sin θ).
  3) Compute Av for each v.
  4) Plot both v and Av as scatter plots with connected lines. Where Av aligns with v (same or opposite direction), you’ve found eigendirections. The stretch factor along those directions is the eigenvalue (ratio of lengths).
- Phone apps: Many graphing calculator apps let you apply 2D linear transforms to grids. Look for “matrix transformation visualizer”.

### Human: Could you make me a one-page cheat sheet for the core stuff?
### Assistant: Concise cheat sheet (essentials only):

Calculus
- Limits: Algebraic simplifications (factoring, conjugates), standard limits lim(sin x)/x = 1, lim((1 + x)^(1/x)) = e.
- Continuity: Polynomials/rationals continuous on domains; piecewise need matching at joins.
- Derivatives: Power rule d(x^n)=n x^(n−1); product (fg)'=f'g+fg'; quotient (f/g)'=(f'g−fg')/g^2; chain (f∘g)'=(f'∘g)g'.
- Common derivatives: d(e^x)=e^x; d(a^x)=a^x ln a; d(ln x)=1/x; d(sin x)=cos x; d(cos x)=−sin x.
- Applications: Tangent lines, optimization (critical points, endpoints), related rates.
- Integrals: Antiderivatives reverse differentiation; ∫x^n dx = x^(n+1)/(n+1)+C (n≠−1); ∫1/x dx = ln|x|+C; substitution for chains.
- Fundamental Theorem: If F' = f, then ∫_a^b f = F(b) − F(a); and d/dx ∫_a^x f(t) dt = f(x).

Linear Algebra
- Vectors: Magnitude |v|=sqrt(v·v); dot product u·v=|u||v|cosθ; orthogonal if u·v=0.
- Span/Linear independence: Span is all linear combinations; independent if only trivial combination gives zero.
- Basis/Dimension: Basis spans and is independent; dimension is number of vectors in a basis.
- Matrices: Multiplication is composition; (AB)C=A(BC); generally AB≠BA.
- Solving Ax=b: Row-reduce [A|b]; pivot in every row of A for unique solution; free variables imply infinitely many.
- Determinant: For 2x2 [[a,b],[c,d]], det=ad−bc; area/volume scaling; det(AB)=det A det B; invertible iff det≠0.
- Eigen: Solve det(A−λI)=0; eigenvector v satisfies Av=λv. Diagonalizable if enough independent eigenvectors.
