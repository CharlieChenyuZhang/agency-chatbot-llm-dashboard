### Human: I'm using Google Docs. How do I set it to US Letter and lock the signature space?
### Assistant: Steps in Google Docs:
1) Set page size to US Letter:
   - File > Page setup > Paper size > Letter (8.5" x 11") > OK.
2) Set margins:
   - File > Page setup > Margins: Top 0.75", Bottom 1.5", Left/Right 0.6".
3) Reserve signature area:
   - Easiest: Insert > Table > 1x1. Drag the table to the bottom of the page, right-click table > Table properties > Row > Minimum row height: 1.25–1.5". Set table border color to white (or 0 pt) to hide it. Type “Signature” and add an underscore line.
   - Alternative: Use the footer. Insert > Footer. Increase footer margin to create space, then add a signature line. Note: footers don’t truly “lock” height, so the 1-row table is more reliable in Docs.

4) Prevent last lines from slipping into the signature space:
   - Keep headings with their first bullet: Format > Line & paragraph spacing > Keep with next (for headings).
   - If content still pushes down, shorten bullets or reduce paragraph spacing slightly.

5) Export:
   - File > Download > PDF document. In the print dialog, make sure paper size is Letter and scale is 100%.

Docs doesn’t have a perfect “lock to bottom” feature, but the single-row table workaround is stable in practice. If you’d prefer a hard lock, I can suggest a quick approach in Word or provide a pre-sized PDF form.
