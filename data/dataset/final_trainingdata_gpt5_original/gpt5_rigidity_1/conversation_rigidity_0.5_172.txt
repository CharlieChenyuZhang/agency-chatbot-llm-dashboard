### Assistant: Steps for Mylio Photos (offline, Year/Month folders):

2) Install and stay offline
- Install Mylio Photos on your Mac.

3) Add sources as folders (don’t move yet)
- Old PC photos: Copy them onto the external drive into a staging folder like “From_PC”.
- Google Photos: Use Google Takeout to export Originals + JSON; place them in “From_Google”. Keep the JSON; it’s useful if any metadata is missing.

5) Deduplicate
- Run PhotoSweeper X on the source folders. Use conservative settings:
  - Keep the highest resolution and the most recent edited version.
  - Keep RAW over JPEG.
  - Preserve HEIC+MOV pairs (Live Photos).

- After cleanup, re-open Mylio so it reindexes changes.

6) Auto-organize into Year/Month
- In Mylio’s folder organization tool, choose a date-based pattern like:
  - Photos_Master / {Date:YYYY} / {Date:MM}
- Use capture date (EXIF) where available; for items missing EXIF, Mylio will fall back to file dates. If some dates look wrong, we can fix those in batches later.

7) People tagging and trips
- Enable People in Mylio and start confirming suggested matches. It runs locally.
- For trips, you can:
  - Create Albums for date ranges you know were trips.
  - If some photos lack GPS, date clusters work well (e.g., 2022-07-10 to 2022-07-18 = “Iceland Trip”).

8) Back up
- Once organized, back up the “Photos_Master” folder with Time Machine and a second external drive.

If you don’t see the exact Year/Month pattern in Mylio, we can use Adobe Bridge’s batch Move/Rename as a fallback to apply the same structure.

### Human: What about duplicates with Live Photos and bursts?
### Assistant: Good question. A few practical tips:
- Live Photos: Each is a HEIC (photo) + MOV (motion). Make sure your deduper treats them as a pair. PhotoSweeper X recognizes many iPhone patterns—disable any setting that auto-deletes “related videos.” If in doubt, filter by extension and never auto-delete .MOV without reviewing.
- Bursts: Keep your best frame(s). In PhotoSweeper, group by similarity and sort by resolution/sharpness; mark extras for deletion. If you need safety, move burst extras to a “Review_Later” folder first.
- RAW+JPEG: Prefer RAW if you plan to edit; otherwise keep JPEG if you don’t edit much and want smaller size.
- Edits vs originals: If you have both an edited copy and an original, keep the edited if it’s your “final,” but don’t discard originals unless you truly won’t re-edit.

If Live Photo handling ever seems ambiguous, we can run the dedupe in two passes: first photos only (HEIC/JPG/RAW), then videos separately, reviewing any MOVs that share base filenames with kept HEICs.
