### Human: Help me launch an MVP and acquire first 100 users
### Assistant: I can help, but I wouldn’t start by “launching an MVP” or chasing 100 users. That tends to produce vanity signups and a bloated build. I’d push for 10 paid design partners and a concierge prototype you can deliver manually in a week.

Here’s the path I recommend:
- Tighten the ICP to one narrow segment and one job-to-be-done.
- Put up a one-page landing with a price anchor, a simple value prop, and a Calendly. Aim for 10 qualified calls.
- Run a concierge prototype: use spreadsheets/automation to deliver the core outcome manually to 3–5 customers this week.
- Pre-sell 5–10 paid pilots with a clear success metric and a 4–6 week commitment.
- Only then freeze a minimal build that automates the one repeated manual step that’s killing you.

If you still want the 100 users quickly, I’ll help, but this route is faster to revenue and learning.

### Human: I already did interviews; I want to ship an MVP in 3 weeks. What should the MVP include?
### Assistant: If you’re shipping in 3 weeks, keep it “Wizard of Oz” and ruthlessly narrow scope. I’d build:
- Onboarding form + data capture: a single form that collects the exact inputs you need to deliver the core outcome.
- One core workflow that produces the promised result end-to-end for the happy path. Anything else is manual behind the scenes.
- Output the result in a simple format (PDF, CSV, or dashboard) plus a “Request fix” button.
- Basic activity logging and a “status” view so users see progress.
- Stripe checkout or a simple invoice flow. Avoid complex auth/roles; use magic links.

Cut from v1:
- Multi-tenant roles/permissions
- Complex settings
- Notifications beyond a single “result ready” email
- Analytics dashboards (ship one KPI)

Success criteria:
- Time-to-first-value under 15 minutes
- 80% of sessions complete the happy path
- 3+ paying pilots by week 3

### Human: I need acquisition tactics to get 100 users in month one.
### Assistant: I’d avoid chasing 100 generic signups. Aim for 10–15 qualified, paying design partners—that will teach you more and fund the build. That said, here’s how I’d approach it:

- Founder-led outbound
  - Build a list of 120 targets in your narrow ICP.
  - Warm intros via existing contacts, LinkedIn second-degree, and niche communities.
  - Cold email 60/day for 3 days with a tight, outcome-focused message and a clear ask for a 15-minute fit call.
  - Offer “charter pricing” and direct access to roadmap.

- Micro-communities and hand-raise posts
  - Post 2–3 practical, insight-rich threads in niche forums/slack groups with a clear CTA to join a 30-minute live demo next week.
  - Host one live session; limit to 20 seats.

- Partnerships
  - Identify 3 small influencers or newsletter owners in the niche; offer an exclusive pilot code and a rev-share.

Sample cold email:
Subject: Quick question about [specific pain]
Body:
Hi [Name]—I help [ICP] cut [pain] by [specific outcome] without [common headache].
We’re piloting with [peer example], and I can show you a 10-minute demo tailored to [their context].
If I can’t show a path to [measurable result] in that call, I’ll send you a $50 gift card for the time.
Open to a 15-minute chat Tues or Wed?
—[You], [Title], [Site]

### Human: What tech stack do you suggest for the MVP?
### Assistant: I wouldn’t code it yet. I’d ship with:
- Frontend: Softr or Typedream for the site + forms; or Retool if internal-facing
- Data: Airtable or Postgres on Supabase
- Automation: Zapier/Make for glue; a lightweight Cloud Function for any custom transform
- Auth: Magic links via Supabase or Clerk; or just signed links per session
- Payments: Stripe checkout link
- Logging: PostHog and a simple error log to a Google Sheet or Logtail

This gets you live in days and is easy to change as you learn.

### Human: I still want to code it in React and Node.
### Assistant: I wouldn’t, but if you’re set on it, keep it minimal:
- App: Next.js (pages or app router) for SSR and built-in API routes
- Backend: Next API routes + Prisma
- DB: Postgres via Supabase (free tier) or Neon
- Auth: Clerk or Supabase auth with magic links
- Payments: Stripe with one product and a single monthly plan
- File storage: Supabase storage or S3
- Observability: Sentry + PostHog
- Infra: Vercel for hosting

Core endpoints only:
- POST /session to create a job with inputs
- GET /session/:id/status
- GET /session/:id/output
- POST /feedback for “Request fix”

CLI script to run manual/async work behind the scenes while you automate gradually. No complex RBAC, no settings pages.

### Human: How do I price it for the first users?
### Assistant: Don’t do free. Charge to learn.
- Charter pricing: 30–40% off list for 12 months, paid upfront or with a 3-month minimum.
- Anchor on ROI: “Replace X hours/month” or “Reduce write-offs by Y%.” For SMB accountants, start at $149–$299/month per firm, not per seat.
- Pilot structure: 4–6 weeks, weekly check-in, success metric agreed. If target isn’t hit, extend two weeks or refund 50%—your call.
- Offer an implementation fee ($199–$499) that can be credited to the first month to increase commitment.

This keeps you honest, filters tire-kickers, and funds iteration.
