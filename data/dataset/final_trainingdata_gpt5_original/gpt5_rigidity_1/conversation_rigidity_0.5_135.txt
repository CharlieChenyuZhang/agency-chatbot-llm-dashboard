### Human: Generate the PowerShell for the flat structure and tags approach.
### Assistant: Here’s a safe, flat-first PowerShell script. It:
- Creates Work, Finance, Photos, _Inbox.
- Moves photos into Photos\YYYY (one level).
- Sends PDFs with “invoice” or “receipt” in the name to Finance, others to Work.
- Leaves other files in _Inbox for manual review.
- Runs with -WhatIf so you can preview. Remove -WhatIf to execute.

```powershell
# Set your source folder (where messy files currently live)
$Source = "$env:USERPROFILE\Downloads"   # change if needed
$Root   = "$env:USERPROFILE\Documents\Organized"  # destination root

# Create top-level folders
$folders = @("$Root\Work", "$Root\Finance", "$Root\Photos", "$Root\_Inbox")
$folders | ForEach-Object { New-Item -ItemType Directory -Path $_ -Force | Out-Null }

# Helper: Get safe year (falls back to file's LastWriteTime)
function Get-YearFolder {
    param($file)
    $year = $file.LastWriteTime.Year
    if ($year -lt 1980 -or $year -gt (Get-Date).Year + 1) { $year = (Get-Date).Year }
    return "$($folders[2])\$year"  # Photos\YYYY
}

# Move Photos (jpg, jpeg, png, heic, mov, mp4)
$photoExt = @(".jpg",".jpeg",".png",".heic",".mov",".mp4",".heif",".tif",".tiff")
Get-ChildItem -Path $Source -Recurse -File -ErrorAction SilentlyContinue |
    Where-Object { $photoExt -contains $_.Extension.ToLower() } |
    ForEach-Object {
        $target = Get-YearFolder $_
        New-Item -ItemType Directory -Path $target -Force | Out-Null
        Move-Item -LiteralPath $_.FullName -Destination $target -WhatIf -Verbose
    }

# Move PDFs: invoice/receipt → Finance; others → Work
Get-ChildItem -Path $Source -Recurse -File -Filter *.pdf -ErrorAction SilentlyContinue |
    ForEach-Object {
        $name = $_.Name.ToLower()
        if ($name -match "invoice|receipt") {
            Move-Item -LiteralPath $_.FullName -Destination "$Root\Finance" -WhatIf -Verbose
        } else {
            Move-Item -LiteralPath $_.FullName -Destination "$Root\Work" -WhatIf -Verbose
        }
    }

# Optional: Common office docs to Work
$docExt = @(".doc",".docx",".ppt",".pptx",".xls",".xlsx",".txt",".md",".rtf")
Get-ChildItem -Path $Source -Recurse -File -ErrorAction SilentlyContinue |
    Where-Object { $docExt -contains $_.Extension.ToLower() } |
    ForEach-Object {
        Move-Item -LiteralPath $_.FullName -Destination "$Root\Work" -WhatIf -Verbose
    }

# Everything else to _Inbox for manual review
Get-ChildItem -Path $Source -Recurse -File -ErrorAction SilentlyContinue |
    ForEach-Object {
        # Skip files already moved (simulate by checking destination existence)
        # In real run (without -WhatIf) you could track via a log.
        Move-Item -LiteralPath $_.FullName -Destination "$Root\_Inbox" -WhatIf -Verbose
    }
```

Notes:
- Replace $Source with your messy folder (e.g., Desktop).
- Review the verbose output. If it looks right, remove each -WhatIf and rerun.
- We can add renaming rules next (e.g., prefix PDFs with YYYY-MM from LastWriteTime).
