### Human: It’s for indie game developers. I was thinking Discord. I want it active quickly. I can spend ~2 hours/day and about $100/month. Can you give me a step-by-step plan?
### Assistant: Great. Discord can work for devs, though we should sanity-check it against your audience (some prefer Slack or a forum like Discourse/Circle for deeper threads). If speed is the priority, Discord is fine to start; we can add a forum later for long-form resources.

A lean 90-day plan:
Phase 0 (Week 0): Foundations
- Purpose: “A practical, kind space where indie devs get reliable feedback, playtesting, and collaborators.”
- Member profile: Solo/2–3 person teams, PC/mobile, early–mid prototype.
- Value: Weekly playtest nights, fast feedback on builds, showcases that drive wishlists.
- Positioning: “Your dev friend group, at scale.”

Phase 1 (Weeks 1–3): Seed and shape
- Seed 30–50 quality members from: past collaborators, itch.io jams, r/gamedev help threads, a few small YouTubers’ audiences.
- Channels: #introductions, #work-in-progress, #playtesting, #feedback-requests, #help-wanted, #showcase, #voice-playtest, #announcements.
- Rituals (weekly): Feedback Friday (structured), Playtest Night (voice + shared builds), Monday Standup.
- Onboarding: Short form + welcome DM + 3-step checklist (introduce, post WIP, sign up for playtest).
- Metrics: 50% of new members post in first 48h; 30% return week 2.

Phase 2 (Weeks 4–8): Consistency and growth
- Partnerships: Offer co-hosted playtest nights with one small YouTuber/podcast and one jam organizer per month.
- Content cadence: 3 prompts/week (WIP, Tech Tip, Blocker Bust), 1 deep-dive thread/week (e.g., steam page teardown).
- Roles: “Playtest Host,” “Feedback Buddy,” “Mod-in-Training.”
- Light application for new members to maintain quality.
- Metrics: DAU/WAU > 0.35, 60% week-4 retention among the seed.

Phase 3 (Weeks 9–12): Scale what works
- Spin up a searchable “Best Of” resource (Notion/Discourse) for persistent value.
- Member-led events: shader show-and-tell, audio clinic.
- Referral loop: “Invite 2 peers who ship.” Recognize referrers in #showcase, not with cash.
- Metrics: 150–200 members, 30%+ monthly active, 10+ attendees per event.

Budget use (~$100/mo)
- Discord Nitro for server boosts (or skip at first).
- Bots: one mod/auto role, one events bot, one forms bot.
- Occasional gift cards for peer-voted “Most Helpful Feedback” (non-cash alternatives are fine too: asset packs/credits).

- Start with a 4-week pilot calendar to test what your devs react to.

- Create a reusable weekly cadence you can scale.

### Human: I want to launch next week with 1,000 members. Can we do a big giveaway to hit that number?
### Assistant: We can run a campaign, but big giveaways often bring low-intent members who churn and hurt culture. A healthier path:
- Target 100–150 high-intent members for launch week; aim for 30–50 active daily.
- Use a waitlist + short application to filter for people actively building.
- Partner with 2–3 micro-creators (5–20k subs) for co-hosted playtests and shoutouts.

If you still want a giveaway:
- Make it skill- or contribution-based (e.g., “Best feedback giver,” “Most helpful playtest host”), not random.
- Keep prizes relevant (asset packs, tool licenses) to deter bots.
- Require meaningful actions (post intro + submit a build or feedback).

We can set a stretch goal: 300 members by week 3, 1,000 by month 3 if engagement holds.

### Human: Yes, give me those two.
### Assistant: Feedback Friday template
- Post format: Title, Goal of feedback (e.g., “Combat feel”), Build link or short clip, 3 questions.
- Rule: 2-for-1 — give feedback to 2 others before posting your own.
- Checklist for reviewers: What worked, what confused you, 1 change that would improve it now, 1 bigger idea for later.

Playtest Night agenda (60–90 min)
- 0–5 min: Welcome + ground rules
- 5–15 min: Playtest 1 (5 min play + 5 min feedback)
- 15–25 min: Playtest 2
- 25–35 min: Playtest 3
- 35–45 min: Break/chat
- 45–75 min: More playtests
- Wrap: Poll for “Most Helpful Feedback” + schedule next session

### Human: How do I measure if this is working?
### Assistant: Simple dashboard, weekly review:
- Activation: % new members who post within 48h (target >50%)
- Retention: Week-4 retention of the seed cohort (target >60%)
- Engagement: DAU/WAU ratio (target >0.35), posts per active user/week
- Event health: Avg attendees (target 10+), % who return to a second event (target >50%)
- Quality: Member NPS or a 1–5 “Was this helpful this week?” poll (target 4.2+)
- Growth: Invites from members vs. you (aim for >40% member-driven by month 2)

### Human: What if it fails anyway?
### Assistant: No community is guaranteed, but we can de-risk:
- Run a pre-mortem: top 3 risks (low-quality members, event fatigue, wrong platform).
- Set kill/pivot criteria now (e.g., if DAU/WAU <0.25 and week-4 retention <40% after 8 weeks).
- Pivot options:
  - Platform shift: Keep Discord for chat, add Discourse/Circle for long-form.
  - Niche focus: Narrow to one engine or discipline (e.g., Godot 2D platformers).
  - Event format change: Fewer, higher-quality events; asynchronous playtests via forms.
- End well if needed: Archive best resources, share where folks can go next, keep the mailing list for a future relaunch.
