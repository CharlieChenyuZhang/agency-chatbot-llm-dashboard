### Human: Design a lightweight audit checklist and scoring rubric we can pilot.
### Assistant: Checklist v0.5 (score each 0–2; weight in parentheses; total 100)
Data and labels (30)
- Representativeness documented (10): 0 none; 1 partial; 2 by job family with gaps flagged
- Label quality (10): 0 unknown; 1 spot checks; 2 inter‑rater checks + bias review
- Sensitive attribute handling (10): 0 ignored; 1 proxy analysis; 2 explicit fairness evaluation plan

Model and evaluation (30)
- Subgroup evaluation (10): 0 none; 1 overall only; 2 per subgroup with CIs/strain tests
- Thresholding/selection reviewed (10): 0 arbitrary; 1 heuristic; 2 job‑analysis anchored
- Stability/shift checks (10): 0 none; 1 periodic; 2 documented drift plan

Process and governance (30)
- Job relatedness evidence (10): 0 none; 1 outdated; 2 recent validity evidence
- Human oversight (10): 0 rubber‑stamp; 1 manual review; 2 escalation + appeal
- Incident/complaint handling (10): 0 ad hoc; 1 informal; 2 documented SLA + tracking

Transparency (10)
- Documentation package (10): 0 marketing only; 1 partial; 2 model card + audit summary + change log

Scoring bands
- 85–100: Low risk with conditions
- 70–84: Medium risk, mitigation required
- <70: High risk; do not deploy without remediation
We can adapt weights if your audience emphasizes compliance or utility more.
