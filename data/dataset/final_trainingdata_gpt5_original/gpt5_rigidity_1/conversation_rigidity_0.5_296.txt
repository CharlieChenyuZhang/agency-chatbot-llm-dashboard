### Human: I tend to procrastinate at the start. Any tips?
### Assistant: A few practical starters:
- 5-minute rule: Commit to just 5 minutes setting up (open notebook, write the first header, list integrals to attempt). Momentum usually follows.
- Pre-commit your first task: “At 9:00 pm I complete A1 and A2.” Put it on a sticky note and set a timer.
- Environment preset: Before dinner, lay out the textbook, tablet, water, and a single pen; block distracting sites for 3 hours with an app.
- Reduce choice: Decide your first substitution method before you sit down (e.g., “If I see a product, I try parts first”).
- Accountability ping: Message a friend “Starting calc now; I’ll check back at 10:30 with progress.”

If willpower is low, start with a 10-minute “easy win” problem to break inertia, then jump to the planned order.

### Human: If I crash one day, how do I recover?
### Assistant: Use a minimal viable day, then a catch-up plan:
- Minimal viable day (30–45 minutes):
  - 20 minutes: Retrieval on weakest subject.
  - 10–15 minutes: Plan tomorrow; set up materials.
- Next-day catch-up:
  - Do one extra 45–60 minute block on the missed subject.
  - Triage using A/B/C: finish A, attempt B, outline C.
  - Use the weekend as a buffer: convert one 2-hour slot into targeted make-up work.

This keeps momentum without snowballing stress.
