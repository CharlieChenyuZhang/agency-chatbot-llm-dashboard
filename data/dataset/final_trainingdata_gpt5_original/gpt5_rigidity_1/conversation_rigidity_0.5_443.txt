### Human: We don't have Sigma. Give me a simple script.
### Assistant: Here’s a minimal Python script that exports active subscriptions with columns: name, email, subscription_start (UTC), plan, country. It uses the Product name for the plan and the customer’s billing address country when available.

Requirements:
- Python 3.9+ recommended
- pip install stripe

Environment:
- Set STRIPE_API_KEY in your environment (use your live key for production)

Script (save as export_active_customers.py):

import os
import csv
import datetime
import stripe

stripe.api_key = os.environ["STRIPE_API_KEY"]

output_file = "active_customers.csv"

# We expand customer and product to avoid extra requests
subs = stripe.Subscription.list(
    status="active",
    expand=["data.customer", "data.items.data.price.product"],
    limit=100
)

with open(output_file, "w", newline="", encoding="utf-8") as f:
    writer = csv.writer(f)
    writer.writerow(["name", "email", "subscription_start", "plan", "country"])

    # auto_paging_iter handles pagination for all results
    for s in subs.auto_paging_iter():
        cust = s.customer if isinstance(s.customer, dict) else {}
        name = (
            cust.get("name")
            or (cust.get("shipping") or {}).get("name")
            or ""
        )
        email = cust.get("email", "")

        start_ts = s.get("start_date")
        start_iso = (
            datetime.datetime.utcfromtimestamp(start_ts).isoformat() + "Z"
            if start_ts else ""
        )

        # Get the first subscription item (common for single-plan subs)
        items = s.get("items", {}).get("data", [])
        item = items[0] if items else None

        product_name = ""
        if item and item.get("price"):
            prod = item["price"].get("product")
            if isinstance(prod, dict):
                product_name = prod.get("name", "")
        plan = product_name or (item["price"].get("nickname", "") if item and item.get("price") else "")

        addr_country = (cust.get("address") or {}).get("country")
        if not addr_country:
            addr_country = ((cust.get("shipping") or {}).get("address") or {}).get("country", "")

        writer.writerow([name, email, start_iso, plan, addr_country])

print(f"Wrote {output_file}")

Run weekly with cron (Linux/macOS):
- crontab -e
- Add: 0 8 * * 1 /usr/bin/env STRIPE_API_KEY=sk_live_... /usr/bin/python3 /path/export_active_customers.py

Notes:
- This pulls all active subscriptions and may include customers multiple times if they have multiple active subscriptions.
- Test with your test key first (sk_test_...) to validate.
- Keep your API key secret (environment variable or a secure secret manager).
- If you need to email the CSV automatically, we can add an SMTP step or upload to cloud storage.
