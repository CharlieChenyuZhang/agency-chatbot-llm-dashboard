Skeleton Flask app (app.py):

from flask import Flask, request, jsonify, render_template_string

app = Flask(__name__)

workouts = []  # temporary in-memory storage

index_html = """
<!doctype html>
<html>
  <head><title>Workout Tracker</title></head>
  <body>
    <h1>Workout Tracker</h1>

    <form id="add-form" method="post" action="/workouts">
      <input name="type" placeholder="type (e.g., run)" required>
      <input name="minutes" type="number" placeholder="minutes" required>
      <button type="submit">Add</button>
    </form>

    <button id="refresh">Refresh</button>
    <ul id="list"></ul>

    <script>
      async function load() {
        const res = await fetch('/workouts');
        const data = await res.json();
        const ul = document.getElementById('list');
        ul.innerHTML = '';
        data.forEach(w => {
          const li = document.createElement('li');
          li.textContent = w.type + ' - ' + w.minutes + ' min';
          ul.appendChild(li);
        });
      }
      document.getElementById('refresh').onclick = load;
      document.getElementById('add-form').onsubmit = async (e) => {
        e.preventDefault();
        const form = new FormData(e.target);
        await fetch('/workouts', { method: 'POST', body: form });
        e.target.reset();
        load();
      };
      load();
    </script>
  </body>
</html>
"""

@app.route("/")
def index():
    return render_template_string(index_html)

@app.route("/workouts", methods=["GET", "POST"])
def workouts_route():
    if request.method == "POST":
        wtype = request.form.get("type")
        minutes = int(request.form.get("minutes", 0))
        workouts.append({"type": wtype, "minutes": minutes})
        return ("", 204)
    return jsonify(workouts)

if __name__ == "__main__":
    app.run(debug=True)

### Human: Show me JSON file approach.
### Assistant: Sure. We’ll load from data.json at startup and save after each write.

Add helpers:

import json, os

DATA_FILE = "data.json"

def load_data():
    if os.path.exists(DATA_FILE):
        with open(DATA_FILE, "r") as f:
            return json.load(f)
    return []

def save_data(items):
    with open(DATA_FILE, "w") as f:
        json.dump(items, f)

Replace workouts = [] with:

workouts = load_data()

And in POST handler, after workouts.append(...), add:

save_data(workouts)

This will persist data in data.json. Note: on Replit, this usually works, but on some configurations file writes can be limited. If you hit a permissions or path issue, we can switch to Replit DB.

### Human: I’m getting a permission error writing the file.
### Assistant: No problem—let’s switch to Replit DB (it avoids file permissions). It’s simple, but note it’s key-value and not relational.

1) Add dependency if needed: in Replit, search “Packages” for “replit” and add.
2) Use it like this:

from replit import db

# Load all on GET
@app.route("/workouts", methods=["GET", "POST"])
def workouts_route():
    if "workouts" not in db:
        db["workouts"] = []
    if request.method == "POST":
        wtype = request.form.get("type")
        minutes = int(request.form.get("minutes", 0))
        items = list(db["workouts"])
        items.append({"type": wtype, "minutes": minutes})
        db["workouts"] = items
        return ("", 204)
    return jsonify(list(db["workouts"]))

This should work without file writes.

### Human: Can we add a simple chart?
### Assistant: Yes. Easiest is Chart.js via CDN. We’ll compute totals per type in the browser and render a bar chart.

In index_html, add inside <head>:

Update the JS load() to compute totals and draw:

let chart;
async function load() {
  const res = await fetch('/workouts');
  const data = await res.json();
  const ul = document.getElementById('list');
  ul.innerHTML = '';
  data.forEach(w => {
    const li = document.createElement('li');
    li.textContent = w.type + ' - ' + w.minutes + ' min';
    ul.appendChild(li);
  });

  const totals = {};
  data.forEach(w => {
    totals[w.type] = (totals[w.type] || 0) + Number(w.minutes);
  });
  const labels = Object.keys(totals);
  const values = labels.map(k => totals[k]);

  const ctx = document.getElementById('chart').getContext('2d');
  if (chart) chart.destroy();
  chart = new Chart(ctx, {
    type: 'bar',
    data: {
      labels: labels,
      datasets: [{ label: 'Minutes', data: values, backgroundColor: '#4e79a7' }]
    },
    options: { responsive: true, maintainAspectRatio: false }
  });
}

This keeps the chart optional. If external CDNs are blocked on your network, we can skip the chart and show a simple totals list instead.
