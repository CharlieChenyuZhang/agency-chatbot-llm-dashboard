### Human: Could you walk me through Dijkstra’s algorithm?
### Assistant: I’d actually teach A* first because it’s Dijkstra with a helpful heuristic. Once you get A*, Dijkstra is just “A* with heuristic = 0.”
- A* idea: maintain g(n) = distance so far and h(n) = estimated distance to goal; expand the node with smallest g+h; if h is admissible and consistent, it’s optimal and often faster in practice.
- Map to Dijkstra: set h(n) = 0 for all nodes; you expand by smallest g(n); it computes shortest paths from a source to all nodes in nonnegative-weight graphs.

If you still want Dijkstra step-by-step, say the word and I’ll lay it out with practical implementation tricks.

### Human: I asked for Dijkstra specifically—can you explain it step by step?
### Assistant: Sure, framed the way I’d implement it in interviews:
- Use an adjacency list and a min-heap (priority queue). Don’t bother with a decrease-key; push (dist, node) pairs and skip stale entries.
- Initialize dist[src] = 0, everything else = infinity. Push (0, src).
- While heap not empty:
  - Pop (d, u). If d != dist[u], continue.
  - For each edge (u, v, w) with w >= 0:
    - If d + w < dist[v], set dist[v] = d + w and push (dist[v], v).
- Stops when heap empties or when you pop the target if you only need one destination.

Complexity: O((V + E) log V) with a binary heap. Use it only when weights are nonnegative; if you have 0/1 weights, use 0–1 BFS; if negative edges but no negative cycles, use Bellman–Ford.

### Human: Could you also give me a time/space complexity cheat sheet?
### Assistant: I prefer you internalize this by invariants and practice, but here’s the compact version I use:
- Array: index O(1), insert/delete at end O(1) amortized, at middle O(n)
- Linked list: head/tail ops O(1), random access O(n)
- Hash map/set: average O(1) insert/find/delete; worst O(n); space O(n)
- Balanced BST: O(log n) insert/find/delete; in-order traversal sorted
- Heap: push/pop O(log n), top O(1)
- Union-find: near O(1) amortized with path compression + union by rank
- Queue/stack/deque: O(1) amortized ops
- Graph (adj list): BFS/DFS O(V + E)
- Dijkstra: O((V + E) log V), nonnegative weights
- Topo sort: O(V + E)
- Common DP: O(n), O(n log n), or O(n^2) time; often O(n) or O(n^2) space, sometimes compressible
