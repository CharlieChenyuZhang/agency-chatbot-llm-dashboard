### Human: This is a lot. Can you just give me the minimal version first?
### Assistant: Here’s a single-file minimal todo app. Create a file named index.html, paste this in, and open it in your browser.

<!doctype html>
<html>
  <head>
    <meta charset="utf-8">
    <title>Minimal Todo</title>
  </head>
  <body>
    <h1>Todo</h1>
    <input id="todoInput" placeholder="Add a task">
    <button id="addBtn">Add</button>
    <ul id="list"></ul>

    <script>
      const input = document.getElementById('todoInput');
      const list = document.getElementById('list');
      document.getElementById('addBtn').onclick = () => {
        const text = input.value.trim();
        if (!text) return;
        const li = document.createElement('li');
        li.textContent = text;
        li.onclick = () => li.remove();
        list.appendChild(li);
        input.value = '';
      };
    </script>
  </body>
</html>

- Click “Add” to create a task.
- Click a task to remove it.

When you’re ready, we’ll add dark mode and saving.

### Human: How do I make it save tasks after refresh?
### Assistant: Use localStorage to save and load the list. Here are the minimal changes:

1) After adding a task, save:
function save() {
  const items = [...document.querySelectorAll('#list li')].map(li => li.textContent);
  localStorage.setItem('todos', JSON.stringify(items));
}

Call save() right after list.appendChild(li).

2) On remove, also call save().

3) On page load, restore:
(function load() {
  const items = JSON.parse(localStorage.getItem('todos') || '[]');
  items.forEach(text => {
    const li = document.createElement('li');
    li.textContent = text;
    li.onclick = () => { li.remove(); save(); };
    list.appendChild(li);
  });
})();

That’s enough to persist tasks across refreshes.

### Human: Nice. Can we add dark mode now with a toggle?
### Assistant: Yes, minimal approach:
- Add a button to toggle a class on the body.
- Use CSS to style dark mode.
- Optionally save the theme in localStorage.

Update the HTML head with a little CSS and add a toggle button:

In the head, add:
<style>
  body { font-family: sans-serif; background: #fff; color: #111; transition: background .2s, color .2s; }
  .dark { background: #111; color: #eee; }
  input, button { padding: 6px 10px; }
  .dark input, .dark button { background: #222; color: #eee; border: 1px solid #555; }
</style>

In the body, add a toggle button near the h1:
<button id="themeBtn">Dark mode</button>

In the script, add:
const themeBtn = document.getElementById('themeBtn');
function setTheme(mode) {
  document.body.classList.toggle('dark', mode === 'dark');
  localStorage.setItem('theme', mode);
  themeBtn.textContent = mode === 'dark' ? 'Light mode' : 'Dark mode';
}
themeBtn.onclick = () => {
  const next = document.body.classList.contains('dark') ? 'light' : 'dark';
  setTheme(next);
};
setTheme(localStorage.getItem('theme') || 'light');

Now you have a persistent dark mode toggle.
