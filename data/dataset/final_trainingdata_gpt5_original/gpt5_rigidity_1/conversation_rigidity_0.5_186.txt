### Human: Okay, share the script. Trash Bulk older than 90 days.
### Assistant: Steps:
1) Go to script.google.com > New project.
2) Paste the code below. It only touches threads with the “Bulk” label whose last message is older than 90 days.
3) Click Run > authorize when prompted.
4) After a successful test run, set a trigger: Triggers (alarm icon) > Add Trigger > choose cleanBulk > Time-driven > Day timer > pick a time.

Code:
function cleanBulk() {
  var labelName = 'Bulk';
  var days = 90; // change if you like
  var label = GmailApp.getUserLabelByName(labelName);
  if (!label) return;
  var cutoff = new Date();
  cutoff.setDate(cutoff.getDate() - days);

  var start = 0;
  var batch;
  do {
    batch = label.getThreads(start, 100);
    if (!batch.length) break;

    for (var i = 0; i < batch.length; i++) {
      var th = batch[i];
      if (th.getLastMessageDate() < cutoff) {
        th.moveToTrash();
      }
    }
    start += 100;
    Utilities.sleep(300); // be gentle with quotas
  } while (batch.length === 100);
}

Tip: Run it once without changes, then check Trash to confirm it caught only what you expect.
