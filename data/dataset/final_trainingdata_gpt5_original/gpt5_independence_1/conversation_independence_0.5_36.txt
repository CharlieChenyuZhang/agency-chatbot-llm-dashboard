VPC flashcards (Anki-style; Q then A):
- What’s the difference between a security group and a NACL? SG = stateful, instance-level; NACL = stateless, subnet-level.
- When do you use a NAT Gateway vs an Internet Gateway? NAT for outbound-only internet from private subnets; IGW for public internet connectivity to/from public subnets.
- Gateway vs Interface VPC Endpoints? Gateway: S3/DynamoDB via route table; Interface: ENI for most other services, supports security groups, per-AZ.
- ALB vs NLB key differences? ALB: HTTP/HTTPS, L7, path/host-based routing, WebSockets; NLB: TCP/UDP, L4, ultra-low latency, static IP.
- VPC Peering vs Transit Gateway? Peering for simple point-to-point; TGW for scalable hub-and-spoke multi-VPC/multi-account.
- SG default behavior if no rules? All outbound allowed; inbound denied.
- NACL rule evaluation order? Numbered, lowest to highest; first match wins; explicit deny supported.
- S3 access from private subnet without public internet? Use S3 Gateway VPC Endpoint; update route tables.
- Route 53 vs ALB routing? Route 53 = DNS-level; ALB = L7 application routing after DNS resolution.
- AZ vs Region? AZ = distinct data centers within a region; multi-AZ for HA, multi-Region for DR/latency.
