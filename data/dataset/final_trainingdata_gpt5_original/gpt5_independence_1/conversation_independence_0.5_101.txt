- Interactions: Validate on blur; show inline error after 300ms; allow override with confirm modal
- Data/Copy: Requires address API v3; log ValidationResult; copy: “We couldn’t confirm your address. Continue anyway?”

Handoff checklist (paste into Jira/Notion):

- States: idle/loading/error/success covered
- Edge cases documented
- API and tracking noted
- Copy finalized and approved
- Accessibility notes (focus order, labels)
- Out-of-scope explicitly stated

Pitfalls and fixes:
- Vague goals → Define success upfront
- Unlinked Figma pages → Link exact frames
- Missing error states → List at least 3 common errors
- Copy TBD → Ship final copy or clearly mark draft
