Beets setup (Windows):
1) Install Python 3.11+.
2) In Command Prompt:

3) Create a config file at %APPDATA%\beets\config.yaml with these defaults (I’m choosing safe options; you can change later):

   import:
     move: yes
     write: no
     copy: no
     timid: yes
     log: D:\Music\beets.log

     comp: Compilations/$album/$track - $title

     '[\\/:*?"<>|]': _

     maxwidth: 600
     auto: no
   duplicates:
     keys: acoustid
     format: $path :: $bitrate :: $format
