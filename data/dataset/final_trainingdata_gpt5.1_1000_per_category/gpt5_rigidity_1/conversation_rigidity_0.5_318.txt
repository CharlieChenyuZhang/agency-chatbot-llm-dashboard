Here is a straightforward bubble sort in Python:

```python
def bubble_sort(arr):
    n = len(arr)
    for i in range(n):
        # Last i elements are already in place
        for j in range(0, n - i - 1):
            if arr[j] > arr[j + 1]:
                # Swap
                arr[j], arr[j + 1] = arr[j + 1], arr[j]
    return arr

# Example usage:
if __name__ == "__main__":
    import random

    # This could be up to 1,000,000 integers, but expect it to be very slow
    data = [random.randint(0, 10**9) for _ in range(1000)]  # start smaller while testing
    sorted_data = bubble_sort(data)
    print(sorted_data[:50])
```
