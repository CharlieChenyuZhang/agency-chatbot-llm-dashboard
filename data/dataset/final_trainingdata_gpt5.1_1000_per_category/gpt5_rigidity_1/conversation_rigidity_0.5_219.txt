Here’s a minimal, practical setup in Google Sheets:

1. Import the CSV:
   - File → Import → Upload → pick your CSV → “Insert new sheet(s).”

2. Identify columns:
   - Suppose:
     - Column A: Order Date
     - Column B: Product Name
     - Column C: Total (numeric)

3. Add a “Month” column:
   - In a new column D (row 2), enter:
     - `=EOMONTH(A2,0)`

   - Fill down.

4. Add a simple “Type” (Big device vs Accessory) column:
   - In column E (row 2), use a keyword-based formula, for example:
     ```google-sheets
     =IF(REGEXMATCH(LOWER(B2),

       "Big Device",
       "Accessory/Other")
     ```
   - Adjust keywords to match your usual purchases.
   - Fill down.

5. Create a Pivot Table for monthly totals:
   - Select all your data (A:E).
   - Insert → Pivot table → New sheet.
