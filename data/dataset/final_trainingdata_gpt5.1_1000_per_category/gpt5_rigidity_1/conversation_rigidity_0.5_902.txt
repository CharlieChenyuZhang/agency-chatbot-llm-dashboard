Core DP patterns (with basic templates):

1) 1D DP over index (e.g., Climbing Stairs, House Robber)
- dp[i] means “best result up to index i”.
- Recurrence like:
  - dp[i] = max(dp[i-1], dp[i-2] + value[i]) or
  - dp[i] = dp[i-1] + dp[i-2].
- Often can space-optimize to two variables.

2) Prefix-based DP (e.g., Maximum Subarray, some subsequence questions)
- dp[i] relates to best ending at i.
- Often uses:
  - dp[i] = max(nums[i], dp[i-1] + nums[i]).

3) 2D DP on indices (e.g., Edit Distance, Longest Common Subsequence)
- dp[i][j] represents best result for substrings up to i, j.
- Transitions consider match/mismatch or skipping one side.

4) Knapsack-style / subset sum (e.g., Partition Equal Subset Sum, classic knapsack)
- dp[i][w] or 1D dp[w] = best value using capacity w.
- Transition: take item or skip item, max of both.

5) Sequence DP like LIS
- Often O(n^2) DP:
  - dp[i] = length of LIS ending at i.
  - Look at all j < i where nums[j] < nums[i].

Generic DP checklist (what you should practice, not just memorize):
1) Ask: “Is there overlapping subproblems + optimal substructure?”
2) Decide: top-down (memoized recursion) or bottom-up table.
3) Define the state in a 1-sentence English definition (e.g., dp[i] = …).
4) Work a small example by hand and fill a mini table/array.
5) Translate the manual steps into recurrence and code.

Now, step-by-step derivation for House Robber:

Problem summary:
- You have a row of houses, each with some money.
- If you rob two adjacent houses, you trigger an alarm.
- Maximize money without robbing adjacent houses.

Step 1: Identify subproblems
You’re repeatedly deciding for each house:
- Rob it, skip its neighbor.
- Skip it, maybe rob the neighbor.

Overlap arises because decisions for a suffix/prefix of houses repeat.

Step 2: Define DP state
Let dp[i] be the maximum money you can rob from houses 0..i (inclusive).
(This is the “English sentence” definition you should always do.)

Step 3: Derive recurrence
At house i, you have two options:
- Skip house i → best is dp[i-1].
- Rob house i → you add nums[i], and you can’t rob i-1, so you add dp[i-2].
Thus:
- dp[i] = max(dp[i-1], dp[i-2] + nums[i])

Base cases:
- dp[0] = nums[0] (only one house).
- dp[1] = max(nums[0], nums[1]) (choose better of the first two).

Step 4: Iterate and fill
For i from 2 to n-1:
- dp[i] = max(dp[i-1], dp[i-2] + nums[i])

Answer: dp[n-1].

Step 5: Space optimization (common in 1D DP)
You notice dp[i] only depends on dp[i-1] and dp[i-2], so:
- Keep two variables: prev1 = dp[i-1], prev2 = dp[i-2].
- Update them in a loop.

Your tasks:
- Implement House Robber with a dp array.
- Then implement the space-optimized version.
- Then, without looking, re-implement from scratch a few days later.

After you do House Robber and Climbing Stairs using this process, the next problems will feel less magical.
