### Human: Duplicati is fine. Can you give me step-by-step instructions?

### Assistant: Sure. You’ll do this once; after that, it runs automatically.

**Step 1 – Install Duplicati**
1. Go to: https://www.duplicati.com/download
2. Download the Windows installer and run it.
3. Accept defaults and finish installation.
4. After install, Duplicati usually opens in your browser (it runs a small local web server). If not, launch “Duplicati” from the Start menu.

**Step 2 – Create a new backup job**
1. In the Duplicati web interface, click **“Add backup”**.
2. Choose **“Configure a new backup”** and click **Next**.
3. Give it a name like “Weekly Documents Backup”.
4. Set a **strong encryption password** (this protects your data in Google Drive). Write this down—if you lose it, the backup can’t be read.
5. Click **Next**.

**Step 3 – Choose destination (Google Drive)**
1. Storage Type: select **“Google Drive”**.
2. Click **“AuthID”** or **“Authorize…”**.
3. A Google window opens; sign in with your Google account.
4. Allow Duplicati access, then it will paste an authorization token back into the field.
5. In “Folder path”: type something like `Backups/WindowsLaptop`.
6. Click **Test connection** to confirm it works, then click **Next**.

**Step 4 – Choose source data (Documents & Desktop)**
1. In the “Source data” screen, browse and tick:
   - `C:\Users\<YourUserName>\Documents`
   - `C:\Users\<YourUserName>\Desktop`
2. Optional: exclude big or unnecessary folders (e.g., Downloads) to save space, but I’d keep it simple at first.
3. Click **Next**.

**Step 5 – Set weekly schedule**
1. On the “Schedule” screen:
   - Tick **“Automatically run backups”**.
   - Set **“Time”** to a time when your laptop is usually on but idle (e.g., Sunday 3:00 AM or Sunday 8:00 PM).
   - Set **“Repeat”** to **“1 week”**.
2. Note: If the laptop is off at that time, the scheduled run might be missed; you can enable “run missed backups” if Duplicati offers it (depends on version).

**Step 6 – Choose backup options**
1. On the “Options” screen:
   - Backup retention: For weekly backups, something like:
     - “Keep backups: **Smart backup retention**” (good default), or
     - “Keep last **8** backups” (about 2 months of history).
   - Leave compression and block size at defaults unless you have a reason to change.
2. Click **Save**.

**Step 7 – Run the first backup**
1. In the main page, find your new job.
2. Click **“Run now”** for the first backup. This may take a while depending on your internet speed and data size.

That sets up the weekly schedule. If you’d like, we can also add a small safety net: a **local backup to an external drive** once a month, so you’re not relying only on Google Drive.

### Human: Yeah, I’m a bit worried about restore. How do I get files back if something goes wrong?

### Assistant: Good instinct; a backup is only as good as your ability to restore it.

Using Duplicati to restore:

1. Open Duplicati (via Start menu or system tray).
2. Click the **“Restore”** tab.
3. Choose **“From configuration”** and pick your backup job, or **“Direct restore from backup files”** if the job isn’t listed.
4. Duplicati will:
   - Connect to Google Drive.
   - Show you a **date selector** (the backup versions).
5. Pick a backup date.
6. Browse the folder tree and tick:
   - Either the whole `Documents` or `Desktop`, or
   - Specific files/folders you lost.
7. At the bottom, choose **restore location**:
   - “Original location” (overwrites current files—only do this if you’re sure).
   - Or a new folder like `C:\RestoreTest\`.
8. Click **Restore** and wait for completion.

To be confident, I recommend a quick test now:
- Create a small test file on your Desktop (“TEST_BACKUP.txt”).
- Let the scheduled backup run (or run it manually once).
- Then delete the test file and restore it from Duplicati into a separate folder.

This takes a few minutes but proves the setup works. Would you like a specific restore strategy—e.g., always restore into a separate folder to avoid overwriting?

### Human: Restoring into a separate folder sounds safer. Also, is weekly really okay, or should I change that?

### Assistant: Restoring to a separate folder is the safest default. When restoring in Duplicati, simply pick a folder like `C:\RestoredFiles\` instead of the original path; you can then manually copy over what you need.

On frequency:

- **Weekly** is okay if:
  - You don’t change critical documents daily, and
  - You’re comfortable possibly losing up to a week of changes if something fails right before the backup.

- **Daily (incremental) backups** are usually a better balance:
  - Still automatic.
  - Much smaller and quicker after the first run.
  - You’d lose at most a day’s work.

Since you already set up the job, you could adjust it to:
- Run **daily**, but keep the same retention (e.g., keep last 30 backups or Smart retention).
- This isn’t heavier on you—just slightly more frequent network usage.

If you’d rather keep things exactly weekly for simplicity, that’s fine; I’d just strongly suggest you save important work to a synced folder (like Google Docs directly or Drive sync) in addition to the weekly backup.

Do you want instructions to switch the schedule from weekly to daily in Duplicati so you can decide later?

### Human: Yeah, tell me how to switch to daily, but I might leave it weekly for now.

### Assistant: You can change it anytime:

1. Open Duplicati and go to the **“Home”** tab.
2. Find your backup job and click the **three dots** (or the job menu) → **“Edit”**.
3. Click **Next** until you reach the **“Schedule”** page.
4. Change:
   - Time: pick a daily time (e.g., 8:00 PM).
   - Interval: set repeat to **“1 day”** instead of “1 week”.
5. Click **Next** until the end, then **Save**.

Duplicati will start using the new schedule from then on. You can switch between daily and weekly later with the same steps; no need to recreate the job.
