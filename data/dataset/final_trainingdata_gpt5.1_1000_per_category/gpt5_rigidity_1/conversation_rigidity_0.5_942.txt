### Human: Yeah, file naming is a disaster. Can you suggest something simple I can actually stick with?

### Assistant: Use a format that’s short, consistent, and easy to scan. For client design work, try:

`Client_Project_AssetType_V##_YYYYMMDD.ext`

For example:
- `AcmeBrand_Logo_Concept_V01_20251121.ai`  
- `AcmeBrand_Logo_Final_V03_20251202.png`  
- `BlueCafe_MenuLayout_Print_V02_20251118.pdf`

Key points:
- `Client` – Short client name (no spaces if possible)  
- `Project` – One or two words (`Logo`, `Website`, `BrandRefresh`)  
- `AssetType` – Optional: `Concept`, `Final`, `Social`, `Print`, etc.  
- `V##` – Version number (`V01`, `V02`, …). Only bump it when you send or export a significant revision.  
- `YYYYMMDD` – Keeps files in chronological order when sorted by name.

If that feels too long, we can drop the date and rely on versioning:
`Client_Project_V##.ext`

Want to aim for the full version-with-date, or the shorter one?
