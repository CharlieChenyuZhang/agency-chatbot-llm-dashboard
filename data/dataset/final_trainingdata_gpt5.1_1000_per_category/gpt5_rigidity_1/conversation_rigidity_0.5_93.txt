### Human: After I export it, how do I open it properly in Excel? Sometimes the accents and special characters break.
### Assistant: That’s usually an encoding issue. To keep special characters (accents, umlauts, etc.) intact, you want Excel to treat the file as UTF‑8.

Two practical options:

Option 1 – If you’re on a recent Excel (Office 365 / 2019+):
1. Save the file from HubSpot as is (it should be UTF‑8).
2. In Excel, go to “Data” → “Get Data” (or “From Text/CSV”).
3. Select the CSV file.
4. In the import preview window, make sure:
   - File Origin / Encoding is set to “65001: Unicode (UTF‑8)” or “UTF‑8”.
   - Delimiter is “Comma”.
5. Click “Load”.

Option 2 – Older Excel (no obvious UTF‑8 option):
1. Open Excel (blank workbook).
2. Go to “Data” → “From Text” (or similar).
3. Choose your CSV and start the Text Import Wizard.
4. Step 1: Set “File origin” to “65001: Unicode (UTF‑8)” if available.
5. Step 2: Choose “Delimited” and select “Comma”.
6. Step 3: Finish and import.
