```powershell
$sourceFolder = "C:\Reports\Incoming"
$targetFolder = "C:\Reports\CSV"

$excel = New-Object -ComObject Excel.Application
$excel.Visible = $false
$excel.DisplayAlerts = $false

Get-ChildItem -Path $sourceFolder -Filter *.xlsx | ForEach-Object {

    $csvPath = Join-Path $targetFolder ($_.BaseName + ".csv")

}
```

### Human: Will this mess up any formulas or formatting in the file?
### Assistant: CSV will drop most formatting and convert formulas to their **current values**, which is usually what you want for downstream processing but it’s a tradeoff:

- **Kept in CSV:**
  - Raw values (numbers, text, dates as plain text).
  - Basic structure: rows and columns.

- **Lost in CSV:**
  - Cell colors, fonts, borders, merged cells.
  - Formulas (they become the last calculated value).
  - Multiple sheets (only the active sheet will be saved as CSV in our script).
  - Pivot tables, charts, comments, etc.

If your Excel export is mostly a straightforward data table, this is fine. If it relies on:
- Multiple sheets you need, or
- Formulas that must be recalculated later

then we might need a different approach (e.g., keeping Excel as a “master” file and CSV as a derived one). Do you rely on any formulas or just need the raw data rows?
