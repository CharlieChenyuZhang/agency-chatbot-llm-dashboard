### Human: Root is `C:\Users\Me\Documents` and also `C:\Users\Me\Desktop`. Some project folders: `ClientA`, `ClientB`, `Thesis`, `Photos2023`, `SideProjectGame`, `WorkReports`. Use Rule A, I want project folders to be preferred. Go ahead and give me a script that just does everything.

### Assistant: I’ll give you a script that *can* do everything, but I strongly recommend you run it in **two stages** instead of “fire and forget”:

1. **Stage 1: Scan & log duplicates only** (no deletion).
2. **Stage 2: After you skim the log, enable the deletion line.**

This avoids catastrophic mistakes (e.g., misclassified shared templates).

Below is a PowerShell script that:

- Scans both `Documents` and `Desktop`.
- Computes hashes for files.
- Groups exact duplicates.
- Follows **Rule A**: prefer copies under known project folders you listed.
- By default: only logs what *would* be deleted.
- Can then be switched to actually delete duplicates.

```powershell
# CONFIGURATION
$roots = @(
    "C:\Users\Me\Documents",
    "C:\Users\Me\Desktop"
)

# Project-preferred folders (edit or extend as needed)
$projectFolders = @(
    "ClientA",
    "ClientB",
    "Thesis",
    "Photos2023",
    "SideProjectGame",
    "WorkReports"
)

# Output log path
$logPath = "C:\Users\Me\duplicate_report.csv"

# SAFETY: set to $false first. After review, switch to $true to delete.
$actuallyDelete = $false

Write-Host "Scanning files..."
$files = Get-ChildItem -Path $roots -Recurse -File -ErrorAction SilentlyContinue

# Compute hash for each file
Write-Host "Computing hashes..."
$hashes = $files | ForEach-Object {
    try {
        $hash = Get-FileHash -Algorithm SHA256 -Path $_.FullName -ErrorAction Stop
        [PSCustomObject]@{
            FullName = $_.FullName
            Length   = $_.Length
            Hash     = $hash.Hash
            LastWriteTime = $_.LastWriteTime
        }
    } catch {
        Write-Warning "Failed to hash file: $($_.FullName). Skipping."
    }
}

Write-Host "Grouping duplicates..."
$dupeGroups = $hashes | Group-Object -Property Hash | Where-Object { $_.Count -gt 1 }

$log = @()

foreach ($group in $dupeGroups) {
    $filesInGroup = $group.Group

    # Determine preferred keeper based on project folder presence, then recency.
    $keeper = $null

    # 1) Try to find any file under a project folder
    $projectMatches = $filesInGroup | Where-Object {
        $path = $_.FullName.ToLower()
        $projectFolders | ForEach-Object {
            if ($path -like "*\$_\*" -or $path -like "*\$_") { return $true }
        } | Where-Object { $_ -eq $true }
    }

    if ($projectMatches.Count -gt 0) {
        # Among project matches, keep the most recently modified
        $keeper = $projectMatches | Sort-Object LastWriteTime -Descending | Select-Object -First 1
    } else {
        # 2) Fallback: keep the most recent modification date
        $keeper = $filesInGroup | Sort-Object LastWriteTime -Descending | Select-Object -First 1
    }

    $duplicates = $filesInGroup | Where-Object { $_.FullName -ne $keeper.FullName }

    foreach ($dupe in $duplicates) {
        $entry = [PSCustomObject]@{
            Hash          = $group.Name
            Keeper        = $keeper.FullName
            ToDelete      = $dupe.FullName
            KeeperDate    = $keeper.LastWriteTime
            ToDeleteDate  = $dupe.LastWriteTime
            FileSizeBytes = $dupe.Length
        }
        $log += $entry

        if ($actuallyDelete) {
            try {
                Remove-Item -LiteralPath $dupe.FullName -Force
            } catch {
                Write-Warning "Could not delete $($dupe.FullName): $($_.Exception.Message)"
            }
        }
    }
}

Write-Host "Writing log to $logPath"
$log | Export-Csv -Path $logPath -NoTypeInformation -Encoding UTF8

Write-Host "Done. actuallyDelete = $actuallyDelete"
Write-Host "Review $logPath before enabling deletion."
```

### Assistant: I can combine them, but doing *deduplication and large-scale moves in a single run* is risky: if something goes wrong, it’s harder to diagnose what caused it. A safer compromise:

- **Single script with two clearly separated phases**, each controlled by a toggle:

  2. `RunRefactor`

You’d run the same script twice:
- First with only dedupe = `$true` and refactor = `$false`.
- Then, after checking, flip the switches.

This keeps things in one file but still lets you control the process.

Here’s a combined script outline with both phases:

```powershell
# ==== CONFIG ====
$roots = @(
    "C:\Users\Me\Documents",
    "C:\Users\Me\Desktop"
)

$projectFolders = @(
    "ClientA",
    "ClientB",
    "Thesis",
    "Photos2023",
    "SideProjectGame",
    "WorkReports"
)

$dedupeLogPath   = "C:\Users\Me\duplicate_report.csv"
$refactorLogPath = "C:\Users\Me\refactor_moves.csv"

# Toggles
$RunDeduplication = $true   # first run: $true, second run: maybe $false
$RunRefactor      = $false  # first run: $false, after checking, set to $true

# Dedupe safety switch
$actuallyDelete = $false    # change to $true after reviewing dedupe log

# Refactor safety switch
$actuallyMove = $false      # change to $true after reviewing refactor log

# Target base for projects and misc
$projectsBase = "C:\Users\Me\Documents\Projects"
$miscBase     = "C:\Users\Me\Documents\Misc\ByType"

# ==== HELPER: Ensure folder exists ====
function Ensure-Folder {
    param([string]$path)
    if (!(Test-Path -LiteralPath $path)) {
        New-Item -ItemType Directory -Path $path | Out-Null
    }
}

# ==== PHASE 1: DEDUPLICATION ====
if ($RunDeduplication) {
    Write-Host "=== PHASE 1: DEDUPLICATION ==="

    Write-Host "Scanning files..."
    $files = Get-ChildItem -Path $roots -Recurse -File -ErrorAction SilentlyContinue

    Write-Host "Computing hashes..."
    $hashes = $files | ForEach-Object {
        try {
            $hash = Get-FileHash -Algorithm SHA256 -Path $_.FullName -ErrorAction Stop
            [PSCustomObject]@{
                FullName      = $_.FullName
                Length        = $_.Length
                Hash          = $hash.Hash
                LastWriteTime = $_.LastWriteTime
            }
        } catch {
            Write-Warning "Failed to hash $($_.FullName). Skipping."
        }
    }

    Write-Host "Grouping duplicates..."
    $dupeGroups = $hashes | Group-Object -Property Hash | Where-Object { $_.Count -gt 1 }

    $dedupeLog = @()

    foreach ($group in $dupeGroups) {
        $filesInGroup = $group.Group

        # Determine keeper per Rule A
        $keeper = $null

        $projectMatches = $filesInGroup | Where-Object {
            $path = $_.FullName.ToLower()
            $projectFolders | ForEach-Object {
                if ($path -like "*\$_\*" -or $path -like "*\$_") { return $true }
            } | Where-Object { $_ -eq $true }
        }

        if ($projectMatches.Count -gt 0) {
            $keeper = $projectMatches | Sort-Object LastWriteTime -Descending | Select-Object -First 1
        } else {
            $keeper = $filesInGroup | Sort-Object LastWriteTime -Descending | Select-Object -First 1
        }

        $duplicates = $filesInGroup | Where-Object { $_.FullName -ne $keeper.FullName }

        foreach ($dupe in $duplicates) {
            $entry = [PSCustomObject]@{
                Hash          = $group.Name
                Keeper        = $keeper.FullName
                ToDelete      = $dupe.FullName
                KeeperDate    = $keeper.LastWriteTime
                ToDeleteDate  = $dupe.LastWriteTime
                FileSizeBytes = $dupe.Length
            }
            $dedupeLog += $entry

            if ($actuallyDelete) {
                try {
                    Remove-Item -LiteralPath $dupe.FullName -Force
                } catch {
                    Write-Warning "Could not delete $($dupe.FullName): $($_.Exception.Message)"
                }
            }
        }
    }

    Write-Host "Writing dedupe log to $dedupeLogPath"
    $dedupeLog | Export-Csv -Path $dedupeLogPath -NoTypeInformation -Encoding UTF8

    Write-Host "Deduplication complete. actuallyDelete = $actuallyDelete"
    Write-Host "Review $dedupeLogPath before enabling deletion."
}

# ==== PHASE 2: REFACTOR / MOVE FILES ====
if ($RunRefactor) {
    Write-Host "=== PHASE 2: REFACTOR ==="

    Ensure-Folder $projectsBase
    Ensure-Folder $miscBase

    # Map project names to target folders
    $projectTargets = @{}
    foreach ($proj in $projectFolders) {
        $target = Join-Path $projectsBase $proj
        Ensure-Folder $target
        $projectTargets[$proj.ToLower()] = $target
    }

    # File-type-based folders under Misc
    $typeFolders = @{
        "pdf"  = "PDFs"
        "doc"  = "Docs"
        "docx" = "Docs"
        "txt"  = "Text"
        "jpg"  = "Images"
        "jpeg" = "Images"
        "png"  = "Images"
        "gif"  = "Images"
        "cs"   = "Code"
        "py"   = "Code"
        "js"   = "Code"
        "java" = "Code"
    }

    $allFiles = Get-ChildItem -Path $roots -Recurse -File -ErrorAction SilentlyContinue
    $refactorLog = @()

    foreach ($file in $allFiles) {
        $pathLower = $file.FullName.ToLower()
        $assigned  = $false

        # 1) Project-based assignment if path contains project name
        foreach ($proj in $projectTargets.Keys) {
            if ($pathLower -like "*\$proj\*" -or $pathLower -like "*\$proj") {
                $targetBase = $projectTargets[$proj]
                $assigned = $true
                break
            }
        }

        $targetDir = $null

        if ($assigned) {
            # Inside project: subfolder by type
            $ext = $file.Extension.TrimStart('.').ToLower()
            $sub = $typeFolders[$ext]
            if (-not $sub) { $sub = "Other" }
            $targetDir = Join-Path $targetBase $sub
        } else {
            # 2) Misc area: by type
            $ext = $file.Extension.TrimStart('.').ToLower()
            $sub = $typeFolders[$ext]
            if (-not $sub) { $sub = "Other" }
            $targetDir = Join-Path $miscBase $sub
        }

        Ensure-Folder $targetDir
        $targetPath = Join-Path $targetDir $file.Name

        # Avoid move if already in correct location
        if ($file.FullName -ieq $targetPath) {
            continue
        }

        $entry = [PSCustomObject]@{
            Source      = $file.FullName
            Destination = $targetPath
        }
        $refactorLog += $entry

        if ($actuallyMove) {
            try {
                # If name collision, add a timestamp suffix
                if (Test-Path -LiteralPath $targetPath) {
                    $baseName = [System.IO.Path]::GetFileNameWithoutExtension($file.Name)
                    $ext      = $file.Extension
                    $stamp    = (Get-Date -Format "yyyyMMdd_HHmmss")
                    $newName  = "$baseName`_$stamp$ext"
                    $targetPath = Join-Path $targetDir $newName
                }
                Move-Item -LiteralPath $file.FullName -Destination $targetPath
            } catch {
                Write-Warning "Could not move $($file.FullName) -> $targetPath : $($_.Exception.Message)"
            }
        }
    }

    Write-Host "Writing refactor log to $refactorLogPath"
    $refactorLog | Export-Csv -Path $refactorLogPath -NoTypeInformation -Encoding UTF8

    Write-Host "Refactor complete. actuallyMove = $actuallyMove"
    Write-Host "Review $refactorLogPath before enabling moves."
}
```
