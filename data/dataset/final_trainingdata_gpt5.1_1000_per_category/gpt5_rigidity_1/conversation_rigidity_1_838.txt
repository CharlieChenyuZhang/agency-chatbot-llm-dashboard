### Assistant: Problem 1: Minimum Length Subarray With Target Sum  
- Problem: Given an array of positive integers nums and an integer target, return the minimal length of a contiguous subarray of which the sum is greater than or equal to target. If there is no such subarray, return 0.
- Constraints:  
  - 1 ≤ len(nums) ≤ 10^5  
  - 1 ≤ nums[i] ≤ 10^4  
  - 1 ≤ target ≤ 10^9
- Example:  
  - Input: target = 7, nums = [2,3,1,2,4,3]  
  - Output: 2  (subarray [4,3])

Solution (sliding window, O(n)):
```python
from math import inf

def min_subarray_len(target, nums):
    n = len(nums)
    left = 0
    current_sum = 0
    min_len = inf

    for right in range(n):
        current_sum += nums[right]
        # Shrink window from the left while condition holds
        while current_sum >= target:
            min_len = min(min_len, right - left + 1)
            current_sum -= nums[left]
            left += 1

    return 0 if min_len == inf else min_len
```
Explanation: Maintain a sliding window [left, right] and expand right to increase sum; whenever the sum reaches or exceeds target, shrink from the left to find the smallest window. Track the minimum length encountered; if none, return 0.

Problem 2: Product of Array Except Self (No Division)  
- Problem: Given an integer array nums, return an array answer such that answer[i] is the product of all the elements of nums except nums[i], without using division.
- Constraints:  
  - 2 ≤ len(nums) ≤ 10^5  
  - -30 ≤ nums[i] ≤ 30  
  - The product of any prefix or suffix fits in 32-bit signed integer.
- Example:  
  - Input: nums = [1,2,3,4]  
  - Output: [24,12,8,6]

Solution (prefix and suffix products, O(n) time, O(1) extra space ignoring output):
```python
def product_except_self(nums):
    n = len(nums)
    answer = [1] * n

    # prefix products: answer[i] = product of nums[0..i-1]
    prefix = 1
    for i in range(n):
        answer[i] = prefix
        prefix *= nums[i]

    # suffix products: multiply by product of nums[i+1..end]
    suffix = 1
    for i in range(n - 1, -1, -1):
        answer[i] *= suffix
        suffix *= nums[i]

    return answer
```
Explanation: First pass builds prefix products so answer[i] holds product of elements before i. Second pass walks from right to left, keeping a running suffix product and multiplying it into answer[i]. The result for each i is prefix_product_before_i * suffix_product_after_i.

Problem 3: Longest Subarray with Equal 0s and 1s  
- Problem: Given a binary array nums (only 0s and 1s), return the length of the longest contiguous subarray with an equal number of 0s and 1s.
- Constraints:  
  - 1 ≤ len(nums) ≤ 10^5  
  - nums[i] ∈ {0, 1}
- Example:  
  - Input: nums = [0,1,0,1,1,0,0]  
  - Output: 6  (subarray [0,1,0,1,1,0] has three 0s and three 1s)

Solution (prefix sum + hash map, O(n)):
```python
def find_max_length_equal_zeros_ones(nums):
    # Treat 0 as -1, 1 as +1; equal 0s and 1s => prefix sum repeats
    prefix_sum = 0
    first_index = {0: -1}  # prefix_sum -> earliest index seen
    max_len = 0

    for i, val in enumerate(nums):
        prefix_sum += 1 if val == 1 else -1

        if prefix_sum in first_index:
            # Subarray (first_index[prefix_sum] + 1) .. i has equal 0s and 1s
            length = i - first_index[prefix_sum]
            if length > max_len:
                max_len = length
        else:
            first_index[prefix_sum] = i

    return max_len
```
Explanation: Convert 0 to -1 and 1 to +1, so a subarray with equal 0s and 1s has total sum 0. Track the earliest index where each prefix_sum occurs; when you see the same prefix_sum again, the subarray between the two indices has sum 0. The maximum distance between repeated prefix sums gives the answer.
