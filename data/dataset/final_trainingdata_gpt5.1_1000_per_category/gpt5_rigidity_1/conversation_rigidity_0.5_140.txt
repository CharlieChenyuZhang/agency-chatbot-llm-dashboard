### Human: I think I have Excel 2016 at work, so probably no FILTER function. What’s the older way?
### Assistant: Under Excel 2016, we can get a separate list, but it’s a bit more manual. I’ll suggest a reasonably simple method using a helper column plus INDEX/SMALL. It’s not as clean as FILTER, but it will work.

Assumptions:
- Name = column A
- Price = column B
- Rating = column C
- Headers in row 1, data from row 2 downward.

Step 1 – Helper column to mark rows that match
1. Insert a new column D, title it “Match”.
2. In D2, enter:
   =IF(AND(C2>=80, B2<50), 1, "")
3. Copy D2 down for all rows with data.

Now every matching product row has a 1 in column D.

Step 2 – Extract matching names into a separate list
1. Choose where you want the result list, say column F:
   - F1: “Filtered Names”
2. In F2, enter this array formula:

   =IFERROR(
      INDEX($A$2:$A$1000,
         SMALL(IF($D$2:$D$1000=1, ROW($D$2:$D$1000)-ROW($D$2)+1),
               ROW(A1)
         )
      ),
   "")

3. Since this is Excel 2016, you need to confirm this as an array formula:
   - Click in the formula bar
   - Press Ctrl+Shift+Enter (not just Enter)
   - Excel will show curly braces { } around the formula if it’s accepted as an array.
4. Copy F2 downwards until you start getting blanks.

How it works:
- The IF part picks out the row indices where Match = 1.
- SMALL gets the 1st, 2nd, 3rd, … matching row as you go down.
- INDEX returns the corresponding Name.
