Task Tracker – Scope & Structure

Core features (MVP only):
1) Add a task with:
   - Title (required)
   - Optional: simple category or due date (you can skip these if time is tight).
2) Mark task as completed / not completed.
3) Delete a task.
4) Filter view: “All / Active / Completed”.
5) Persist tasks to localStorage so they survive page reloads.

Non-goals (to keep it manageable):
- No user accounts or backend.
- No subtasks.
- No drag-and-drop (unless you have extra time later).
- No complex categories/tags.

Simple UI layout:
- Header: app title.
- Form: input + “Add task” button.
- Filters: three buttons or a select (All, Active, Completed).
- Task list: list of items with checkbox + text + delete icon/button.
- Footer: maybe a small counter (e.g., “3 tasks remaining”).

Suggested file structure:
- index.html
- styles.css
- app.js

Basic data shape in JS:
- Each task: { id: string, title: string, completed: boolean }

Key JS steps:
1) Load tasks from localStorage on page load.
2) Render the list based on current filter.
3) Handle:
   - Submit form → create new task → push into array → save to localStorage → re-render.
   - Click checkbox → toggle completed → save → re-render.
   - Click delete → remove from array → save → re-render.
   - Click filter button → set currentFilter variable → re-render.

This keeps it nicely contained. If you’re tempted to add a lot more features later, we can choose one “stretch goal” (like simple stats or sorting) rather than many.
