**4. GitHub API calls**

Goal for v1: list merged PRs between two tags. To do that correctly, you really need the date/time of each tag, then query PRs merged in that time range.

**4.1 Get tag commit dates**

Endpoint:  
`GET /repos/{owner}/{repo}/git/ref/tags/{tag}` is not always enough; better:

1. Get tag → commit SHA:
   - `GET /repos/{owner}/{repo}/git/ref/tags/{tag}`
2. Then get commit details:
   - `GET /repos/{owner}/{repo}/commits/{sha}`

But an easier and more stable way for a first version is:

- `GET /repos/{owner}/{repo}/releases/tags/{tag}`

which returns a release with `published_at`. This assumes you use GitHub Releases with tags. If your team doesn’t always create Releases, you may need the commit-based approach.

For now, let’s assume releases exist:

```http
GET https://api.github.com/repos/{owner}/{repo}/releases/tags/{tag}
Authorization: Bearer <token>
Accept: application/vnd.github+json
```

Response has `published_at` which you can treat as your from/to boundaries.

**4.2 Search PRs merged in a date range**

Two approaches:

- a) Use the Search API:
  - `GET /search/issues?q=repo:owner/repo+is:pr+is:merged+merged:YYYY-MM-DD..YYYY-MM-DD`
  - Pros: simple.
  - Cons: Limited to day granularity; some rate limits.

- b) List PRs and filter by merge date:
  - `GET /repos/{owner}/{repo}/pulls?state=closed&sort=updated&direction=desc`
  - Paginate and filter by `merged_at`.
  - Pros: More precise.
  - Cons: Slightly more work.

For a first version, I’d use **(b)** for better precision and no search query complexity.

You’ll:
1. Fetch PR pages (e.g., 50 per page) until all `merged_at` dates are older than your `fromTag` date.
2. Filter PRs where `merged_at` is between `fromDate` and `toDate`.

**5. Implementing GitHubClient**

`GitHubClient.kt` (conceptual):

```kotlin
package github

import io.ktor.client.*
import io.ktor.client.call.*
import io.ktor.client.plugins.contentnegotiation.*
import io.ktor.client.request.*
import io.ktor.http.*
import io.ktor.serialization.kotlinx.json.*
import kotlinx.serialization.Serializable
import kotlinx.serialization.json.Json
import java.time.Instant

class GitHubClient(private val token: String) {

    private val client = HttpClient {
        install(ContentNegotiation) {
            json(Json { ignoreUnknownKeys = true })
        }
        defaultRequest {
            header(HttpHeaders.Authorization, "Bearer $token")
            header(HttpHeaders.Accept, "application/vnd.github+json")
        }
    }

    suspend fun getReleaseByTag(owner: String, repo: String, tag: String): GitHubRelease {
        return client.get("https://api.github.com/repos/$owner/$repo/releases/tags/$tag").body()
    }

    suspend fun getMergedPullRequests(
        owner: String,
        repo: String,
        from: Instant,
        to: Instant
    ): List<PullRequest> {
        val results = mutableListOf<PullRequest>()
        var page = 1
        val perPage = 50

        while (true) {
            val prs: List<PullRequest> = client.get("https://api.github.com/repos/$owner/$repo/pulls") {
                parameter("state", "closed")
                parameter("sort", "updated")
                parameter("direction", "desc")
                parameter("page", page)
                parameter("per_page", perPage)
            }.body()

            if (prs.isEmpty()) break

            val mergedInRange = prs.filter { pr ->
                pr.mergedAt?.let {
                    val t = Instant.parse(it)
                    t.isAfter(from) && t.isBefore(to)
                } ?: false
            }

            results += mergedInRange

            // Stop if all PRs in this page are older than from
            val newestInPage = prs.maxByOrNull { it.mergedAt ?: prCreatedFallback(it) }
            val newestInstant = newestInPage?.mergedAt?.let(Instant::parse)
            if (newestInstant == null || !newestInstant.isAfter(from)) {
                break
            }

            page++
        }

        return results
    }

    private fun prCreatedFallback(pr: PullRequest): Instant =
        Instant.parse(pr.createdAt)

}

@Serializable
data class GitHubRelease(
    val tag_name: String,
    val published_at: String? = null
)

@Serializable
data class PullRequest(
    val number: Int,
    val title: String,
    val body: String? = null,
    val labels: List<Label> = emptyList(),
    val merged_at: String? = null,
    val created_at: String
) {
    val mergedAt: String?
        get() = merged_at
    val createdAt: String
        get() = created_at
}

@Serializable
data class Label(
    val name: String
)
```

This is conceptual; you’ll have to adjust types, nullability, and stopping conditions.

**6. Release notes generation**

`CategoryConfig.kt`:

```kotlin
package release

data class Category(
    val title: String,
    val emoji: String? = null,
    val labelNames: Set<String>
)

object DefaultCategories {
    val Features = Category("Features", "🚀", setOf("feature", "enhancement"))
    val Fixes = Category("Fixes", "🐞", setOf("bug", "fix"))
    val Chores = Category("Chores", "🧹", setOf("chore", "refactor", "docs"))

    val all = listOf(Features, Fixes, Chores)
}
```

`ReleaseNotesGenerator.kt`:

```kotlin
package release

import github.PullRequest

class ReleaseNotesGenerator(
    private val categories: List<Category> = DefaultCategories.all
) {
    fun generate(prs: List<PullRequest>): String {
        val byCategory = mutableMapOf<Category, MutableList<PullRequest>>()
        categories.forEach { byCategory[it] = mutableListOf() }
        val uncategorized = mutableListOf<PullRequest>()

        prs.forEach { pr ->
            val prLabels = pr.labels.map { it.name.lowercase() }.toSet()
            val matchingCategory = categories.firstOrNull { cat ->
                prLabels.any { it in cat.labelNames }
            }
            if (matchingCategory != null) {
                byCategory.getValue(matchingCategory) += pr
            } else {
                uncategorized += pr
            }
        }

        val sb = StringBuilder()
        categories.forEach { cat ->
            val items = byCategory[cat].orEmpty()
            if (items.isNotEmpty()) {
                sb.appendLine("## ${cat.emoji?.plus(" ") ?: ""}${cat.title}")
                items.forEach { pr ->
                    sb.appendLine("- ${pr.title} (PR #${pr.number})")
                }
                sb.appendLine()
            }
        }

        if (uncategorized.isNotEmpty()) {
            sb.appendLine("## Other")
            uncategorized.forEach { pr ->
                sb.appendLine("- ${pr.title} (PR #${pr.number})")
            }
        }

        return sb.toString().trim()
    }
}
```

**7. Wiring it up in `Main.kt`**

```kotlin
import cli.parseArgs
import github.GitHubClient
import release.ReleaseNotesGenerator
import kotlinx.coroutines.runBlocking
import java.time.Instant

fun main(args: Array<String>) = runBlocking {
    val opts = parseArgs(args)
    val (owner, repo) = opts.repo.split("/", limit = 2)

    val client = GitHubClient(opts.token)
    val fromRelease = client.getReleaseByTag(owner, repo, opts.fromTag)
    val toRelease = client.getReleaseByTag(owner, repo, opts.toTag)

    val fromInstant = Instant.parse(fromRelease.published_at
        ?: error("Release ${opts.fromTag} has no published_at"))
    val toInstant = Instant.parse(toRelease.published_at
        ?: error("Release ${opts.toTag} has no published_at"))

    val prs = client.getMergedPullRequests(owner, repo, fromInstant, toInstant)
    val generator = ReleaseNotesGenerator()
    val notes = generator.generate(prs)

    println(notes)
}
```

This assumes:
- Releases exist for both tags.
- `published_at` is non-null.
If that’s not always true in your real world, we’d need a fallback using commit dates instead. That’s more work but doable.
