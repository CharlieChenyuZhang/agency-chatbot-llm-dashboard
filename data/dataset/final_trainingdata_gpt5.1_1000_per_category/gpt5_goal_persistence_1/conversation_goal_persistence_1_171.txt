**Question:**  
You’re given network 192.168.10.0/24. You need subnets that can handle at least 50 hosts each.  
What subnet mask should you use, and how many such subnets can you get?

Step 1 – How many host addresses per subnet?
- Need ≥ 50 usable hosts.
- Formula: 2^h – 2 ≥ required hosts.
  - Try h = 5 → 2^5 – 2 = 32 – 2 = 30 (too small).
  - Try h = 6 → 2^6 – 2 = 64 – 2 = 62 (good, ≥ 50).
- So we need 6 host bits.

Step 2 – Determine prefix length
- IPv4 address has 32 bits total.
- If host bits = 6, then network bits = 32 – 6 = 26.
- So our new subnet mask is **/26**.

Step 3 – How many such subnets from /24 to /26?
- We started with /24, moving to /26.
- We borrowed 2 bits (because 24 → 26 is +2).
- Number of subnets = 2^borrowed = 2^2 = **4 subnets**.

Step 4 – Optional: list the subnet ranges
- A /26 has 64 IPs per block (because 2^6 = 64).
- Starting from 192.168.10.0/24:
  - 192.168.10.0 – 63
  - 192.168.10.64 – 127
  - 192.168.10.128 – 191
  - 192.168.10.192 – 255
