#### 1. Basic Anki setup (once)

1. Install Anki (desktop is best) and create a free account to enable syncing.

3. In options for that deck:

#### 2. Card types that work well for networking

Use 3 main patterns:

1. **Definition cards**
   - Front: “What is the purpose of the ARP protocol?”
   - Back: “Maps IP addresses to MAC addresses within a local network.”

2. **Parameter/config cards**
   - Front: “Default admin distance for OSPF?”  
   - Back: “110”
   - Front: “TCP port number for HTTPS?”  
   - Back: “443”

3. **Scenario/behavior cards**
   - Front: “What happens when a switch receives a frame with an unknown destination MAC?”  
   - Back: “It floods the frame out all ports except the incoming port.”

Keep each card to exactly one idea.

#### 3. How to turn a textbook paragraph into cards (example)

Suppose the book section says:

> OSPF is a link-state routing protocol that uses Dijkstra’s algorithm, supports VLSM, and has an administrative distance of 110.

You create 3–4 cards:

1. Front: “OSPF is what type of routing protocol?”  
   Back: “Link-state.”

2. Front: “Which algorithm does OSPF use for path calculation?”  
   Back: “Dijkstra’s algorithm (shortest path first).”

3. Front: “Does OSPF support VLSM and CIDR?”  
   Back: “Yes, it supports both.”

4. Front: “What is the default administrative distance of OSPF?”  
   Back: “110.”
