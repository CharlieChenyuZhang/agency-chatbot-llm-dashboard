### Assistant: Great. A simple way on Windows is to use a small PowerShell script.

1. Press `Win + R`, type `notepad`, and press Enter.  
2. Paste this into Notepad:

```powershell
Start-Sleep -Seconds 1500
[System.Windows.Forms.MessageBox]::Show("25 minutes are up!", "Timer")
```

3. At the top of the file, add this line so the message box works:

```powershell
Add-Type -AssemblyName System.Windows.Forms
Start-Sleep -Seconds 1500
[System.Windows.Forms.MessageBox]::Show("25 minutes are up!", "Timer")
```

4. Save the file as, for example, `timer.ps1` (make sure the extension is `.ps1`, not `.txt`).  
5. Right-click the file and choose **Run with PowerShell**.

That will wait 1500 seconds (25 minutes) and then show a popup saying the time is up.

If anything in these steps doesn’t work, tell me what happened and I’ll adjust.
