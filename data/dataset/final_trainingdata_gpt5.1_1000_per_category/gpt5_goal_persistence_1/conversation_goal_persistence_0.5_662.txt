Next, we’ll create a script that copies Desktop and Documents to a folder like:
C:\Users\jdoe\OneDrive - Contoso Ltd\PC-Backups

And each run will create a subfolder with today’s date.

1) Press Windows key, type “Notepad,” and open it.
2) Paste this script into Notepad (don’t run it yet):

powershell -NoProfile -ExecutionPolicy Bypass -Command ^
  "$date = Get-Date -Format 'yyyy-MM-dd'; ^
   $sourceDesktop = '$env:USERPROFILE\Desktop'; ^
   $sourceDocs = '$env:USERPROFILE\Documents'; ^
   $destRoot = 'C:\Users\jdoe\OneDrive - Contoso Ltd\PC-Backups'; ^
   $dest = Join-Path $destRoot $date; ^
   New-Item -ItemType Directory -Force -Path $dest | Out-Null; ^
   robocopy $sourceDesktop (Join-Path $dest 'Desktop') /MIR /R:1 /W:1; ^
   robocopy $sourceDocs   (Join-Path $dest 'Documents') /MIR /R:1 /W:1;"

3) Save the file as: C:\Users\jdoe\backup_weekly.bat
