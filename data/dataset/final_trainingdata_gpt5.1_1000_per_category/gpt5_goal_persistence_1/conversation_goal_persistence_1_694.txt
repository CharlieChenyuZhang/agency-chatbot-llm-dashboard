- Copies your Desktop and Documents into that dated folder.

Script (you can copy this):

```powershell
# backup-weekly.ps1

$timestamp = Get-Date -Format "yyyy-MM-dd_HHmm"
$oneDriveRoot = "C:\Users\jane.doe\OneDrive - Contoso"
$backupRoot   = Join-Path $oneDriveRoot "BackupExports"
$backupFolder = Join-Path $backupRoot "Backup_$timestamp"

# Create target folder
New-Item -ItemType Directory -Path $backupFolder -Force | Out-Null

# Define source folders
$desktop   = [Environment]::GetFolderPath("Desktop")
$documents = [Environment]::GetFolderPath("MyDocuments")

# Copy Desktop
Write-Host "Backing up Desktop from $desktop"
Copy-Item -Path $desktop\* -Destination (Join-Path $backupFolder "Desktop") -Recurse -Force -ErrorAction SilentlyContinue

# Copy Documents
Write-Host "Backing up Documents from $documents"
Copy-Item -Path $documents\* -Destination (Join-Path $backupFolder "Documents") -Recurse -Force -ErrorAction SilentlyContinue
```

Options that don’t require raising permissions:

1) Use a one-liner PowerShell command from Task Scheduler that contains the logic directly (sometimes still blocked, but less often).
2) Use a plain old batch (.bat) file with only built-in commands like xcopy/robocopy.

The most compatible, least policy-sensitive choice is a .bat file using robocopy, which is built into Windows.

Let’s switch to a batch script:

1) Open Notepad.
2) Paste this content (adjusting the path if needed):

```bat
@echo off
setlocal

rem Set OneDrive root
set "ONEDRIVE_ROOT=C:\Users\jane.doe\OneDrive - Contoso"
set "BACKUP_ROOT=%ONEDRIVE_ROOT%\BackupExports"

rem Generate timestamp
for /f "tokens=1-4 delims=/ " %%a in ("%date%") do (
    set YYYY=%%d
    set MM=%%b
    set DD=%%c
)
for /f "tokens=1 delims=." %%a in ("%time%") do set TIME=%%a
set TIME=%TIME::=%
set "STAMP=%YYYY%-%MM%-%DD%_%TIME%"

set "TARGET=%BACKUP_ROOT%\Backup_%STAMP%"

mkdir "%TARGET%\Desktop"
mkdir "%TARGET%\Documents"

rem Get user profile
set "USERPROFILE=%USERPROFILE%"

rem Backup Desktop
robocopy "%USERPROFILE%\Desktop" "%TARGET%\Desktop" /MIR /R:2 /W:5

rem Backup Documents
robocopy "%USERPROFILE%\Documents" "%TARGET%\Documents" /MIR /R:2 /W:5

endlocal
```

3) Save it as: `backup-weekly.bat` in a folder you control, e.g. `C:\Users\jane.doe\Scripts\backup-weekly.bat`.
