Generic SQL pattern for first vs. repeat purchases (Snowflake-ish syntax):

1) Identify first order per customer:
WITH first_orders AS (
  SELECT
    customer_id,
    MIN(order_date) AS first_order_date
  FROM orders
  GROUP BY customer_id
),

first_order_details AS (
  SELECT
    o.customer_id,
    o.order_id AS first_order_id,
    o.order_date AS first_order_date,
    o.channel,
    o.total_amount,
    o.discount_amount,
    o.primary_category
  FROM orders o
  JOIN first_orders f
    ON o.customer_id = f.customer_id
   AND o.order_date = f.first_order_date
)

2) Find second purchase within 90 days:
, second_purchases AS (
  SELECT
    o.customer_id,
    MIN(o.order_date) AS second_order_date
  FROM orders o
  JOIN first_order_details f
    ON o.customer_id = f.customer_id
   AND o.order_date > f.first_order_date
   AND o.order_date <= DATEADD(day, 90, f.first_order_date)
  GROUP BY o.customer_id
)

3) Combine and calculate churn flag:
SELECT
  f.customer_id,
  f.first_order_date,
  f.channel,
  f.total_amount,
  f.discount_amount,
  f.primary_category,
  CASE WHEN s.second_order_date IS NULL THEN 1 ELSE 0 END AS churn_90d,
  s.second_order_date
FROM first_order_details f
LEFT JOIN second_purchases s
  ON f.customer_id = s.customer_id;

From there, you can:
- GROUP BY channel, primary_category, discount_band, etc.
- Compute churn_90d_rate = AVG(churn_90d) per segment.
