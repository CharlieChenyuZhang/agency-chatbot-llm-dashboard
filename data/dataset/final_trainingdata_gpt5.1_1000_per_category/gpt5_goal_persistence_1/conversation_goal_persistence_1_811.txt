### Human: I'm on Windows 11, and I have a free Google Drive account. I want to back up my Documents folder once a week.

### Assistant: Great, we can do this with Google’s “Drive for desktop” app plus Windows Task Scheduler to enforce a weekly backup pattern.

First, let’s install and configure syncing:

1) Install Google Drive for desktop  
   - Go to: https://www.google.com/drive/download  
   - Under “For individuals,” download “Drive for desktop.”  
   - Run the installer and sign in with your Google account.

2) Choose how it syncs  
   - When prompted, choose “Sync with Google Drive” (you can use either “Mirror files” or “Stream files”; for backups, “Mirror files” is simpler but uses local disk space).  
   - Make sure a “Google Drive” folder appears in File Explorer (usually under This PC → Google Drive).

3) Create a backup folder in Drive  
   - In File Explorer, open the Google Drive folder.  
   - Create a folder named “Weekly Documents Backup” (or similar).

Now we’ll set up an automated weekly copy of your Documents folder into that Drive folder using Task Scheduler and a small batch script.

4) Create the backup script  
   - Press Win+R, type `notepad`, press Enter.

   ```
   robocopy "C:\Users\YourUser\Documents" "C:\Users\YourUser\Google Drive\Weekly Documents Backup" /MIR /R:3 /W:5 /XF Thumbs.db /XD Temp
   ```

   - Replace `YourUser` with your actual Windows username.  
   - Click File → Save As…  
   - Set “Save as type” to “All Files (*.*)”.  
   - Name it: `weekly_docs_backup.bat`  
   - Save it somewhere stable, e.g. `C:\Scripts\weekly_docs_backup.bat` (create C:\Scripts if it doesn’t exist).

   - In the right pane, click “Create Basic Task…”

   - Trigger: “Weekly” → choose day/time you want (e.g., Sunday at 7 PM).  
   - Action: “Start a program.”  
   - Program/script: `C:\Scripts\weekly_docs_backup.bat` (browse to select it).  
   - Finish.

That will run the script once a week and copy your Documents into your Google Drive folder, which then syncs to the cloud.
