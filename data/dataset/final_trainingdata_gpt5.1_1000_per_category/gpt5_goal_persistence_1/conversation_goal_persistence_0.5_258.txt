### Assistant: For a portfolio project, clarity and simplicity matter more than perfect scalability.

Two common approaches:

1) Separate collections (more “realistic”)
   - `/users/{userId}/habits/{habitId}`
   - `/users/{userId}/habitCompletions/{completionId}`
   - Each completion doc: `{ habitId, date, status }`

Pros:
- Easy to query completions by date range.
- Scales better if you add more analytics later.

Cons:
- Slightly more complex code.

2) Embedded completions inside habit docs (simpler to reason about)
   - `/users/{userId}/habits/{habitId}`
   - Each habit has a field like `completions: Record<string, boolean>` where key = date string (`"2025-11-21"`).

Pros:
- Fewer collections.
- Easy to load everything for one habit.

Cons:
- Can get large if used heavily.
- Less flexible for advanced queries.

For your use case (simple tracker + showcase), I’d pick option 2. It keeps the code readable and demonstrates enough modeling thought.

Create a habit:

```ts
import {
  collection,
  addDoc,
  serverTimestamp,
} from "firebase/firestore";
import { db } from "./firebase";

export async function createHabit(userId: string, name: string) {
  const habitsRef = collection(db, "users", userId, "habits");

  const docRef = await addDoc(habitsRef, {
    userId,
    name,
    createdAt: serverTimestamp(),
    completions: {}, // start empty
  });

  return docRef.id;
}
```

Read all habits for a user:

```ts
import {
  collection,
  getDocs,
} from "firebase/firestore";
import { db } from "./firebase";
import type { Habit } from "./types";

export async function getHabits(userId: string): Promise<Habit[]> {
  const habitsRef = collection(db, "users", userId, "habits");
  const snapshot = await getDocs(habitsRef);

  const habits: Habit[] = snapshot.docs.map((doc) => {
    const data = doc.data();

    return {
      id: doc.id,
      userId: data.userId as string,
      name: data.name as string,
      createdAt: (data.createdAt?.toDate?.().toISOString?.() ??
        new Date().toISOString()) as string,
      completions: (data.completions ?? {}) as Record<string, boolean>,
    };
  });

  return habits;
}
```

Toggle completion for a given date:

```ts
import {
  doc,
  getDoc,
  updateDoc,
} from "firebase/firestore";
import { db } from "./firebase";
import type { ISODateString } from "./types";

export async function toggleHabitCompletion(
  userId: string,
  habitId: string,
  date: ISODateString
) {
  const habitRef = doc(db, "users", userId, "habits", habitId);
  const snapshot = await getDoc(habitRef);

  if (!snapshot.exists()) {
    throw new Error("Habit not found");
  }

  const data = snapshot.data();
  const completions = (data.completions ?? {}) as Record<string, boolean>;

  const current = completions[date] === true;
  const updated = { ...completions, [date]: !current };

  await updateDoc(habitRef, {
    completions: updated,
  });
}
```

This is not the most optimized (reads the doc before writing), but it’s perfectly fine for a portfolio project and shows clear logic.
