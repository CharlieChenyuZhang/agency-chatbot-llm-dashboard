### Human: It works, the text changes. But I don't really understand what that code means.
### Assistant: That’s normal at this stage. Let’s break it down in simple terms:

```js
const button = document.getElementById('myButton');
const message = document.getElementById('message');
```
- Think of `const` as “create a named box to hold something.”
- `button` is a box that holds the button element from the page (the one with `id="myButton"`).
- `message` holds the `<p>` element with `id="message"`.

```js
button.addEventListener('click', function () {
  message.textContent = 'You clicked the button! 🎉';
});
```
- “When someone **clicks** the button, run this function (a little recipe of steps).”
- That function changes the text of the `message` paragraph.

Very rough mapping:
- **variables** (`const button`) → labels for things
- **functions** (`function () { ... }`) → reusable steps
- **events** (`'click'`) → “when X happens, do Y”
