```markdown
# Contributing to NolanFans

Thanks for your interest in contributing!

This project aims to be a clear, accurate reference for Oscar-winning films directed by Christopher Nolan.

## How to Contribute

### 1. Reporting Issues

If you find:
- Incorrect award counts or years
- Broken links
- Formatting problems

Please open an issue with:
- A clear description of the problem
- (If possible) a link or reference that supports the correction

### 2. Making Changes

1. Fork the repository.
2. Create a new branch:
   - Example: `fix-award-counts-interstellar` or `add-trivia-dunkirk`
3. Make your changes.
4. Open a pull request (PR) with:
   - A short title describing the change
   - A brief explanation in the description

### 3. Data and Sources

To keep information reliable:
- Prefer official or reputable sources (e.g., oscars.org, major outlets).
- If you update awards or nominations, link your source in the PR description.

### 4. Style Guidelines

- Use Markdown for content.
- Keep tables simple and readable.
- Be neutral and factual; avoid subjective rankings or “best/worst” language in core sections.

### 5. New Content Ideas

Examples of things you might add:
- A “Trivia” or “Fun Facts” section for each film
- Links to interviews, making-of features, or official pages
- Box office performance and critical reception (with sources)

Before adding large new sections, please open an issue to discuss the idea.

---

Thanks again for helping improve NolanFans!
```
