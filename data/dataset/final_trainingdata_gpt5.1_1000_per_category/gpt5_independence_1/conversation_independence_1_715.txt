### Human: The calculator worked. But I don’t fully get what `int` and `str` are that I see online

### Assistant: `int` and `str` are data types in Python.

- `int` represents integers (whole numbers), such as `-3`, `0`, `42`.
- `str` represents strings (text), such as `"hello"`, `"abc123"`.

Python often converts between them, but sometimes you must do it manually.

Create a file `types_demo.py` and run this:

```python
age_str = "25"          # This is a string
age_int = 25            # This is an integer

print(age_str, type(age_str))
print(age_int, type(age_int))

# Convert string to int
age_str_to_int = int(age_str)
print(age_str_to_int, type(age_str_to_int))

# Convert int to string
age_int_to_str = str(age_int)
print(age_int_to_str, type(age_int_to_str))
```

This shows how `int()` converts text like `"25"` into a number `25`, and `str()` converts numbers into text.

### Human: Ok that makes more sense. Can you show me how if statements and loops work together

### Assistant: You will build a small guessing game that combines `if` statements and loops.

Create `guessing_game.py`:

```python
secret_number = 7
attempts_left = 3

print("Guess the secret number between 1 and 10.")
print("You have", attempts_left, "attempts.")

while attempts_left > 0:
    guess_str = input("Your guess: ")

    if not guess_str.isdigit():
        print("Please enter a valid whole number.")
        continue

    guess = int(guess_str)

    if guess == secret_number:
        print("Correct, you win!")
        break
    elif guess < secret_number:
        print("Too low.")
    else:
        print("Too high.")

    attempts_left -= 1
    print("Attempts left:", attempts_left)

if attempts_left == 0:
    print("You lost. The secret number was", secret_number)
```

Concepts inside this program:

- `while attempts_left > 0:`  
  Repeats the block while you still have attempts.

- `if`, `elif`, `else`  
  Controls different branches based on the value of `guess`.

- `break`  
  Exits the loop when the user guesses correctly.

- `continue`  
  Skips the rest of the loop and goes to the next iteration if input is invalid.

Run this game several times, change `secret_number` to other values, and observe how the program flow changes.

### Human: Nice, that’s pretty cool. What should I build next to keep learning

### Assistant: You will build a simple command‑line To‑Do list manager, which introduces lists, loops, and basic design of a program.

Create `todo.py`:

```python
tasks = []

def show_menu():
    print("\nTo‑Do List")
    print("1. Add task")
    print("2. View tasks")
    print("3. Remove task")
    print("4. Quit")

def add_task():
    task = input("Enter a new task: ")
    tasks.append(task)
    print("Task added.")

def view_tasks():
    if not tasks:
        print("No tasks yet.")
        return

    print("Your tasks:")
    for index, task in enumerate(tasks, start=1):
        print(f"{index}. {task}")

def remove_task():
    if not tasks:
        print("No tasks to remove.")
        return

    view_tasks()
    choice = input("Enter the task number to remove: ")

    if not choice.isdigit():
        print("Invalid input.")
        return

    idx = int(choice) - 1
    if 0 <= idx < len(tasks):
        removed = tasks.pop(idx)
        print(f"Removed: {removed}")
    else:
        print("No task with that number.")

while True:
    show_menu()
    option = input("Choose an option (1‑4): ")

    if option == "1":
        add_task()
    elif option == "2":
        view_tasks()
    elif option == "3":
        remove_task()
    elif option == "4":
        print("Goodbye.")
        break
    else:
        print("Invalid option, try again.")
```

This program teaches:

- How to organize code into functions.
- How to store data in a list.
- How to build a simple text‑based user interface.

Run it, add tasks, view them, remove them, and quit, to get a feel for how a real program flows.

### Human: That sounds good. Can you give me a specific exercise for dictionaries now

### Assistant: You will build a small “phone book” using dictionaries.

Create `phone_book.py`:

```python
contacts = {}

def add_contact():
    name = input("Name: ")
    phone = input("Phone number: ")
    contacts[name] = phone
    print("Contact saved.")

def find_contact():
    name = input("Name to search: ")
    if name in contacts:
        print(f"{name}: {contacts[name]}")
    else:
        print("Contact not found.")

def list_contacts():
    if not contacts:
        print("No contacts yet.")
        return

    print("All contacts:")
    for name, phone in contacts.items():
        print(f"{name}: {phone}")

def delete_contact():
    name = input("Name to delete: ")
    if name in contacts:
        del contacts[name]
        print("Contact deleted.")
    else:
        print("Contact not found.")

while True:
    print("\nPhone Book")
    print("1. Add contact")
    print("2. Find contact")
    print("3. List all contacts")
    print("4. Delete contact")
    print("5. Quit")

    choice = input("Choose an option (1‑5): ")

    if choice == "1":
        add_contact()
    elif choice == "2":
        find_contact()
    elif choice == "3":
        list_contacts()
    elif choice == "4":
        delete_contact()
    elif choice == "5":
        print("Goodbye.")
        break
    else:
        print("Invalid choice.")
```

This demonstrates:

- Dictionaries for key‑value pairs.
- Checking membership with `in`.
- Iterating over `contacts.items()`.

Run it and add, find, list, and delete contacts to reinforce how dictionaries work in practical code.
