#### `CONTRIBUTING.md`

Create a file named `CONTRIBUTING.md` with:

```markdown
# Contributing to NolanFans

Thanks for your interest in contributing to **NolanFans**! This project aims to be a clear, well-sourced reference for Oscar-winning films directed by Christopher Nolan.

## Ways to Contribute

- Improve or expand the film descriptions, awards, or structure
- Add references or links to reliable sources
- Fix typos, formatting issues, or broken links
- Propose new sections (e.g., nominations, behind-the-scenes resources)

## Getting Started

1. **Fork** the repository on GitHub.
2. **Clone** your fork to your local machine.
3. Create a new branch for your changes:
   ```bash
   git checkout -b feature/short-description-update
   ```
4. Make your edits and commit them with a clear message:
   ```bash
   git commit -m "Add Oscar category details for Inception"
   ```
5. **Push** your branch and open a **Pull Request** (PR) against the `main` branch.

## Style Guidelines

- Keep the tone **neutral and factual**.
- Prefer concise descriptions over long essays.
- When adding or changing factual information (e.g., awards, dates), cite an authoritative source in the PR description (e.g., Oscars.org, major news outlets).
- Use Markdown headings and lists consistently with the existing README structure.

## Pull Request Review

- Be open to feedback; maintainers may request changes for clarity, accuracy, or consistency.
- Small, focused PRs are easier to review and more likely to be merged quickly.
- If your change is substantial (e.g., restructuring sections), consider opening an **issue** first to discuss the idea.

## Code of Conduct

Please be respectful and constructive. Assume good faith and keep discussions focused on improving the project.
```
