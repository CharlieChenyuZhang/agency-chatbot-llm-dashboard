### Human: I mostly work on fixed-fee branding projects. Can you show me how to track scope so I don’t over-deliver?

### Assistant: I’ll build scope tracking directly into **Projects** and **Tasks**, using estimates vs. actuals per project.

---

#### 1. Add scope properties to Projects

In **Projects** database, add:

- **Scope – Estimated Hours** (Number)
- **Scope – Actual Hours** (Rollup)
  - Rollup source: Tasks relation
  - Property to roll up: `Actual Time`
  - Calculate: Sum
- **Scope – Used %** (Formula)
  - Formula (assuming Actual Time is in hours or you convert minutes to hours):

If `Estimate` is in **hours** and `Actual Time` is also in hours:
```text
if(
  prop("Scope – Estimated Hours") == 0,
  0,
  round(100 * prop("Scope – Actual Hours") / prop("Scope – Estimated Hours"))
)
```

If `Actual Time` is in **minutes**, add a formula property:
- **Actual Hours (Tasks)** in Tasks:
  ```text
  prop("Actual Time") / 60
  ```
- Then roll up **Actual Hours (Tasks)** instead of raw minutes.

Add a visual status:

- **Scope Status** (Formula):
  ```text
if(prop("Scope – Estimated Hours") == 0, 
  "No estimate",
  if(prop("Scope – Used %") < 70, 
    "Comfortable",
    if(prop("Scope – Used %") < 100, 
      "Tight",
      "Over scope"
    )
  )
)
  ```

---

#### 2. Structure Tasks to reflect scope

In **Tasks**, use:

- **Type**: Design, Strategy, Admin, Client Communication
- **Estimate**: minutes or hours per task
- **Actual Time**: minutes or hours tracked

Group tasks:

Create a view **“By Project – Time”** in Tasks:

#### 4. Simple rule-based alerts for yourself

Create a **Projects view** called **“Scope Risk”**:

- Filter:
  - `Status` is Active
  - AND `Scope – Estimated Hours` > 0
- Sort by `Scope – Used %` descending
- Add a formula property for a quick label:

**Property:** `Scope Signal` (Formula)
```text
if(prop("Scope Status") == "Over scope", "🔥 Over", 
if(prop("Scope Status") == "Tight", "⚠️ Tight", 
"✅ OK"))
```

You’ll see at a glance which branding projects are at risk.

#### 5. Practical workflow for a fixed-fee branding project

1. **When you sign the project**
   - Open the Project.
   - Set:
     - `Scope – Estimated Hours` (e.g., 40)
   - Outline key phases as tasks with estimates:
     - Discovery & Strategy
     - Concepts
     - Revisions
     - Final files
     - Client communication (approx hours)
   - Make sure the sum of `Estimate` roughly matches 40 hours.

2. **During work**
   - For each focused work block, update `Actual Time` for the task (e.g., 90 minutes).
   - Watch the `Scope – Used %` in the Project:
     - At ~70%: start being more selective on extras.
     - At ~90%: redirect scope creep (“This is beyond the agreed scope; I can quote for an add-on”).

3. **End of project**
   - Compare:
     - Estimated vs Actual
   - Use that to refine estimates for future similar branding projects.

This gives you a light, integrated scope guardrail without requiring a separate tool.
