Step 2: Epsilon–delta limit definition  
Definition: We say \(\lim_{x\to a} f(x) = L\) if:

For every \(\varepsilon > 0\), there exists a \(\delta > 0\) such that, for all \(x\),
\[
0 < |x - a| < \delta \implies |f(x) - L| < \varepsilon.
\]

I’ll walk you through a concrete example, then you’ll do one.

Example: Show \(\lim_{x\to 2} (3x+1) = 7\).

We want: given \(\varepsilon > 0\), find \(\delta\) such that  
if \(|x - 2| < \delta\), then \(|(3x+1)-7| < \varepsilon\).

Compute:
\[
|(3x+1)-7| = |3x - 6| = 3|x - 2|.
\]
So it’s enough to force \(3|x-2| < \varepsilon\), i.e. \(|x-2| < \varepsilon/3\).  
So we can choose \(\delta = \varepsilon/3\).

Step 3: Limits of sequences  
Definition: A sequence \((a_n)\) converges to \(L\) if:

For every \(\varepsilon > 0\), there exists \(N\in\mathbb{N}\) such that

Step 6: Linear independence and span  
Let \(V\) be a vector space and \(v_1,\dots,v_k \in V\).

- They are linearly independent if the only solution to
  \[
  \alpha_1 v_1 + \dots + \alpha_k v_k = 0
  \]
  is \(\alpha_1 = \dots = \alpha_k = 0\).

- The span of \(\{v_1,\dots,v_k\}\) is all finite linear combinations:
  \[
  \mathrm{span}\{v_1,\dots,v_k\} = \{\alpha_1 v_1 + \dots + \alpha_k v_k : \alpha_i \in \mathbb{R}\}.
  \]

Concrete example in \(\mathbb{R}^2\):  
Vectors \(e_1 = (1,0)\) and \(e_2 = (0,1)\).

- They are linearly independent.  
- Their span is all of \(\mathbb{R}^2\).

Step 7: Completeness of \(\mathbb{R}\) and Cauchy sequences  
Definition: A sequence \((a_n)\) is Cauchy if for every \(\varepsilon>0\), there exists \(N\) such that for all \(m,n \ge N\),
\[
|a_n - a_m| < \varepsilon.
\]

Fact: In \(\mathbb{R}\), every Cauchy sequence converges. This is the completeness of \(\mathbb{R}\).

Example intuition: If the terms of a sequence get arbitrarily close to each other, in \(\mathbb{R}\) they must be converging to some real limit.

Step 8: Metric spaces  
Definition: A metric space is a set \(X\) with a function \(d: X \times X \to \mathbb{R}\) (a metric) such that for all \(x,y,z \in X\):

1) \(d(x,y) \ge 0\), and \(d(x,y)=0\) iff \(x=y\).  
2) \(d(x,y) = d(y,x)\).  
3) \(d(x,z) \le d(x,y) + d(y,z)\) (triangle inequality).

Example: \(\mathbb{R}\) with \(d(x,y) = |x-y|\).  
Example: \(\mathbb{R}^2\) with Euclidean distance \(d(x,y) = \sqrt{(x_1-y_1)^2+(x_2-y_2)^2}\).

Step 9: Eigenvalues and eigenvectors  
Given a linear transformation \(T: V \to V\) (or a square matrix \(A\)), a nonzero vector \(v\) is an eigenvector if
\[
T(v) = \lambda v
\]
for some scalar \(\lambda\), called an eigenvalue.

For a matrix \(A\), eigenvalues are roots of the characteristic polynomial \(\det(A - \lambda I) = 0\).

Concrete example:  
Let
\[
A = \begin{pmatrix}
2 & 0 \\
0 & 3
\end{pmatrix}.
\]
We solve \(\det(A - \lambda I) = 0\):
\[
\det\begin{pmatrix}
2-\lambda & 0 \\
0 & 3-\lambda
\end{pmatrix} = (2-\lambda)(3-\lambda) = 0.
\]
So eigenvalues are \(\lambda = 2\) and \(\lambda=3\).
