## Experiment Log Template (Use this for each serious experiment)

Create a Markdown file `experiments.md` in your repo and log each experiment as a row in a table:

```markdown
# Experiment Log – Home Credit Default Risk

| ID  | Date       | Model             | Key Preprocessing / Features                       | Hyperparameters (key ones)             | Validation AUC | Notes / Interpretation                        |
|-----|------------|-------------------|-----------------------------------------------------|----------------------------------------|----------------|-----------------------------------------------|
| E01 | 2025-01-10 | LogisticRegression| Basic impute (median), one-hot top 20 categories   | C=1.0, solver=liblinear               | 0.650          | Baseline model; underfitting, weak AUC       |
| E02 | 2025-01-11 | RandomForest      | Same as E01 + 3 engineered ratio features          | n_estimators=200, max_depth=10        | 0.710          | Stronger; trees capture nonlinearities       |
| E03 | 2025-01-12 | LightGBM          | E02 features + more careful cat handling           | lr=0.05, n_estimators=500, num_leaves=31 | 0.740       | Best so far; may benefit from more tuning    |
| E04 | 2025-01-13 | LightGBM          | E03 + additional age-related features              | lr=0.03, n_estimators=800, num_leaves=63 | 0.752       | Slight gain; check for overfitting           |
```

**Rules I’m imposing for you:**
- Assign a unique ID to each meaningful experiment (E01, E02, …).
- Change one “big thing” at a time when possible (model family, feature set, or major hyperparameters).
- Always note what you learned from the experiment, even if the result is worse.
