     - Rent/Mortgage
     - Minimum debt payments

4. **Rule: Income changes auto-adjust**
   - If income goes **up**:
     - 50% of the increase → Extra debt / emergency savings.
     - 30% → Lifestyle.
     - 20% → Long-term investing.
   - If income goes **down**:
     - Cut Lifestyle first.
     - Then reduce extra debt payments (but not minimums).
     - Essentials only touched last.

I’ll describe a spreadsheet-style setup you can mirror in any app:

Columns:
- Category | Group | Planned | Actual | Difference | Auto Action

Auto logic (conceptually):
- `Difference = Planned - Actual`
- If `Difference < 0` (overspending):

  - If not enough, pull from lifestyle categories in order: Misc → Shopping → Eating Out → Entertainment.
- If `Difference > 0` (leftover at month-end):
  - If any high-interest debt: move leftover to “Extra Debt.”
  - Else if Emergency fund < target: move to “Emergency Fund.”
  - Else: move to “Investing.”

This gives you:
- A complete monthly budget structure
- Clear, automatic rules for how money moves when you overspend or underspend
- Built-in prioritization for debt, savings, and essentials
