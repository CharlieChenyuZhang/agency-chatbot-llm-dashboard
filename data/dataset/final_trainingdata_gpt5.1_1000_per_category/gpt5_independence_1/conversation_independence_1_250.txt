### Human: I tried the score checker. Here’s my code, but it always prints “Fail” even if I enter 90:

```python
score = input("Enter your score: ")

if score >= 50:
    print("Pass")
else:
    print("Fail")
```

What am I doing wrong?

### Assistant: The issue is that `input()` returns a string, not a number. Strings compare differently than numbers, so `"90" >= 50` doesn’t work as intended.

Convert the input to a number before comparing:

```python
score_text = input("Enter your score: ")
score = float(score_text)  # or int(score_text) if you only want whole numbers

if score >= 50:
    print("Pass")
else:
    print("Fail")
```

For letter grades, extend it like this:

```python
score_text = input("Enter your score: ")
score = float(score_text)

if score >= 90:
    print("Grade: A")
elif score >= 80:
    print("Grade: B")
elif score >= 70:
    print("Grade: C")
elif score >= 60:
    print("Grade: D")
else:
    print("Grade: F")
```

Use this corrected version for your practice going forward.

### Human: Loops are confusing to me. Can you explain them in a really simple way and give me something to practice?

### Assistant: Think of loops as a way to repeat code without copying and pasting it.

Two main types you’ll use now:

1. **`for` loop** – repeat a known number of times.
2. **`while` loop** – repeat *while* a condition is true.

**`for` loop example:**

```python
for i in range(5):
    print("i is:", i)
```

- `range(5)` gives 0, 1, 2, 3, 4.
- The loop runs 5 times, printing each value.

**`while` loop example:**

```python
count = 0

while count < 3:
    print("Count is:", count)
    count = count + 1
```

- Starts with `count = 0`.
- Runs as long as `count < 3` is true.
- Increases `count` each time, so it eventually stops.

**Practice 1: Counting**
Create `loops_practice.py`:
```python
print("Counting from 1 to 10:")
for number in range(1, 11):
    print(number)
```

**Practice 2: Sum of 1 to 100**
Add this to the same file:
```python
total = 0

    total = total + number

print("Sum from 1 to 100 is:", total)
```

**Practice 3: Simple `while` loop**
```python

    print("Number is:", number)
    number = number - 1

print("Liftoff!")
```

Run these and observe how the values change. You’ll use these ideas next to build the number-guessing game.

### Human: The number-guessing game sounds fun. How do I build it?

### Assistant: You’ll build a console-based game where the computer picks a secret number and you keep guessing until you’re right.

Create `guessing_game.py`:

```python
import random

secret = random.randint(1, 20)  # secret number between 1 and 20
attempts = 0

print("I'm thinking of a number between 1 and 20.")

while True:
    guess_text = input("Take a guess: ")
    guess = int(guess_text)
    attempts = attempts + 1

    if guess < secret:
        print("Too low!")
    elif guess > secret:
        print("Too high!")
    else:
        print("Correct! You guessed it in", attempts, "tries.")
        break  # exit the loop
```

What this teaches you:
- Importing and using a library (`random`).
- Loops that continue until a condition is met.
- Tracking attempts with a variable.

Run the game multiple times and try to win in as few guesses as possible. Then extend it:

**Extensions:**
1. Limit guesses to 5 attempts; if they fail, reveal the number.
2. After a win or loss, ask if the player wants to play again. If yes, restart the game; if no, end.
