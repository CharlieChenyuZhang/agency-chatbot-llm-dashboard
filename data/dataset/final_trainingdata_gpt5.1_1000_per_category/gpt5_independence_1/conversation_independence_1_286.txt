## Progression Plan (12 Weeks)

**Weeks 1–3: Base Building**

- Start with a load that feels like ~RPE 7–8 (2–3 reps in reserve) on main lifts.  
- For each main lift (bench, squat, row, deadlift):  
  - If you hit the top of the rep range for all sets (e.g., 4×8 on a 6–8 range), increase weight next week by:  
    - Upper body: +2.5–5 lb (1–2.5 kg)  
    - Lower body: +5–10 lb (2.5–5 kg)  
- Accessories: aim to add 1 rep per set each week. When you can do the top of the range easily, bump weight slightly and drop reps back to the low end.

**Weeks 4–6: Intensification**

- Narrow rep range slightly and push load higher on compounds:
  - Main lifts: move to 4×5–6  
  - Keep accessories at same rep ranges but try to be closer to failure (RPE 8–9).
- Still add small amounts of weight each week if all sets land within the rep range with solid form.
- If you fail the lower end of the rep range on more than one set, keep the weight the same next week and try to get more reps.

**Week 7: Deload**

- Keep the same exercise selection and order.  
- Reduce volume and intensity:
  - Use ~60–70% of the weight you used in Week 6 on main lifts.  
  - Do 2–3 sets instead of 4 on compounds and 2 sets instead of 3 on accessories.  
  - Stay at RPE ~6 (4 reps in reserve).  
- Purpose: recover joints, nervous system, and allow adaptation to “catch up”.

**Weeks 8–10: Second Push (Strength + Hypertrophy)**

- Return to your Week 6 working weights as a starting point.
- Main lifts:
  - Bench, Squat, Row: 5×5  
  - Deadlift: 4×4–5  
- Progress:
  - Add weight again weekly if you hit all prescribed sets/reps with decent form.
- Accessories: keep 8–12 reps, but choose slightly heavier loads than Weeks 1–3.

**Weeks 11–12: Peak + Volume Taper**

- Week 11:
  - Main lifts: 3–4 sets of 3–5 reps, heavier than previous weeks but still submaximal (RPE 8–8.5).  
  - Accessories: drop 1 set each but keep effort high (RPE 8–9).
- Week 12:
  - Optional “test” week:
    - Choose 1–2 main lifts (e.g., squat and bench) and work up to a heavy set of 3 or a conservative 1RM attempt if you’re experienced with maxing.  
    - For remaining lifts, perform 2–3 light sets of 5–6 at ~70% of your recent best.
  - If you don’t want to test maxes, instead run Week 11’s structure again at slightly lighter loads.

## Progressive Overload Rules (Simple)

- First priority: add reps within the given range.  
- Second priority: once you hit the top of the range on all sets, add weight next week.  
- Keep at least 1–2 reps “in the tank” on most sets; don’t grind to failure on compounds.  
- If you stall for 2–3 weeks on a lift:
  - Reduce the load by ~5–10% and build back up using the same progression.

You can run this 12‑week block, take a lighter week, then repeat with slightly higher starting loads and/or small exercise swaps.

## How to Overload with Limited Weight

Since you’re capped at 25 kg dumbbells, you’ll rely heavily on rep progression, tempo, and unilateral work.

**1. Rep & Set Progression**

- Use ranges like 6–10, 8–12, 10–15.  
- Each week, try to add 1 rep per set until you hit the top of the range on all sets, then:
  - Option A: Increase difficulty (unilateral or different lever) and drop back to the low end of the rep range.  
  - Option B: Add a set (e.g., 3→4 sets) for a block of weeks.

**2. Tempo & Pauses**

When reps get very high (15–20) and still feel easy, increase difficulty by:

- Slower eccentrics: 3–4 seconds lowering.  
- Pauses:
  - At the bottom of squats, lunges, presses (1–2 seconds).  
  - At peak contraction for rows, curls, hip thrusts (1–2 seconds).  

**3. Unilateral Emphasis**

Favor single‑limb work so each limb gets more stimulus per load:

- Bulgarian split squats, reverse lunges, step‑ups, single‑leg RDLs, single‑arm rows, single‑arm presses.

## 12‑Week Progression (Same Skeleton)

- Weeks 1–3:  
  - Learn form, start conservative. Aim mid‑range (e.g., 8 reps of 6–10).  
  - Add 1 rep/set per week if possible.

- Weeks 4–6:  
  - On key patterns (goblet squat, DB RDL, DB bench, pull‑ups, hip thrust):  
    - If you hit the top of the rep range across all sets twice, add a set for the next week or slow tempo.  
  - Push closer to RPE 8–9 on the last set of major exercises.

- Week 7 (Deload):  
  - Cut sets in half; use same exercises but only mid‑range reps with easy effort (RPE ~6).

- Weeks 8–10:  
  - Increase difficulty: more unilateral, slower tempo, slightly higher volume.  
  - Example:  
    - Swap some goblet squats for Bulgarian split squats or front‑foot elevated split squats.  
    - Use 3–4s eccentric on DB bench and rows.

- Weeks 11–12:  
  - Keep exercise selection; reduce sets slightly (volume taper) but push intensity:
    - Last set of big lifts can be an AMRAP within safe form (stop at technical breakdown).  
  - Aim to set rep PRs at given loads (e.g., “hip thrust 25 kg DB for 20 solid reps”).

Warm‑ups, conditioning, and general guidance from the earlier plan still apply; just use bodyweight movements and lighter DB sets for warm‑ups.

## 1. Calorie Target

Use a simple rule of thumb:

- Daily calories ≈ **bodyweight (lb) × 12**  
  - Example: 170 lb → ~2,040 kcal/day

This generally creates a modest deficit (about 300–500 kcal/day for many). Stay at this level for the entire 12 weeks unless you feel consistently drained and performance crashes; in that case, increase by ~150–200 kcal/day.

---

## 2. Protein, Carbs, Fats

**Protein**

- Target: **0.7–1.0 g per lb of bodyweight** (1.6–2.2 g/kg).  
- Example (170 lb): 120–170 g/day.  
- Distribute over 3–5 meals with at least 20–30 g protein each time.

**Fats**

- Target: **0.3–0.4 g per lb** (0.7–0.9 g/kg).  
- Example (170 lb): 50–70 g/day.

**Carbs**

- Fill the remaining calories with carbs.  
- Roughly:  
  - Carbs (g) ≈ [Total calories − (Protein g × 4 + Fat g × 9)] / 4.

## 4. Timing Around Workouts

- 1–3 hours pre‑workout:
  - 20–40 g protein, 30–60 g carbs, low fat.  
- Within 1–2 hours post‑workout:
  - 20–40 g protein, moderate carbs.  
- This supports performance and recovery but total daily intake matters most.

---

## 5. Adjustments Over 12 Weeks

- Weigh yourself under similar conditions 2–3×/week and track the weekly average.  
- Target fat loss rate:
  - ~0.25–0.75% of bodyweight per week.  
- If weight isn’t trending down after 2–3 weeks:
  - Reduce by ~150–200 kcal/day (usually from carbs/fats).  
- If strength is nosediving and you feel exhausted:
  - Add ~150–200 kcal/day, ideally around training.

---

## 6. Simple Behavioral Rules

- Prioritize whole foods: lean proteins, fruits, vegetables, whole grains, minimally processed fats.  
- Minimum:
  - 2 servings fruit + 2 servings vegetables daily.  
- Hydration:
  - ~2–3 L water/day, more if you sweat heavily.  
- Alcohol: minimize; it directly interferes with fat loss and recovery.

Keep this framework consistent throughout the 12 weeks while running the training block, and you’ll support gradual fat loss and strength gains simultaneously.

## Technique & Programming Tweaks for Knees

- Range of Motion:
  - Only squat/lunge as deep as pain‑free. Partial ROM is fine while still loading muscles.  
- Tempo:
  - Use slow, controlled eccentrics (2–3 seconds down) and avoid “bouncing” out of the bottom.  
- Stance:
  - Slightly wider stance, toes turned slightly out, and sit back more can decrease knee stress.  
- Reps:
  - Favor 8–15 reps on leg work, not very heavy 3–5 rep sets.  
- Progression:
  - Progress by reps and tempo before increasing load.  
  - If an increase in weight bothers your knee, reduce weight and instead increase reps or slow the tempo.

The 12‑week progression (build weeks, deload at Week 7, then push again) stays the same. Just apply overload within the pain‑free ranges and movements above.
