### Human: Sometimes I get errors in the terminal and I don’t really understand them. What should I do when that happens?

### Assistant: Treat every error as a clue, not a dead end. You’ll follow a simple 4-step process whenever you see one:

1) Read the last line of the error message:
- It usually says something like `SyntaxError`, `NameError`, `TypeError`, etc.
- That last line tells you what kind of problem you hit.

2) Look at the line number:
- The error message mentions a line, e.g. `File "conditions.py", line 5`
- Open that file and go straight to that line.

3) Apply a quick checklist:

- For `SyntaxError`:
  - Check missing `:` at the end of `if`, `elif`, `else`, `for`, `while`, `def`.
  - Check indentation (spaces) are consistent.
  - Check quotes and parentheses are closed.

- For `NameError`:
  - Variable name spelled exactly the same as when you created it?
  - Did you define it before using it?

- For `TypeError`:
  - Are you combining incompatible types, like string + number without converting?

4) Fix one thing, then run again:
- Don’t change many things at once.
- Make a small edit, run, see what changed.

As you continue, you’ll deliberately trigger a few common errors and fix them so you get comfortable reading error messages.

For now, next time you see an error, copy the last line and look for:
- The error type
- The line number
Then use the checklist above on that line.

### Human: Can you give me a small exercise to practice if statements and variables together?

### Assistant: Build a tiny “shop” script where the player tries to buy an item. This uses variables, `if`, and comparisons.

Create `shop.py` with this logic:
- The player has some amount of gold.
- A sword costs a fixed price.
- The script tells the player whether they can afford it and what happens.

Template:

```python
player_name = "Alex"
gold = 7
sword_price = 10

print("Welcome to the shop,", player_name)
print("You have", gold, "gold.")
print("The sword costs", sword_price, "gold.")

if gold >= sword_price:
    print("You buy the sword!")
    gold = gold - sword_price
    print("Gold left:", gold)
else:
    print("You do not have enough gold.")
    print("Come back later.")
```

Then extend it:
- Add a `potion_price` variable.
- If the player can’t afford the sword, but has at least enough for a potion, let them buy the potion instead.
- Update `gold` correctly after buying the potion.

This mirrors real game shop logic and solidifies conditions and arithmetic.

### Human: That was fun. When do I actually start making a real game?

### Assistant: You’ll move into a simple, real text-based game after one more building block: loops. Loops let you keep the game running until the player wins, loses, or quits.

You’re ready for a small game project over the next few sessions:
1) Learn `while` loops and `break`.
2) Build a guess-the-number game.
3) Reskin it with a “monster guessing” or “door guessing” theme.

Here’s the next step right now: a basic loop example in `loop_example.py`:

```python
health = 10

while health > 0:
    print("Your health is", health)
    health = health - 1

print("You have fallen!")
```

Run it and observe:
- The `while` loop repeats as long as `health > 0`.
- It stops when the condition is no longer true.

Once you’ve seen that, you’ll adapt this pattern into a loop that keeps asking the player for guesses until they get the right number or lose.
