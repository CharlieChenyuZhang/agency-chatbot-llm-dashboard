### Assistant: Here’s a minimal Python script that uses GitLab’s REST API to set reviewers on a merge request. You’ll need: - Your **GitLab URL** (e.g. `https://gitlab.example.com`). - A **Personal Access Token** with `api` scope. - The **project ID**. - The **MR IID** (the number you see in the MR URL, like `!42` → IID = 42). - The **user IDs** of the reviewers. > Note: In recent GitLab versions, the API field for reviewers is typically `reviewer_ids`. Please confirm against your instance’s API docs (`/help/api`) and adjust if needed. ```python #!/usr/bin/env python3 import os import sys import requests GITLAB_URL = os.environ.get("GITLAB_URL", "https://gitlab.example.com") GITLAB_TOKEN = os.environ.get("GITLAB_TOKEN") # set this in your env # Set your default reviewer user IDs here DEFAULT_REVIEWER_IDS = [123, 456] # replace with real user IDs if not GITLAB_TOKEN: print("Error: GITLAB_TOKEN environment variable not set.") sys.exit(1) def set_reviewers(project_id, mr_iid, reviewer_ids): url = f"{GITLAB_URL}/api/v4/projects/{project_id}/merge_requests/{mr_iid}" headers = { "PRIVATE-TOKEN": GITLAB_TOKEN, "Content-Type": "application/json", } payload = { "reviewer_ids": reviewer_ids } resp = requests.put(url, headers=headers, json=payload) if resp.status_code == 200: data = resp.json() names = [r.get("name") for r in data.get("reviewers", [])] print(f"Successfully set reviewers on MR !{mr_iid}: {names}") else: print(f"Failed to set reviewers (status {resp.status_code}): {resp.text}") sys.exit(1) def main(): if len(sys.argv) != 3: print(f"Usage: {sys.argv[0]} <project_id> <mr_iid>") sys.exit(1) project_id = sys.argv[1] mr_iid = sys.argv[2] set_reviewers(project_id, mr_iid, DEFAULT_REVIEWER_IDS) if __name__ == "__main__": main() ``` **How to use it** 1.
