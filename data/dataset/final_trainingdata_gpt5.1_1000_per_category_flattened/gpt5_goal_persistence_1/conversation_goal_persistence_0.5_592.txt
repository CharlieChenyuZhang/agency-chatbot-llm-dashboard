### Assistant: Good topic to tackle. Conceptually: - Adjacency list: For each node, store a list of its neighbors. - Space: O(V + E) - Best for sparse graphs (when E is not close to V²) - Adjacency matrix: A V x V boolean/int matrix where matrix[u][v] indicates an edge. - Space: O(V²) - Best for dense graphs or when you need O(1) edge existence checks. For typical interview problems (V up to, say, 10^5, E up to 10^5 or 10^6), adjacency lists are the default. Adjacency list in Java (0-based nodes from 0..n-1): int n = ...; // number of nodes List<List<Integer>> graph = new ArrayList<>(); for (int i = 0; i < n; i++) { graph.add(new ArrayList<>()); } // For an undirected edge u - v: graph.get(u).add(v); graph.get(v).add(u); // For a directed edge u -> v: graph.get(u).add(v); Once you have this, DFS/BFS become straightforward: - DFS: recursive or with a stack - BFS: with a queue If you’d like, write a tiny example in your own words/code: construct a graph with 4 nodes and edges: 0-1, 0-2, 1-3.
