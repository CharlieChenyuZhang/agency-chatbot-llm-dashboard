Linking tasks to notes (from the task side) When you’re viewing a **Task**: 1. Use the **Notes** relation property. 2. Everyday flow you should follow **During meetings / thinking time:** - Open a new Note (Type = Meeting/Idea). - Write freely. - At the end, scan for action items: - For each action, create a linked Task via the `Tasks` relation right inside the note. - Set each new Task’s `Status = Inbox` or `Next`, and set `Project` if relevant. **During planning / Weekly Review:** - Open active Projects. - Open their Notes (via the Project page). - Create or refine Tasks from those Notes as needed. **During the day:** - Live mostly in the **Today** page. - When a task looks confusing, open it, jump to its linked Note or Project for context, then come back to Today.
