Machine learning (ML) is a subset of AI concerned with algorithms that learn patterns from data and make predictions or decisions without being explicitly programmed for each task. Formally, an ML algorithm seeks a function that maps inputs (features) to outputs (labels or targets) by optimizing a performance objective on observed data. Supervised learning handles labeled data. For regression (predicting continuous values), common algorithms include linear regression, ridge and lasso regression, and tree‑based methods like random forests and gradient boosting. For classification (discrete labels), algorithms include logistic regression, support vector machines (SVMs), k‑nearest neighbors (k‑NN), decision trees, random forests, gradient boosting machines (XGBoost, LightGBM, CatBoost), and neural networks. Unsupervised learning discovers structure in unlabeled data. Key methods include k‑means and Gaussian mixture models for clustering, principal component analysis (PCA) and t‑SNE/UMAP for dimensionality reduction, and hierarchical clustering for building cluster trees. These methods are used for customer segmentation, anomaly detection, and data exploration. Reinforcement learning (RL) trains an agent to act in an environment to maximize cumulative reward. Core algorithms include Q‑learning, SARSA, and policy gradient methods (REINFORCE, actor‑critic, Proximal Policy Optimization). RL underlies advances in game playing and robotics. Deep learning uses neural networks with many layers to learn hierarchical representations. Convolutional neural networks (CNNs) dominate vision; recurrent networks and transformers dominate sequence modeling and natural language processing. Training typically uses stochastic gradient descent variants (SGD, Adam) and regularization techniques such as dropout, weight decay, and data augmentation. Practical ML involves data preprocessing, feature engineering or representation learning, model selection, hyperparameter tuning (e.g., grid/random/Bayesian search), cross‑validation, and rigorous evaluation using metrics like accuracy, F1, ROC‑AUC, RMSE, and calibration measures. Robust deployments also require monitoring for drift, fairness, and reliability in production.
