### Human: Set up a note-taking system with capture rules
### Assistant: You’ll use a simple, robust system based on three components: 1) One main app 2) A small set of notebooks/folders 3) Explicit capture rules for every kind of input I’ll design it so it works in any general markdown or notes app (Evernote, Notion, Obsidian, Apple Notes, OneNote, etc.). You can map the structure to your preferred tool. --- #### 1. Structure of your system Create these top-level areas: - **/Inbox** – temporary dumping ground for all new notes - **/Areas** – ongoing responsibilities (Work, Personal, Health, Finance, Learning, etc.) - **/Projects** – short- to medium-term outcomes with a clear finish line - **/Archive** – finished or inactive stuff Inside: - **/Areas** - Work - Personal - Health - Finances - Learning - **/Projects** - P-ProjectName (e.g., P-Website Redesign) - P-Trip to Japan - **/Inbox** - Just a flat list of notes - **/Archive** - Old projects, old notes you don’t need often This mirrors the PARA method (Projects, Areas, Resources, Archive), but simplified. --- #### 2. Universal naming rules Use consistent titles: - **Meetings**: `M – [Person/Team] – [Topic] – [YYYY-MM-DD]` - **Ideas**: `Idea – [Short Description]` - **Reading notes**: `Book – [Title] – [Author]` - **Articles/papers**: `Article – [Source] – [Title]` - **Projects**: `P – [Outcome]` - **Reference**: `Ref – [Topic]` This keeps everything searchable and scannable. --- #### 3. Capture rules (what goes where, when) You’ll use **one rule per situation**, so you never hesitate. **Rule 1 – Random thoughts / ideas** - Where: **/Inbox** - Format: - Title: `Idea – [3–6 word summary]` - Body: - 1–2 sentence description - Bullet list if needed - Example: - Title: `Idea – Morning deep work routine` - Body: - Description: 90-minute focused block before email. - Bullets: - 07:30–09:00, 5 days/week - No phone, no email - Only 1 key task **Rule 2 – Tasks / to-dos** - Where: If your notes app has tasks, use that; otherwise still **/Inbox**. - Format inside any note: - `- [ ] verb-first task description (with clear outcome)` - Example: - `- [ ] Draft slide outline for Q1 review` - `- [ ] Email Alex project summary` If your task is based on a note (e.g., meeting), add a task at the top of that note: `- [ ] Pull 3 action items from this meeting` **Rule 3 – Meeting notes** - Where: Start in **/Inbox**, move later to **/Projects** or **/Areas** - Template: - Title: `M – [Person/Team] – [Topic] – [YYYY-MM-DD]` - Sections: - `Context:` 2–3 sentences (why this meeting exists) - `Notes:` bullets, not paragraphs - `Decisions:` bullets prefixed with “Decision: …” - `Actions:` checkboxes `- [ ] Owner – action – when` - Example action: - `- [ ] You – Send recap email – Today` **Rule 4 – Project-related notes** - Where: Directly in **/Projects/P-ProjectName** - Types: - Project brief: `P – [Outcome] – Brief` - Meeting notes (moved from inbox) - Brainstorms: `P – [Outcome] – Brainstorm – [Topic]` - Every project’s brief includes: - `Goal:` - `Deadline:` - `Why it matters:` - `Next 3 actions:` **Rule 5 – Reading (books, courses, articles)** - Where: **/Areas/Learning** or **/Projects** if tied to a specific project - Books: - Title: `Book – [Title] – [Author]` - Sections: - `Summary (3–5 sentences)` - `Key ideas (bullets)` - `Quotes (with page/loc)` - `Applications (concrete actions for you)` - Articles: - Title: `Article – [Site] – [Title]` - Same sections, but shorter. **Rule 6 – Reference info (how-tos, logins, recurring info)** - Where: In the appropriate **Area**: - Work reference → `/Areas/Work` - Personal admin → `/Areas/Personal` - Finance details → `/Areas/Finances` - Format: - Stable title like: `Ref – [Tool/Process/Topic]` - Use headings and bullet points; avoid long prose. **Rule 7 – Journaling / reflection** - Where: `/Areas/Personal` - Title: `Journal – [YYYY-MM-DD]` - Simple prompt: - `What happened?` - `What mattered?` - `What will I do tomorrow?` --- #### 4. Daily routine (so it doesn’t become chaos) You’ll run three quick routines: **Morning (5 minutes)** - Open main notes app. - Check active projects (`/Projects`) and pick **1–3 priorities** for the day. - Create or update **one** project note if needed (e.g., add “Next 3 actions”). **During the day (capture mode)** - Any thought, task, or note → straight into **/Inbox**, following the capture rules above. - Don’t organize during the day, only capture. **Evening (10–15 minutes)** - Open **/Inbox**. For each note: - If it belongs to a project → move to `/Projects/P-ProjectName` - If it belongs to an area → move to `/Areas/[AreaName]` - If it was a one-off and done → mark as done or move to `/Archive` - Ensure every project you’re actually working on has: - A clear goal - At least 1–3 next actions written --- #### 5. Minimal tagging system Use only a few tags (if your app supports tags): - `#task` – notes that mostly are action lists - `#waiting` – tasks waiting on someone else - `#idea` – raw ideas - `#reading` – books/articles notes - `#template` – templates you’ll reuse Don’t add new tags for at least a month. Keep it minimal. --- #### 6. Core capture rules summary (one glance) - New idea? → `/Inbox` → `Idea – ...` - New task? → `/Inbox` or inside relevant project note as `- [ ] ...` - Meeting? → `/Inbox` using meeting template → later file under project/area - Project-related info? → straight into `/Projects/P-ProjectName` - Reference/how-to? → `/Areas/[Area]` with `Ref – [Topic]` - Reading? → `/Areas/Learning` with the reading template - Reflecting? → `/Areas/Personal` as `Journal – YYYY-MM-DD` This gives you a complete, opinionated system you can start using immediately.
### Human: I mostly use Apple devices and email a lot. How would this work there?
### Assistant: You’ll anchor this system in Apple’s built-in tools and your email: --- #### 1. Main tools on Apple - **Apple Notes** as your primary note-taking app - **Mail** for email capture - **Shortcuts** for fast capture from iPhone/iPad - **Reminders** only for hard-deadline tasks (calendar/reminder style) --- #### 2. Set up Apple Notes structure In Apple Notes, create these folders: - `Inbox` - `Areas` - `Projects` - `Archive` Inside **Areas**: - `Work` - `Personal` - `Health` - `Finances` - `Learning` Inside **Projects**: - Create as needed: `P – [Outcome]` All capture rules from before map directly to these folders. --- #### 3. Email → Notes capture You’ll handle email in three ways: 1. **Actionable email (needs work)** - In Mail, use “Share” → “Notes” - Choose folder: **Inbox** - At the top of the created note, add: - `- [ ] Reply to [Name] about [Topic]` - This creates a task that lives in your notes system, not in your inbox. 2. **Reference email (info you may need later)** - Share to Notes - File directly to: - `/Areas/Work` if work-related - `/Areas/Finances` for statements/invoices - etc. - Title format: `Ref – [Sender/Topic]` 3. **Quick task from email subject** - If you don’t need the full body, just: - Create a new note in `/Inbox` - Title: `Task – [From Subject/Topic]` - Body: `- [ ] [Concrete action]` Then you archive the email in Mail. The work lives in Notes. --- #### 4. Fast capture on iPhone/iPad (Shortcuts) Create three simple Shortcuts: 1) **“Quick Idea to Inbox”** - Action 1: Ask for text (“Idea?”) - Action 2: Create note in Apple Notes: - Folder: `Inbox` - Title: `Idea – [Current Date & Time]` - Body: the text you entered - Add to: Home Screen, Today View, and Siri (“Hey Siri, quick idea”). 2) **“Quick Task to Inbox”** - Ask for text (“Task?”) - Create note in `Inbox` - Title: `Task – [Short label from first words]` - Body: `- [ ] [Your text]` 3) **“Meeting Note”** - When launched, create a new note in `Inbox` with: - Title: `M – [Placeholder] – [YYYY-MM-DD]` - Body containing the meeting template structure: - `Context:` - `Notes:` - `Decisions:` - `Actions:` - You fill details during/after the meeting. This gives you one-tap capture on your phone and iPad. --- #### 5. Hard deadlines with Reminders Use **Reminders** for: - Due dates with real consequences (bills, appointments, submissions) - Calendar-like items Workflow: - Task lives as a checkbox in your relevant note. - If it must be done by a date: - Add a matching reminder in the Reminders app with: - Same title - Due date/time - Optional link back to the note (copy note link from Apple Notes if available in your OS version). You avoid duplicating full task lists in Reminders; only hard-deadline items go there. --- #### 6. Your Apple routine **Morning (Mac or iPad)** - Open Apple Notes → `Projects` folder - Scan active projects - For today’s 1–3 priorities, add `- [ ]` items at the top of each relevant project note. **During the day (iPhone, iPad, Mac)** - New idea or task → use the Shortcuts (“Quick Idea to Inbox” / “Quick Task to Inbox”) or create directly in `Inbox`. - Email that requires work → Share to Notes (`Inbox`), then archive the email. **Evening (Mac or iPad)** - Open `Inbox` folder - For each note: - Decide: Project, Area, or Archive - Move the note accordingly - Make sure each active project has: - Clear next actions - Any crucial deadlines reflected in Reminders This fits neatly into the Apple ecosystem without you juggling multiple complex tools.
### Human: I don’t like folders much. I prefer search. Can we simplify the structure?
### Assistant: You’ll keep the capture rules but flatten the structure and lean on naming plus a few tags instead of deep folders. --- #### 1. Simplified Apple Notes structure Use just two main folders: - `Inbox` - `Cabinet` Everything that’s not in `Inbox` lives in `Cabinet`. Inside `Cabinet`, you won’t create many subfolders. At most, add: - (Optional) `Archive` for very old stuff you rarely need. --- #### 2. Naming becomes the main organizer You’ll rely on titles like: - `P – [Project outcome]` - `M – [Person/Team] – [Topic] – [YYYY-MM-DD]` - `Book – [Title] – [Author]` - `Ref – [Topic]` - `Idea – [Short description]` - `Journal – [YYYY-MM-DD]` Apple Notes search will easily surface anything with these consistent prefixes. --- #### 3. Minimal tags instead of folders Use only 5 tags: - `#project` – for project notes - `#area` – for ongoing responsibility (Work, Health, etc.) notes - `#idea` – raw ideas - `#reading` – books/articles notes - `#reference` – stable info like how-tos You apply one or two tags per note at most. No custom tags for now. Examples: - A project brief: Title: `P – Launch new website` Tags: `#project` - A work reference note: Title: `Ref – Quarterly reporting process` Tags: `#reference #area` - A book note: Title: `Book – Deep Work – Cal Newport` Tags: `#reading` --- #### 4. Capture + processing with this flat system **Capture:** - All new notes → `Inbox` - Use your existing capture rules for content and titles. **Processing (once a day or every other day):** For each note in `Inbox`: - Add 1–2 tags (from the small set). - Move it to `Cabinet`. - If completed/done but worth keeping, tag it and optionally move to `Archive` (inside Cabinet). You never worry about nesting or which exact folder to use. Search + prefixes + tags handle retrieval. --- #### 5. How you find things later - Projects: search `P –` or `#project` - Meetings: search `M – [Person/Team]` + date or topic - Ideas: search `Idea –` or `#idea` - Reference: search `Ref – [keyword]` or `#reference` - Reading notes: search `Book –` or `#reading` This keeps the mental overhead low while preserving the clarity of the capture rules.
### Human: Can you write the exact templates I should use for meetings, projects, and reading notes?
### Assistant: You’ll use three reusable templates you can paste into Apple Notes and duplicate as needed. --- #### 1. Meeting notes template **Title format:** `M – [Person/Team] – [Topic] – [YYYY-MM-DD]` **Body template:** ``` # M – [Person/Team] – [Topic] – [YYYY-MM-DD] Context: - Why this meeting exists: - What you want out of it: Attendees: - [Name] - [Name] Notes: - [Key point 1] - [Key point 2] - [Key point 3] Decisions: - Decision: [What was decided] - Decision: [What was decided] Actions: - [ ] [Owner] – [Action] – [When] - [ ] [Owner] – [Action] – [When] Follow-up: - Next check-in date: - How you’ll know this was successful: ``` --- #### 2. Project brief / main project note template **Title format:** `P – [Clear outcome]` **Body template:** ``` # P – [Clear outcome] Status: [Not started / In progress / On hold / Done] Owner: [You] Start date: [YYYY-MM-DD] Target completion: [YYYY-MM-DD] Goal: - [1–2 sentences describing the outcome] Why it matters: - [Reason 1] - [Reason 2] Scope: - Includes: - [Item] - [Item] - Excludes: - [Item] - [Item] Constraints: - Time: - Budget: - People: - Tools: Success criteria: - [Measurable or observable success condition] - [Another one] Next 3 actions: - [ ] [Action 1] - [ ] [Action 2] - [ ] [Action 3] Key resources: - [Link or note name] - [Link or note name] Notes / log: - [YYYY-MM-DD] – [Update] - [YYYY-MM-DD] – [Update] ``` --- #### 3. Reading notes (books, articles, courses) **Book template** **Title format:** `Book – [Title] – [Author]` **Body template:** ``` # Book – [Title] – [Author] Status: [To read / Reading / Finished] Started: [YYYY-MM-DD] Finished: [YYYY-MM-DD] One-sentence summary: - [Your own summary] Key ideas (3–10 bullets): - [Idea 1] - [Idea 2] - [Idea 3] Favorite quotes: - "[Quote]" – p.[page] / loc.[location] - "[Quote]" – p.[page] Connections: - This relates to: - [Other book / idea / project] - [Your experience] Applications (how you will use this): - [Action you will take] - [Habit you will change/start] - [Decision you will revisit] Notes: - [Any additional thoughts or excerpts] ``` **Article / paper template** **Title format:** `Article – [Site/Source] – [Title]` **Body template:** ``` # Article – [Site/Source] – [Title] Link: - [URL] One-paragraph summary: - [Your own words] Key points: - [Point 1] - [Point 2] - [Point 3] What’s new or surprising: - [Insight 1] - [Insight 2] Application: - [Concrete change to your work or thinking] Quotes / excerpts: - "[Quote]" - "[Quote]" ``` You can create one “Templates” note in Apple Notes, store these three there, and duplicate the relevant section whenever needed.
### Human: How should I handle notes for learning from books over time, not just one-off summaries?
### Assistant: You’ll turn each book into an ongoing learning “hub” and connect it to your real projects and habits. --- #### 1. Treat each book note as a living document Use the **Book template** as the base and evolve it: - Start with: - Status: `Reading` - A few key ideas as you go, not at the end. - While reading: - Add short bullets or quotes, not long summaries. - Use “Connections” and “Applications” sections heavily. The book note remains in your `Cabinet` tagged with `#reading`. --- #### 2. Capture while reading (fast and light) When you read (physical, Kindle, PDF): - For each important point: - Add a bullet under **Key ideas** or **Notes**: - `- [Chapter/Section] – [Short idea]` - For actionable items: - Add to **Applications** immediately: - `- Try [behavior] during [specific situation] this week` You avoid big backlog reviews later by making decisions while the idea is fresh. --- #### 3. Link books to projects and habits Whenever a book idea affects something concrete: 1. **Project link** - If it supports an existing project: - Open the project note `P – [Outcome]` - Add a bullet in the “Key resources” or “Notes / log”: - `- See: Book – [Title] – [Author] → [specific idea]` - If it inspires a new project: - Create a new project note using the project template. - Add a line in the book’s **Applications**: - `- Start project: P – [Outcome] (created [date])` 2. **Habit / behavior change** - In the book’s **Applications**: - `- New habit: [Behavior] when [Trigger]` - If you track habits separately (e.g., in a habit app), add it there too. - In Apple Notes, you can create a single “Habits – [Year]” note and list: - `- [YYYY-MM-DD] – Started: [Habit] (from Book – [Title])` --- #### 4. Periodic review routine for learning Once a week (pick a fixed day), run a **Learning review** in Apple Notes: 1. Search `#reading`. 2. Open any book where: - Status is `Reading` or recently `Finished`. 3. In each: - Add 1–3 more **Key ideas** based on your highlights/notes. - Update **Applications**: - Mark implemented items as done: - `- [x] Implemented: [Action] (on [date])` - Add 1–2 new actions if still relevant. 4. If a book no longer feels useful: - Status → `Finished` - Add a 2–3 sentence “Retrospective” at the bottom: - `Retrospective:` `- What was most useful:` `- What I’d ignore if I reread:` You turn passive reading into an active loop of trying and adjusting. --- #### 5. Quick capture from Kindle or PDF into Apple Notes When you highlight something: - **Option A – Manual batch** - After a reading session, open your highlight list. - Copy only the top 3–5 highlights into the **Quotes** section. - Immediately add 1 bullet in **Applications** per highlight cluster. - **Option B – On the fly (if reading on iPad)** - Use the Share menu from your reading app, send quote to Apple Notes. - Append to the existing `Book – [Title] – [Author]` note. - Under it, write: - `→ So what? [Your own interpretation]` - `→ Application: [Concrete action or reflection]` This ensures every captured quote is paired with your interpretation or intended use. --- #### 6. How you retrieve learning later When working on something: - Search relevant keywords + `Book –` or `#reading`. - Skim: - **Applications** first (what you planned to do). - Then **Key ideas** for context. Over time, your notes become a personal “second brain” of books, directly tied to your projects and habits rather than isolated summaries.
