### Human: I’m actually on Ubuntu. Just set it up properly for that.
### Assistant: I’ll set up a weekly encrypted backup from Ubuntu to Backblaze B2 using `restic` and `cron`. Plan: - Tool: `restic` (CLI, encrypted, efficient) - Storage: Backblaze B2 - Schedule: Weekly, Sunday at 02:00 - Data: Your home directory (`/home/youruser`) - Retention: Keep 12 weekly snapshots (about 3 months) 1. Install restic and required tools ```bash sudo apt update sudo apt install restic ``` 2. Create Backblaze B2 credentials - In Backblaze B2: - Create a bucket, e.g., `ubuntu-backups`. - Create an Application Key with access to that bucket. - Note: - `B2_ACCOUNT_ID` - `B2_ACCOUNT_KEY` - `B2_BUCKET` 3. Configure environment variables Create a file `/etc/restic-backup.conf` (as root): ```bash sudo nano /etc/restic-backup.conf ``` Put in (adjust values): ```bash export RESTIC_REPOSITORY="b2:ubuntu-backups:/" export RESTIC_PASSWORD="a-strong-passphrase-here" export B2_ACCOUNT_ID="your-account-id" export B2_ACCOUNT_KEY="your-app-key" export BACKUP_SOURCE="/home/youruser" export RESTIC_RETENTION_PRUNE_FLAGS="--keep-weekly 12" ``` Save and restrict permissions: ```bash sudo chmod 600 /etc/restic-backup.conf ``` 4. Initialize the backup repository ```bash source /etc/restic-backup.conf restic init ``` 5. Create the backup script ```bash sudo nano /usr/local/bin/weekly-restic-backup.sh ``` Contents: ```bash #!/usr/bin/env bash set -e source /etc/restic-backup.conf # Run backup restic backup "$BACKUP_SOURCE" # Prune old snapshots according to policy restic forget $RESTIC_RETENTION_PRUNE_FLAGS --prune # Optional: check repository occasionally # restic check ``` Make it executable: ```bash sudo chmod 700 /usr/local/bin/weekly-restic-backup.sh ``` 6. Schedule it with cron Edit root’s crontab: ```bash sudo crontab -e ``` Add: ```bash 0 2 * * 0 /usr/local/bin/weekly-restic-backup.sh >> /var/log/weekly-restic-backup.log 2>&1 ``` This runs every Sunday at 02:00. 7. Test it once Run manually: ```bash sudo /usr/local/bin/weekly-restic-backup.sh ``` Then list snapshots: ```bash source /etc/restic-backup.conf restic snapshots ``` At this point, your Ubuntu system will perform encrypted weekly backups of your home directory to Backblaze B2 and keep the last 12 weekly versions.
