### Human: Before that, can you just explain indentation a bit more? It confuses me.
### Assistant: I’ll simplify indentation for you and give you a rule you can follow. In Python, indentation (spaces at the start of the line) tells the interpreter which lines belong together inside a block, such as: - after `if`, `elif`, `else` - after `for`, `while` - after `def` (functions) Example: ```python age = 20 if age >= 18: print("Adult") # inside the if-block print("Can vote") # also inside the if-block print("Done") # outside the if-block ``` The two `print` lines under `if` are indented the same amount, so they’re part of the block. The last `print` is not indented, so it runs regardless of the `if`. Practical rule for you: - Always use 4 spaces for one level of indentation. - Everything that should “happen inside” an `if`, `else`, `for`, or `while` must be indented one level more than the line above that ends with `:`. You don’t need to overthink it: when you write a line ending with `:`, press Enter and then indent the next line by 4 spaces (or let your editor do it automatically). ### Human: I don't really get the while loop. Why do we set guess = None first?
### Assistant: I’ll break this down and then give you a slightly cleaner pattern you can reuse. `while` loop idea: - `while CONDITION:` means “as long as CONDITION is true, keep repeating this block of code.” In the example: ```python guess = None while guess != secret: ... ``` We need `guess` to exist before we check `guess != secret`. Setting `guess = None` gives it an initial value that is definitely not equal to the secret number, so the loop starts. A more intuitive pattern you can use is an infinite loop with `break`: ```python import random secret = random.randint(1, 100) while True: guess = int(input("Guess the number (1-100): ")) if guess < secret: print("Too low!") elif guess > secret: print("Too high!") else: print("Correct!") break # exit the loop ``` Here’s the logic in plain language: - `while True:` → loop forever - If the guess is wrong, give a hint and continue - If the guess is correct, say “Correct!” and `break` to exit the loop Use this version. Run it. Then I’ll extend it for you by: - Counting how many guesses the user took - Ending the game if they exceed a maximum number of attempts
