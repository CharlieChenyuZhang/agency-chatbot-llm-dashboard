### Human: Can you give me a concrete filename format I can plug into a script or renaming tool for my normal photos?
### Assistant: Use a consistent pattern based on **EXIF date and time**, with optional location/subject: **Base format (safe for all OSes):** `YYYY-MM-DD_HHMMSS_Category_Location_Subject_###.ext` Where: - `YYYY-MM-DD` = date taken (from EXIF). - `HHMMSS` = 24-hour time (e.g., 093421). - `Category` = short tag like `Travel`, `Family`, `Event`, `Everyday`. - `Location` = optional city or place (`Paris`, `Home`, `Office`). - `Subject` = optional 1–2 word description (`Birthday`, `Beach`, `Hike`). - `###` = sequence number for that second, padded to 3 digits (`001`, `002`). **Examples:** - `2023-08-14_103245_Travel_Paris_EiffelTower_001.jpg` - `2020-12-25_083012_Family_Home_ChristmasMorning_001.CR2` - `2019-07-05_194501_Event_Berlin_Wedding_002.JPG` If you don’t want to manually add Category/Location/Subject for everything, default to: `YYYY-MM-DD_HHMMSS__###.ext` Examples: - `2021-05-03_184512__001.jpg` - `2018-11-20_091033__002.RAW` Most renaming tools (e.g., Advanced Renamer, A Better Finder Rename, ExifTool) can be configured as: - Date: `YYYY-MM-DD` - Time: `HHMMSS` - Counter: `001` - Pattern: ` ` = EXIF date ` ` = EXIF time ` ` = counter And template: `<ExifDate>_<ExifTime>__<IncNr:3>` You can later add Category/Location only for specific folders when you curate them.
