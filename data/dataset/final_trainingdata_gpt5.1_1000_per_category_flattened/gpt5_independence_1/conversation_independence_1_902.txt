### Assistant: You’ll treat a system of linear equations as one matrix equation A·x = b. That viewpoint makes solving and analyzing the system much more systematic. --- **System of equations → matrix form** Example system: 1) 2x + 3y = 5 2) −x + 4y = 1 You separate: - Coefficients → matrix A - Variables → vector x - Right-hand sides → vector b A = [ [ 2, 3], [−1, 4] ] x = (x, y) b = (5, 1) Then the system is just: - A·x = b Checking: A·x = (2x + 3y, −x + 4y) = (5, 1) matches the two equations. **Why this helps:** 1. You can study **all** solutions at once via properties of A: - If A is invertible, then x = A⁻¹b gives a unique solution. - If A is not invertible, you might have no solutions or infinitely many. 2. You can use systematic algorithms (like Gaussian elimination) which are easy to write in matrix form. --- **Solving the example system (by elimination):** System: 1) 2x + 3y = 5 2) −x + 4y = 1 Step 1: Eliminate x.
