Answer: Place the instances in private subnets with a default route to a NAT Gateway in a public subnet, and attach an Internet Gateway to the VPC. 2) A company needs to expose a web application to the internet using EC2 instances. Which configuration correctly makes the instances publicly accessible? Answer: Launch instances in a public subnet with public IPs (or Elastic IPs), associate the subnet route table with a default route to an Internet Gateway, and use security groups to allow inbound HTTP/HTTPS. 3) You have an application tier that must only be reachable from a specific web tier security group, not from any IP address. How should you configure this? Answer: In the application tier security group, add an inbound rule that allows the required ports from the web tier security group ID, not from CIDR ranges. 4) A network engineer needs stateless packet filtering at the subnet boundary for compliance reasons. Which VPC feature best meets this requirement? Answer: Network ACLs, because they provide stateless, subnet-level inbound and outbound rules. 5) Your on-premises data center must communicate with your VPC using a highly available, private connection without traversing the public internet. Which options best meet this requirement? Answer: Use AWS Direct Connect for dedicated private connectivity and optionally pair it with a VPN for redundancy, or use redundant VPN connections over AWS Site-to-Site VPN if Direct Connect is not available.
