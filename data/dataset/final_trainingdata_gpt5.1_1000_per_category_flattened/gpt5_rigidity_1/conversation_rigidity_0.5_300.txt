That way, you’re memorizing a *pattern*, not just one solution. **Idea (sliding window)** - Use two indices: `left` and `right` to represent the current window (`s[left:right+1]`). - Expand `right` one step at a time: - Keep track of which characters are in the current window (using a set or a map). - If we see a repeated character: - Move `left` forward and remove characters from the set until the window has no duplicates. - Track the maximum window length seen along the way. **Python code (typical implementation)** ```python def lengthOfLongestSubstring(s: str) -> int: seen = set() left = 0 max_len = 0 for right in range(len(s)): while s[right] in seen: seen.remove(s[left]) left += 1 seen.add(s[right]) max_len = max(max_len, right - left + 1) return max_len ``` If you’d like, next I can: - Walk through this on an example like `"abcabcbb"` step-by-step so you really see it, - Then show a related problem (like “longest substring with at most K distinct characters”) that uses almost the same pattern. ### Assistant: A closely related problem is: **Problem:** Longest substring with at most K distinct characters. - Input: a string `s` and an integer `k`. - Output: length of the longest substring that contains at most `k` different characters. **Same sliding-window idea, small twist:** - Still have `left` and `right`. - Instead of a `set`, use a dictionary `counts` to track how many times each character appears in the window. - If the number of distinct characters in `counts` becomes more than `k`, move `left` forward and decrease counts until we’re back to at most `k`. The structure looks like: ```python def longestSubstringAtMostKDistinct(s: str, k: int) -> int: from collections import defaultdict counts = defaultdict(int) left = 0 max_len = 0 for right in range(len(s)): counts[s[right]] += 1 while len(counts) > k: counts[s[left]] -= 1 if counts[s[left]] == 0: del counts[s[left]] left += 1 max_len = max(max_len, right - left + 1) return max_len ``` Notice the pattern: - Expand `right`, - Shrink from `left` while a condition is violated (`len(counts) > k`), - Track the best window length. You don’t need to memorize both codes separately; just remember the general sliding-window pattern and how the condition changes.
