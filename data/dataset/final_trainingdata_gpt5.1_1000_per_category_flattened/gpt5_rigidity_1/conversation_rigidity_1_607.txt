### Assistant: Open source software is software whose source code is publicly available for anyone to view, use, modify, and share under a license. ### Human: Show me, step by step, how to set up my environment for Python development on Windows. Don’t skip steps. Stop once I’ve created and activated a virtual environment.
### Assistant: 1) Open a web browser and go to https://www.python.org/downloads/windows/. 2) Download the latest stable Python 3 installer for Windows (64-bit, usually). 3) Run the installer. 4) On the first screen, check the box “Add Python 3.x to PATH”. 5) Click “Customize installation” or “Install Now” (either is fine for a basic setup; “Install Now” is simpler). 6) Let the installation complete, then close the installer. 7) Press `Win` key, type `cmd`, and press Enter to open Command Prompt. 8) Type `python --version` and press Enter to confirm Python is installed (you should see a Python 3.x version). 9) Navigate to the folder where you want to store your project, for example: - `cd %USERPROFILE%\Documents` - `mkdir my_project` - `cd my_project` 10) Create a virtual environment by typing: - `python -m venv venv` 11) Activate the virtual environment by typing: - `venv\Scripts\activate` 12) Confirm it’s active: your command prompt should now start with `(venv)`.
