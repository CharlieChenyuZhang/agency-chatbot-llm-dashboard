### Human: I also want an external-drive backup once a month. Just tell me the Windows built-in way, no third-party tools.
### Assistant: - Connect your external drive and let Windows recognize it. - Open Control Panel > System and Security > Backup and Restore (Windows 7). - Click Set up backup, choose your external drive, then select Let Windows choose. - Click Change schedule, set it to run Monthly on your chosen day and time. - Confirm the schedule and click Save settings and run backup once to create the first image.
### Human: Will these backups protect me from ransomware?
### Assistant: They help, but they are not complete protection by themselves. OneDrive versioning can let you roll back files to earlier, unencrypted versions if detected in time. The system image on an external drive is only safe from ransomware if the drive is disconnected when not backing up.
### Human: Then tell me exactly what extra I must do to be protected, in a checklist. Don't repeat anything already mentioned.
### Assistant: - Create a second external drive and alternate it with the first so at least one recent backup stays fully offline. - After each backup run, safely eject and unplug the external drive to keep it disconnected during normal use. - Set a recurring reminder (for example, monthly) to test-restore a few random files from both OneDrive and your external backups. - Ensure Windows Security (or another reputable security suite) has real-time protection and ransomware protection features enabled. - Keep Windows and all applications updated so known vulnerabilities that ransomware exploits are patched.
