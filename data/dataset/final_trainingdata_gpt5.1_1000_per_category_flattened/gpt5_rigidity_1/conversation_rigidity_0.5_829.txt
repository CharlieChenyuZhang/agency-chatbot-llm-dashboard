Step-by-step to record your first episode (Windows + 1 USB mic)** 1. **Install software** - On one laptop: - Download **Audacity** (from audacityteam.org). - Install it with default options. 2. **Connect your mic** - Plug the USB mic into the laptop. - In Windows Sound settings: - Set the USB mic as the **default input** (recording device). 3. **Set up Audacity** - Open Audacity. - At the top: - Choose your USB mic as the **Recording Device**. - Choose your laptop speakers or headphones as the **Playback Device**. - Set project rate to **44100 Hz** (standard). 4. **Do a test recording (very important)** - Both of you sit where you’d normally sit. - Hit the red **Record** button. - Talk for 30–60 seconds like you would in a real episode. - Hit **Stop**, then **Play**: - Check volume: not too quiet, not clipping (distorted). - If it’s too loud and distorted, lower your input level (mic level in Windows or Audacity). - If too quiet, move closer to the mic and increase input slightly. 5. **Record the real episode** - Hit **Record**. - Record the whole conversation in one take to keep it simple at first. - If you totally mess up, pause and say, “We’ll cut that out later,” then keep going. 6. **Basic editing** - Use the **Selection Tool** to: - Highlight dead air, big mistakes. - Press Delete. - Use **Effect → Noise Reduction** if background hum is noticeable: - Select a few seconds of “room noise.” - Click “Get Noise Profile.” - Then select the whole track and apply Noise Reduction with default settings once. - Use **Effect → Normalize** to even out volume. 7. **Export your episode** - File → Export → Export as MP3. - Bitrate: 128 kbps is fine starting out. - Name it something like: `Episode_001_Internet_Stories.mp3`. **B.
