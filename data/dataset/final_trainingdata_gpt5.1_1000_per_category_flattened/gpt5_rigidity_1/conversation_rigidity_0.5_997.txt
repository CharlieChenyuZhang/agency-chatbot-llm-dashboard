### Human: Let's do Python. I have multiple sheets though. I need each sheet as its own CSV. How would that look?
### Assistant: You can loop over all sheets in the workbook and write each one to its own CSV file. Here’s a Python + pandas script that does exactly that: ```python import pandas as pd from pathlib import Path excel_path = Path("input.xlsx") # change to your file output_folder = Path("csv_exports") output_folder.mkdir(exist_ok=True) # Load all sheets as a dict: {sheet_name: DataFrame} sheets = pd.read_excel(excel_path, sheet_name=None) for sheet_name, df in sheets.items(): # Create a safe file name from the sheet name safe_name = "".join(c if c.isalnum() or c in " _-" else "_" for c in sheet_name) csv_path = output_folder / f"{safe_name}.csv" df.to_csv(csv_path, index=False, encoding="utf-8") print(f"Exported sheet '{sheet_name}' to {csv_path}") ``` What this does: - Reads **all sheets** in `input.xlsx`. - Creates a folder called `csv_exports` next to your script (if it doesn’t exist). - Exports each sheet to `SheetName.csv` (with unsafe characters replaced by `_`). This gives you one CSV per sheet, all with values only (no formulas), which should be ideal for uploading or further processing. If your web app only needs **one** of the sheets, you can adjust the script to just export the specific sheet name instead of all of them.
