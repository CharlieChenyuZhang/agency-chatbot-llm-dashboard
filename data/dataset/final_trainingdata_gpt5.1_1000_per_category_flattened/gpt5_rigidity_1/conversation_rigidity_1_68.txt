Problem: Coin Change (minimum coins to make a given amount) Idea: - Use bottom-up DP where dp[i] = minimum coins needed to make amount i. - Initialize dp[0] = 0 and all others to a large sentinel value (e.g., amount + 1). - For each coin, update dp for all amounts ≥ coin: dp[i] = min(dp[i], dp[i – coin] + 1). - If dp[amount] is still the sentinel, return -1. Java code: ```java public int coinChange(int[] coins, int amount) { int max = amount + 1; int[] dp = new int[amount + 1]; Arrays.fill(dp, max); dp[0] = 0; for (int coin : coins) { for (int i = coin; i <= amount; i++) { dp[i] = Math.min(dp[i], dp[i - coin] + 1); } } return dp[amount] > amount ? -1 : dp[amount]; } ``` Time complexity: O(n * amount), where n is number of coins. Space complexity: O(amount).
